# Reverse Linked List · 反转链表

- **LeetCode:** 206
- **难度 Difficulty:** Easy
- **标签 Topics:** 链表 / 迭代 / 递归 / Linked List / Iteration / Recursion
- **苹果频率:** 高频（候选面经多次出现，链表类最高频之一）

## 题干（中文）

给定单链表的头节点 `head`，请你反转链表，并返回反转后的头节点。

## Problem Statement (English)

Given the `head` of a singly linked list, reverse the list, and return the reversed list.

## 示例 / Examples

```
输入 / Input:  head = [1,2,3,4,5]
输出 / Output: [5,4,3,2,1]

输入 / Input:  head = [1,2]
输出 / Output: [2,1]

输入 / Input:  head = []
输出 / Output: []
```

## 约束 / Constraints

- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

## 进阶 / Follow-up

链表可以选用**迭代**或**递归**方式完成反转。你能否用两种方法解决这道题？
