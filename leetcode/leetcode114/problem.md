# LeetCode 114. Flatten Binary Tree to Linked List（二叉树展开为链表）

## 考点
栈、树、DFS、链表、二叉树

## 题目描述
给你二叉树的根节点 `root`，请你将它展开为一个单链表：

- 展开后的单链表应该同样使用 `TreeNode`，其中 `right` 子指针指向链表中下一个节点，而 `left` 子指针始终为 `null`。
- 展开后的单链表应该与二叉树**先序遍历**顺序相同。

**示例 1：**
```
输入：root = [1,2,5,3,4,null,6]
输出：[1,null,2,null,3,null,4,null,5,null,6]
```

**示例 2：**
```
输入：root = []
输出：[]
```

**示例 3：**
```
输入：root = [0]
输出：[0]
```

**提示：**
- 树中节点数目在范围 `[0, 2000]` 内
- `-100 <= Node.val <= 100`

## 解题思路
**方法：反向前序遍历（右-左-根）**

使用「右-左-根」的遍历顺序（即先序遍历的逆序），用一个全局变量 `prev` 记录上一个访问的节点。

1. 如果根为空，直接返回
2. 递归处理右子树
3. 递归处理左子树
4. 将当前节点的 `right` 指向 `prev`，`left` 置为 `null`
5. 更新 `prev = root`

**为什么这样可行？**
按「右→左→根」的顺序访问，实际上就是先序「根→左→右」的逆序。当我们按逆序构建链表时，每个节点的 next 正好是先序遍历的下一个节点。

**关键点：**
- 必须在修改 `left`/`right` 之前保存原始引用
- 这种方法不需要额外空间
- 也可以使用迭代 + 栈的 O(1) 额外空间方法（Morris 遍历变形）

时间复杂度：O(n)  
空间复杂度：O(n) —— 递归栈，最坏情况链状树
