# LeetCode 167. Two Sum II - Input Array Is Sorted（两数之和II） — **中等**

## 考点
Array, Two Pointers, Binary Search

## 题目描述
给你一个下标从 **1** 开始的整数数组 `numbers` ，该数组已按 **非递减顺序排列** ，请你从数组中找出满足相加之和等于目标数 `target` 的两个数。如果设这两个数分别是 `numbers[index1]` 和 `numbers[index2]` ，则 `1 <= index1 < index2 <= numbers.length` 。

以长度为 2 的整数数组 `[index1, index2]` 的形式返回这两个整数的下标 `index1` 和 `index2`。

你可以假设每个输入 **只对应唯一的答案** ，而且你 **不可以** 重复使用相同的元素。

你所设计的解决方案必须只使用常量级的额外空间。

**示例 1：**

```
输入：numbers = [2,7,11,15], target = 9
输出：[1,2]
解释：2 与 7 之和等于目标数 9 。因此 index1 = 1, index2 = 2 。返回 [1, 2] 。
```

**示例 2：**

```
输入：numbers = [2,3,4], target = 6
输出：[1,3]
解释：2 与 4 之和等于目标数 6 。因此 index1 = 1, index2 = 3 。返回 [1, 3] 。
```

**示例 3：**

```
输入：numbers = [-1,0], target = -1
输出：[1,2]
解释：-1 与 0 之和等于目标数 -1 。因此 index1 = 1, index2 = 2 。返回 [1, 2] 。
```

**提示：**
- `2 <= numbers.length <= 3 * 10^4`
- `-1000 <= numbers[i] <= 1000`
- `numbers` 按 **非递减顺序** 排列
- `-1000 <= target <= 1000`
- **仅存在一个有效答案**

## 解题思路

### 核心思路

数组已排序，利用双指针从两端向中间逼近。计算两指针所指元素之和，若和太小则左指针右移（增大和），若和太大则右指针左移（减小和）。因为数组有序，这种贪心策略能保证找到唯一解。

### 算法步骤

1. 初始化 `left = 0`, `right = n - 1`
2. 当 `left < right` 时循环：
   - `sum = nums[left] + nums[right]`
   - 若 `sum == target`：返回 `[left + 1, right + 1]`（1-indexed）
   - 若 `sum < target`：`left++`
   - 若 `sum > target`：`right--`

### 图解示例

**示例**: `nums = [2, 7, 11, 15]`, `target = 9`

```
数组: 索引  0   1   2   3
     值   [2,  7, 11, 15]
           ↑           ↑
          left       right

Step 1: left=0, right=3
        2 + 15 = 17 > 9 → right 左移
        [2,  7, 11, 15]
         ↑       ↑
        left   right

Step 2: left=0, right=2
        2 + 11 = 13 > 9 → right 左移
        [2,  7, 11, 15]
         ↑   ↑
        left right

Step 3: left=0, right=1
        2 + 7 = 9 == target → 返回 [1, 2]
```

**双指针移动方向原理：**

```
和的大小 → 指针移动方向示意图：

  sum < target           sum > target
  ← 需要更大 →          ← 需要更小 →
    left →                   ← right

    [ ■  ■  ■  ■  ■  ■  ■  ■ ]
      ↑                    ↑
     left                right
       →→→              ←←←
     增大和              减小和
```

### 逐步追踪表

| 步骤 | left | right | nums[left] | nums[right] | sum | 比较 | 操作 |
|------|------|-------|------------|-------------|-----|------|------|
| 1 | 0 | 3 | 2 | 15 | 17 | 17 > 9 | right=2 |
| 2 | 0 | 2 | 2 | 11 | 13 | 13 > 9 | right=1 |
| 3 | 0 | 1 | 2 | 7 | 9 | 9 == 9 | 返回[1,2] |

### 方法二：二分查找

固定一个数，对剩余部分用二分查找 target - nums[i]。适合 n 很大的情况。

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 双指针 | O(n) | O(1) |
| 二分查找 | O(n log n) | O(1) |

### 边界情况

| 场景 | 输入 | 处理 |
|------|------|------|
| 负数和正数混合 | `[-3, 1, 2, 5]`, target=2 | 双指针正常工作 |
| 目标在两端 | `[1, 2, 3, 9]`, target=10 | left=0, right=3 直接命中 |
| 最小长度 | `[1, 2]`, target=3 | 唯一解 |
| 全负数 | `[-5, -3, -1]`, target=-4 | 双指针正常工作 |

### 复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| 时间复杂度 | O(n) | 最坏情况遍历整个数组 |
| 空间复杂度 | O(1) | 只使用两个指针 |
