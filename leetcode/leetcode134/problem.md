# LeetCode 134. Gas Station（加油站）

## 考点
贪心、数组

## 题目描述
在一条环路上有 `n` 个加油站，其中第 `i` 个加油站有汽油 `gas[i]` 升。

你有一辆油箱容量无限的汽车，从第 `i` 个加油站开往第 `i+1` 个加油站需要消耗汽油 `cost[i]` 升。你从其中的一个加油站出发，开始时油箱为空。

给定两个整数数组 `gas` 和 `cost`，如果你可以按顺序绕环路行驶一周，则返回出发时加油站的编号，否则返回 `-1`。如果存在解，则**保证它是唯一的**。

**示例 1：**
```
输入：gas = [1,2,3,4,5], cost = [3,4,5,1,2]
输出：3
解释：从 3 号加油站（索引为 3）出发，可获得 4 升汽油。油箱 = 0 + 4 = 4。
     开往 4 号加油站，此时油箱 = 4 - 1 + 5 = 8。
     开往 0 号加油站，此时油箱 = 8 - 2 + 1 = 7。
     开往 1 号加油站，此时油箱 = 7 - 3 + 2 = 6。
     开往 2 号加油站，此时油箱 = 6 - 4 + 3 = 5。
     开往 3 号加油站，成功绕行一周。
```

**示例 2：**
```
输入：gas = [2,3,4], cost = [3,4,3]
输出：-1
解释：总共只有 2+3+4=9 升油，但总消耗为 3+4+3=10，无法绕行一周。
```

**提示：**
- `n == gas.length == cost.length`
- `1 <= n <= 10^5`
- `0 <= gas[i], cost[i] <= 10^4`

## 解题思路
**贪心算法。**

**关键推理：**
1. 如果总油量 `sum(gas)` < 总消耗 `sum(cost)`，一定无法完成，返回 `-1`
2. 如果总油量 >= 总消耗，一定存在可行的起点，且题目保证唯一

**算法：**
1. 计算 `totalTank = 0`（总剩余油量）和 `currTank = 0`（当前段剩余油量）
2. 记录 `start = 0`（候选起点）
3. 遍历每个加油站 i：
   - `totalTank += gas[i] - cost[i]`
   - `currTank += gas[i] - cost[i]`
   - 如果 `currTank < 0`，说明从 `start` 到 `i` 之间任何点出发都无法通过此段：
     - 重置 `start = i + 1`
     - 重置 `currTank = 0`
4. 最后若 `totalTank >= 0` 返回 `start`，否则返回 `-1`

**为什么跳过的区间一定不行？**
如果从 `start` 出发到 `i` 时油量变负，那么从 `start` 到 `i` 之间的任意点出发，到达 `i` 时的油量只会更少（因为少了一段加油），所以一定也无法通过。

时间复杂度：O(n)  
空间复杂度：O(1)
