# LeetCode 23. Merge k Sorted Lists（合并K个升序链表）

## 考点
Linked List, Divide and Conquer, Heap

## 题目描述
给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

### 示例 1
```
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
```

### 约束
- `k == lists.length`
- `0 <= k <= 10^4`
- `0 <= lists[i].length <= 500`
- `-10^4 <= lists[i][j] <= 10^4`
- `lists[i]` 按升序排列

## 解题思路

### 方法：分治法（归并）
核心思想：两两合并链表，直到只剩一个链表。类似归并排序的合并过程。

**步骤：**
1. 如果 `lists` 为空，返回 `null`。
2. 使用分治递归：
   - 如果 `left === right`，返回 `lists[left]`。
   - 如果 `left > right`，返回 `null`。
   - 计算 `mid = (left + right) >> 1`。
   - 递归合并左半部分和右半部分。
3. 使用「合并两个有序链表」的函数合并两个链表。

**关键点：**
- 分治递归深度为 O(log k)，每层合并 O(N) 个节点（N 为所有节点总数）。
- 相比逐个合并（O(kN)），分治法时间复杂度更优，为 O(N log k)。
- 也可以使用最小堆（优先队列），每次取 k 个链表头中最小的节点。

时间复杂度：O(N log k)，N 是所有节点总数
空间复杂度：O(log k)（递归栈）
