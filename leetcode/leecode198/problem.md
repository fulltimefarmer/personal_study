# LeetCode 198. House Robber（打家劫舍） — **中等**

## 考点
数组、动态规划

## 题目描述
你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你**不触动警报装置的情况下**，一夜之内能够偷窃到的最高金额。

**示例 1：**
```
输入：[1,2,3,1]
输出：4
解释：偷窃 1 号房屋（金额 = 1），然后偷窃 3 号房屋（金额 = 3）。
     偷窃到的最高金额 = 1 + 3 = 4。
```

**示例 2：**
```
输入：[2,7,9,3,1]
输出：12
解释：偷窃 1 号房屋（金额 = 2），偷窃 3 号房屋（金额 = 9），接着偷窃 5 号房屋（金额 = 1）。
     偷窃到的最高金额 = 2 + 9 + 1 = 12。
```

**提示：**
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

## 解题思路

### 核心思路

经典线性 DP。`dp[i]` 表示偷到第 i 间房时的最大收益。对每间房，要么偷（不能偷前一间），要么不偷（保留前一间的收益）。状态转移：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。

### 算法步骤

1. 若 `n == 1`，返回 `nums[0]`
2. 初始化 `prev2 = nums[0]`, `prev1 = max(nums[0], nums[1])`
3. 从 i=2 到 n-1 循环：
   - `curr = max(prev1, prev2 + nums[i])`
   - `prev2 = prev1`, `prev1 = curr`
4. 返回 `prev1`

### 图解示例

**示例**: `nums = [2, 7, 9, 3, 1]`

```
房屋及其金额:
  i=0    i=1    i=2    i=3    i=4
  [2]    [7]    [9]    [3]    [1]

DP 推理过程:

i=0: dp[0] = 2
     只能偷第0间

i=1: dp[1] = max(7, 2) = 7
     偷第1间(7) vs 只偷第0间(2)

i=2: dp[2] = max(dp[1], dp[0] + 9) = max(7, 2+9) = 11
     不偷第2间(沿用7) vs 偷第2间(2+9=11)

i=3: dp[3] = max(dp[2], dp[1] + 3) = max(11, 7+3) = 11
     不偷(11) vs 偷第3间(7+3=10)
     选大的: 不偷 → 11

i=4: dp[4] = max(dp[3], dp[2] + 1) = max(11, 11+1) = 12
     不偷(11) vs 偷第4间(11+1=12)
     选大的: 偷 → 12

DP表最终值:
  i    0   1   2   3   4
  nums 2   7   9   3   1
  dp   2   7  11  11  12

偷窃方案: 偷 i=0(2), i=2(9), i=4(1) → 2+9+1=12

决策树示意:
                 dp[0]=2
              /           \
        dp[1]=7          (不能同时偷)
        /   \           /   \
    dp[2]=11  ...     ...   ...
      /   \
  dp[3]   dp[3]
 (不偷)   (偷)
  =11     =10

实际决策:
 [2] → skip → [9] → skip → [1]
  ✓           ✓           ✓    = 12
```

### 逐步追踪表

| i | nums[i] | prev2 (dp[i-2]) | prev1 (dp[i-1]) | prev2+nums[i] | max | curr (dp[i]) |
|---|---------|-----------------|-----------------|---------------|-----|-------------|
| 0 | 2 | — | — | — | — | 2 |
| 1 | 7 | 2 | 2 | 9 | max(2,9) | 7 |
| 2 | 9 | 2 | 7 | 11 | max(7,11) | 11 |
| 3 | 3 | 7 | 11 | 10 | max(11,10) | 11 |
| 4 | 1 | 11 | 11 | 12 | max(11,12) | 12 |

### 边界情况

| 场景 | 输入 | 处理 |
|------|------|------|
| 单间房 | `[5]` | 直接返回5 |
| 两间房 | `[2, 3]` | 返回 max(2, 3) = 3 |
| 全部相同 | `[5, 5, 5, 5]` | 隔间偷，返回 5+5=10 |
| 递增序列 | `[1, 2, 3, 4]` | 偷1和3 → 1+3=4；或偷2和4 → 2+4=6；最大6 |

### 复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| 时间复杂度 | O(n) | 一次遍历 |
| 空间复杂度（滚动） | O(1) | 只使用 prev2, prev1, curr |
| 空间复杂度（DP表） | O(n) | 若需要回溯轨迹 |
