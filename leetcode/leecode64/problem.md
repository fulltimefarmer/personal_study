# LeetCode 64. Minimum Path Sum（最小路径和） — **中等**

## 考点
Array, Dynamic Programming, Matrix

## 题目描述
给定一个包含非负整数的 `m x n` 网格 `grid`，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**说明：** 每次只能向下或者向右移动一步。

### 示例 1
```
输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
解释：因为路径 1→3→1→1→1 的总和最小。
```

### 示例 2
```
输入：grid = [[1,2,3],[4,5,6]]
输出：12
```

### 约束
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 200`

## 图解

```mermaid
flowchart TD
    A[原地DP] --> B[累加第一行: grid[0][j] += grid[0][j-1]]
    B --> C[累加第一列: grid[i][0] += grid[i-1][0]]
    C --> D{i=1..m-1, j=1..n-1}
    D --> E["grid[i][j] += min<br>grid[i-1][j], grid[i][j-1]"]
    E --> D
    D -->|结束| F["返回 grid[m-1][n-1]"]
```

## 解题思路

### 核心思路
同样是网格 DP，但这次要求最小值而非路径数。到达 (i,j) 的最小路径和 = 当前格子的值 + min(从上方到达的最小和, 从左侧到达的最小和)。

**关键洞察：** 选择来自上方或左侧路径中较小的那条，再加上当前格子的值。第一行只能累加左边的值，第一列只能累加上方值。

### 算法步骤

1. 获取 m, n
2. 初始化第一行：`grid[0][j] += grid[0][j-1]` for j=1..n-1（只能从左边来）
3. 初始化第一列：`grid[i][0] += grid[i-1][0]` for i=1..m-1（只能从上方来）
4. 填充其余位置：对 i=1..m-1, j=1..n-1：
   - `grid[i][j] += min(grid[i-1][j], grid[i][j-1])`
5. 返回 `grid[m-1][n-1]`

| 情况 | 输入 | 处理 | 结果 |

### 方法对比

**方法一：原地 DP（推荐）**
```
直接修改 grid，grid[i][j] 存储到该位置的最小路径和
时间: O(m×n), 空间: O(1)
```

**方法二：独立 DP 数组**
```
创建新 dp 数组，不修改输入
时间: O(m×n), 空间: O(m×n) 或 O(n) 一维优化
```

**方法三：一维 DP**
```
dp[j] 存储当前行到列 j 的最小路径和
更新: dp[j] = grid[i][j] + min(dp[j], dp[j-1])
时间: O(m×n), 空间: O(n)
```

### 复杂度分析

- **时间复杂度：** O(m × n)，每个格子计算一次
- **空间复杂度：** O(1)（原地修改），或 O(n)（一维 DP 数组）
- 这是典型的网格最短路径 DP，空间可以极致优化
