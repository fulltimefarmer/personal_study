# LeetCode 207. Course Schedule（课程表） — **中等**

## 考点
深度优先搜索、广度优先搜索、图、拓扑排序

## 题目描述
你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1`。

在选修某些课程之前需要一些先修课程。先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]`，表示如果要学习课程 `ai` 则**必须**先学习课程 `bi`。

- 例如，先修课程对 `[0, 1]` 表示：想要学习课程 `0`，你需要先完成课程 `1`。

请你判断是否可能完成所有课程的学习？如果可以，返回 `true`；否则，返回 `false`。

**示例 1：**
```
输入：numCourses = 2, prerequisites = [[1,0]]
输出：true
解释：总共有 2 门课程。学习课程 1 之前，你需要完成课程 0。这是可能的。
```

**示例 2：**
```
输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false
解释：总共有 2 门课程。学习课程 1 之前，你需要先完成课程 0；而学习课程 0 之前，你还应先完成课程 1。这是不可能的。
```

**提示：**
- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= 5000`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < numCourses`
- `prerequisites[i]` 中的所有课程对互不相同

## 解题思路

### 核心思路

课程依赖关系构成有向图（先修课程 → 后续课程）。问题转化为判断有向图是否有环。若有环则无法完成所有课程。两种主流方法：BFS（Kahn 算法 / 入度法）和 DFS（三色标记法）。

### 方法一：BFS — Kahn 算法（入度法）

#### 算法步骤

1. 构建邻接表 `graph`（先修→后续）和入度数组 `indegree`
2. 将所有入度为 0 的节点入队
3. 当队列非空时：
   - 出队节点 `u`，`count++`
   - 遍历 u 的所有邻居 v：`indegree[v]--`，若变为 0 则入队
4. 若 `count == numCourses` → 无环，返回 true；否则有环

### 方法二：DFS — 三色标记法

标记每个节点的访问状态：`0`=未访问，`1`=正在访问（当前递归路径中），`2`=已访问完成。DFS 时若遇到状态为 1 的节点，说明存在环。

### 图解示例

**示例 1**: `numCourses=2, prerequisites=[[1,0]]` (无环)

```
课程依赖关系图:
  0 ──→ 1

邻接表:
  0: [1]
  1: []

入度:
  0: 0  ← 无先修, 入队
  1: 1

BFS过程:
  队列: [0]
  pop 0 → count=1, 邻居1入度减1→0, 入队
  队列: [1]
  pop 1 → count=2

  count=2 == numCourses=2 → true
```

**示例 2**: `numCourses=2, prerequisites=[[1,0],[0,1]]` (有环)

```
课程依赖关系图:
  ┌─────┐
  ↓     │
  0 ⇄ 1
  │     ↑
  └─────┘

邻接表:
  0: [1]
  1: [0]

入度:
  0: 1
  1: 1
  (没有入度为0的节点!)

BFS过程:
  队列: []  ← 初始无入度为0的节点
  count = 0 < numCourses = 2 → false, 有环!
```

**Kahn算法拓扑排序图示（更复杂的例子）：**

```
课程: numCourses=6, prereq=[[3,0],[3,1],[4,2],[5,3],[5,4]]

依赖图:
      0 ──┐
           ├──→ 3 ──→ 5
      1 ──┘          ↗
      2 ──→ 4 ──────┘

邻接表:
  0: [3]    入度: 0=0
  1: [3]         1=0
  2: [4]         2=0
  3: [5]         3=2
  4: [5]         4=1
  5: []          5=2

BFS拓扑排序过程:
  step1: 入度0的节点入队 → queue=[0,1,2]
  step2: pop 0 → 3入度 2→1
  step3: pop 1 → 3入度 1→0 → 3入队
  step4: pop 2 → 4入度 1→0 → 4入队
  step5: pop 3 → 5入度 2→1
  step6: pop 4 → 5入度 1→0 → 5入队
  step7: pop 5 → 完成

  出队顺序: 0, 1, 2, 3, 4, 5  (count=6, 无环)
```

**DFS三色法检测环：**

```
三色标记示意:
  [0] → [1]  →  [2]
  未    正      已
  访    在      完
  问    访      成
       问

检测到环的情况:
  从节点0开始DFS:
    dfs(0): 标记0=1(正在访问)
      dfs(1): 标记1=1(正在访问)
        dfs(0): 发现0已是1(正在访问)
                → 回到当前路径中的节点 → 有环!
```

### 逐步追踪表（Kahn算法，示例2有环）

| 步骤 | 队列 | 出队 | count | 邻居 | 邻居新入度 | 入队 |
|------|------|------|-------|------|-----------|------|
| 初始 | [] | — | 0 | — | — | — |
| — | — | — | 0 | — | — | — |

入度数组 [1,1]，无入度为0的节点，队列为空，BFS无法启动。count=0 ≠ 2 → 有环。

### 边界情况

| 场景 | 处理 |
|------|------|
| 无先修课（`prerequisites` 为空） | 所有课入度为0，直接 true |
| 单门课 | count==1，true |
| 自环 | `[[0,0]]` → 入度[1] → 队列空 → false |
| 大图无环 | BFS 正常完成拓扑排序 |

### 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS (Kahn) | O(V + E) | O(V + E) |
| DFS (三色) | O(V + E) | O(V + E) |
