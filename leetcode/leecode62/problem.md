# LeetCode 62. Unique Paths（不同路径） — **中等**

## 考点
Math, Dynamic Programming, Combinatorics

## 题目描述
一个机器人位于一个 `m x n` 网格的左上角（起始点在下图中标记为 "Start"）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 "Finish"）。

问总共有多少条不同的路径？

### 示例 1
```
输入：m = 3, n = 7
输出：28
```

### 示例 2
```
输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

### 约束
- `1 <= m, n <= 100`
- 答案保证在 `2 * 10^9` 以内

## 解题思路

### 核心思路
机器人从 (0,0) 到 (m-1,n-1)，每一步只能向下或向右。问题等价于：在总共 (m-1)+(n-1) = m+n-2 步中，选择 (m-1) 步向下，其余向右。

**两种视角：**
1. **DP 视角（自顶向下）：** 到达 (i,j) 的路径数 = 到达 (i-1,j) 的路径数 + 到达 (i,j-1) 的路径数
2. **组合数学视角：** C(m+n-2, m-1) = C(m+n-2, n-1)

### 算法步骤

**方法一：动态规划**

1. 创建二维 DP 数组 dp[m][n]
2. 初始化第一行和第一列为 1（到达第一行/列的任何位置只有一种方式：一直向右/向下）
3. 对 i = 1 到 m-1, j = 1 到 n-1：
   - dp[i][j] = dp[i-1][j] + dp[i][j-1]
4. 返回 dp[m-1][n-1]

**空间优化（一维 DP）：** dp[j] = dp[j] + dp[j-1]，其中等式右边的 dp[j] 是上一行的值，dp[j-1] 是当前行左边的值。

```
                                    F (终点)

每个格子的值 = 上方 + 左方

```

**一维 DP 滚动更新（m=3, n=7）：**

```
初始 dp: [1, 1, 1, 1, 1, 1, 1]  (第一行)

处理第 2 行 (i=1):
  j=1: dp[1] = dp[1] + dp[0] = 1 + 1 = 2
  j=2: dp[2] = dp[2] + dp[1] = 1 + 2 = 3
  j=3: dp[3] = dp[3] + dp[2] = 1 + 3 = 4
  j=4: dp[4] = dp[4] + dp[3] = 1 + 4 = 5
  j=5: dp[5] = dp[5] + dp[4] = 1 + 5 = 6
  j=6: dp[6] = dp[6] + dp[5] = 1 + 6 = 7
  → dp = [1, 2, 3, 4, 5, 6, 7]

处理第 3 行 (i=2):
  j=1: dp[1] = dp[1] + dp[0] = 2 + 1 = 3
  j=2: dp[2] = dp[2] + dp[1] = 3 + 3 = 6
  j=3: dp[3] = dp[3] + dp[2] = 4 + 6 = 10
  j=4: dp[4] = dp[4] + dp[3] = 5 + 10 = 15
  j=5: dp[5] = dp[5] + dp[4] = 6 + 15 = 21
  j=6: dp[6] = dp[6] + dp[5] = 7 + 21 = 28
  → dp = [1, 3, 6, 10, 15, 21, 28]
  
答案: dp[6] = 28
```

### 逐步追踪（DP 二维）

**输入：m = 3, n = 2**

| 操作 | dp[0][0] | dp[0][1] | dp[1][0] | dp[1][1] | dp[2][0] | dp[2][1] |
|------|----------|----------|----------|----------|----------|----------|
| 初始化 | 1 | 1 | 1 | - | 1 | - |
| dp[1][1] | - | - | - | 1+1=2 | - | - |
| dp[2][1] | - | - | - | - | - | 1+2=3 |

结果: 3，对应三条路径：
1. → ↓ ↓
2. ↓ ↓ →
3. ↓ → ↓

### 边界情况

| 情况 | 输入 | 处理 | 结果 |
|------|------|------|------|
| 1×1 网格 | m=1, n=1 | 0步移动，1条路径 | 1 |
| 单行 | m=1, n=100 | 只有向右一种方式 | 1 |
| 单列 | m=100, n=1 | 只有向下一种方式 | 1 |
| 大网格 | m=100, n=100 | DP 或组合数计算 | C(198,99) |

### 方法对比

**方法一：二维 DP**
```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
时间: O(m×n), 空间: O(m×n)
```

**方法二：一维 DP（空间优化）**
```
dp[j] = dp[j] + dp[j-1]  (dp[j] 是上一行的值)
时间: O(m×n), 空间: O(n)
```

**方法三：组合数学（最优）**
```
C(m+n-2, m-1) = (m+n-2)! / ((m-1)! × (n-1)!)
计算: 遍历 k 从 1 到 (m-1), ans = ans × (N-k+1) / k
时间: O(min(m,n)), 空间: O(1)
```

### 复杂度分析

- **二维 DP：** 时间 O(m×n)，空间 O(m×n)
- **一维 DP：** 时间 O(m×n)，空间 O(n)
- **组合数学：** 时间 O(min(m,n))，空间 O(1)
- n ≤ 100 时 DP 足够；n 更大时组合数学优势明显
