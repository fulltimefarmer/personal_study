# LeetCode 39. Combination Sum（组合总和） — **中等**

## 考点
Array, Backtracking

## 题目描述
给你一个 **无重复元素** 的整数数组 `candidates` 和一个目标整数 `target`，找出 `candidates` 中可以使数字和为目标数 `target` 的所有 **不同组合**，并以列表形式返回。你可以按 **任意顺序** 返回这些组合。

`candidates` 中的 **同一个** 数字可以 **无限制重复被选取**。如果至少一个数字的被选数量不同，则两种组合是不同的。

对于给定的输入，保证和为 `target` 的不同组合数少于 `150` 个。

**示例 1：**
```
输入：candidates = [2,3,6,7], target = 7
输出：[[2,2,3],[7]]
解释：
2 和 3 可以形成一组候选，2 + 2 + 3 = 7 。注意 2 可以使用多次。7 也是一个候选，7 = 7。仅有这两种组合。
```

**示例 2：**
```
输入: candidates = [2,3,5], target = 8
输出: [[2,2,2,2],[2,3,3],[3,5]]
```

**示例 3：**
```
输入: candidates = [2], target = 1
输出: []
```

**提示：**
- `1 <= candidates.length <= 30`
- `2 <= candidates[i] <= 40`
- `candidates` 的所有元素 **互不相同**
- `1 <= target <= 40`

## 解题思路

### 核心思路
回溯 + 剪枝：每个元素可以无限次使用，关键是递归时**起始索引不+1**（允许重复选），但通过 `start` 索引确保不会回头选择（避免 `[2,3]` 和 `[3,2]` 这样的重复组合）。

### 算法步骤
1. 对 `candidates` 排序（可选，用于剪枝优化）
2. 定义递归函数 `backtrack(start, path, remaining)`：
   - `start`：本次可选的起始索引（包含）
   - `path`：当前已选数字列表
   - `remaining`：剩余目标和
3. 终止条件：
   - `remaining == 0`：找到一个解，将 `path` 的副本加入结果
   - `remaining < 0` 或 `start >= len`：剪枝返回
4. 从 `start` 遍历到末尾，对每个 `candidates[i]`：
   - 若 `candidates[i] > remaining`：剪枝（后面的更大，不需要继续）
   - `path.push(candidates[i])`
   - 递归 `backtrack(i, path, remaining - candidates[i])`
   - `path.pop()`（回溯）

### 图解示例
`candidates = [2, 3, 6, 7], target = 7`

```

                  /   |   \    \

          /\  |     |
         2   3     [3,3]✗(7-3-3-3=-2)

        [2,2,2]✗(7-2-2-2=1, 无1)

 选2  选3
  │    │

  i=0: 选2 → rem=1, path=[2,2,2]
```

### 逐步追踪
`candidates = [2,3,6,7], target = 7`

| 深度 | start | path | remaining | 候选判断 | 操作 |
|------|-------|------|-----------|---------|------|
| 0 | 0 | [] | 7 | - | 开始 |
| 1a | 0 | [2] | 5 | 2≤7 | 递归(0, [2], 5) |
| 2a | 0 | [2,2] | 3 | 2≤5 | 递归(0, [2,2], 3) |
| 3a | 0 | [2,2,2] | 1 | 2>1剪枝 | 回溯 |
| 3b | 1 | [2,2,3] | 0 | 3≤3 | **收集: [2,2,3]** ✓ |
| 1b | 1 | [3] | 4 | 3≤7 | 递归(1, [3], 4) |
| 2b | 1 | [3,3] | 1 | 3≤4 | 递归(1, [3,3], 1) |
| 3c | - | - | - | 所有>1 | 剪枝回溯 |
| 1c | 2 | [6] | 1 | 6≤7 | 递归(2, [6], 1) |
| 2c | - | - | - | 所有>1 | 剪枝回溯 |
| 1d | 3 | [7] | 0 | 7≤7 | **收集: [7]** ✓ |

### 边界情况
| 情况 | candidates | target | 输出 | 说明 |
|------|-----------|--------|------|------|
| 无解 | [2] | 1 | [] | target 小于最小候选 |
| 候选即target | [2,3,5] | 8 | [[2,2,2,2],[2,3,3],[3,5]] | 多种组合 |
| 全相同候选 | [2,2,2] | 4 | [[2,2]] | 去重后仅一个有效候选 |
| 单元素 | [5] | 15 | [[5,5,5]] | 重复使用 |

### 复杂度分析
- **时间复杂度**: O(N^(T/M))，N 为候选数数量，T 为目标值，M 为最小候选数。最坏情况每个节点分支 N，深度 T/M
- **空间复杂度**: O(T/M)，递归栈深度（最多选 T/M 个最小候选数）

### 方法对比
| 方法 | 时间复杂度 | 空间复杂度 | 优点 |
|------|-----------|-----------|------|
| 回溯(无排序) | O(N^(T/M)) | O(T/M) | 简单直接 |
| 回溯+排序剪枝 | O(N^(T/M)) | O(T/M) | 提前剪枝，实际更快 |
| DP(完全背包) | O(N*T) | O(T*K) | 可求方案数，但难以输出所有组合 |

### 关键技巧
- **为什么是 `backtrack(i, ...)` 而不是 `backtrack(i+1, ...)`**：因为同一个元素可以无限次使用，下次递归仍然可以从 `i` 开始
- **为什么需要 `start` 参数**：防止回头选择产生重复组合。没有 start 的话 `[2,3]` 和 `[3,2]` 都会被找到，但它们被视为同一组合
- **排序剪枝**：排序后若 `candidates[i] > remaining`，后面的更大，直接 break 内层循环
