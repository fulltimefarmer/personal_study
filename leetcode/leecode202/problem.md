# LeetCode 202. Happy Number（快乐数） — **简单**

## 考点
哈希表、数学、双指针

## 题目描述
编写一个算法来判断一个数 `n` 是不是快乐数。

**「快乐数」** 定义为：
- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和。
- 然后重复这个过程直到这个数变为 1，也可能是**无限循环**但始终变不到 1。
- 如果这个过程**结果为 1**，那么这个数就是快乐数。

如果 `n` 是**快乐数**就返回 `true`；不是，则返回 `false`。

**示例 1：**
```
输入：n = 19
输出：true
解释：
1^2 + 9^2 = 82
8^2 + 2^2 = 68
6^2 + 8^2 = 100
1^2 + 0^2 + 0^2 = 1
```

**示例 2：**
```
输入：n = 2
输出：false
解释：
2 → 4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4 → ...（循环）
```

**提示：**
- `1 <= n <= 2^31 - 1`

## 解题思路

### 核心思路

快乐数的计算过程本质上是检测一个数的变换序列是否会收敛到 1 还是进入循环。类似链表中检测环，可以用哈希集合记录历史值，或使用快慢指针（Floyd 判圈算法）检测循环。

### 方法一：哈希集合法

#### 算法步骤

1. 定义辅助函数 `getNext(n)`: 计算 n 的各位数字平方和
2. 初始化集合 `seen = {}`
3. 当 `n != 1` 且 `n` 不在 `seen` 中时：
   - `seen.add(n)`
   - `n = getNext(n)`
4. 返回 `n == 1`

### 方法二：快慢指针（Floyd 判圈算法）

#### 算法步骤

1. 初始化 `slow = n`, `fast = getNext(n)`
2. 当 `fast != 1` 且 `slow != fast` 时：
   - `slow = getNext(slow)` — 慢指针走一步
   - `fast = getNext(getNext(fast))` — 快指针走两步
3. 返回 `fast == 1`

### 图解示例

**示例 1**: `n = 19` (快乐数)

```
变换链:
  19 → 1²+9²=82 → 8²+2²=68 → 6²+8²=100 → 1²+0²+0²=1 → 1

链式图:
  19 ──→ 82 ──→ 68 ──→ 100 ──→ 1 ──→ 1 ──→ ...
                           到达1后稳定

快慢指针追踪:
  step 0: slow=19, fast=82
  step 1: slow=82, fast=100   (slow走1步, fast走2步: 82→68→100)
  step 2: slow=68, fast=1     (slow: 82→68, fast: 100→1→1)
  step 3: slow=100, fast=1    (slow: 68→100, fast: 1→1)
  step 4: slow=1, fast=1      → fast==1, 是快乐数!
```

**示例 2**: `n = 2` (非快乐数)

```
变换链形成循环:
  2 → 4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4 → ...

循环图示:
        2 ──→ 4 ←── 20
             │       ↑
             16     42
             │       ↑
             37    145
             │       ↑
             58 ←── 89

快慢指针追踪:
  slow: 2 → 4 → 16 → 37 → 58 → ...
  fast: 4 → 37 → 89 → 42 → 4 → ...
  step 1: slow=4,  fast=37
  step 2: slow=16, fast=42
  step 3: slow=37, fast=4
  step 4: slow=58, fast=37
  step 5: slow=89, fast=89  → slow==fast, 进入循环!
  fast != 1 → 非快乐数
```

### 逐步追踪表（方法一，n=19）

| 步骤 | n | getNext计算 | getNext结果 | seen集合 | n==1? |
|------|---|-------------|-------------|----------|-------|
| 1 | 19 | 1²+9²=1+81 | 82 | {19} | No |
| 2 | 82 | 8²+2²=64+4 | 68 | {19,82} | No |
| 3 | 68 | 6²+8²=36+64 | 100 | {19,82,68} | No |
| 4 | 100 | 1²+0²+0²=1 | 1 | {19,82,68,100} | **Yes!** |

### 进入循环的可能数字

已知唯一的非快乐数循环（除了收敛到1）是固定循环：

```
4 → 16 → 37 → 58 → 89 → 145 → 42 → 20 → 4
```

所有非快乐数最终都会进入这个循环。

### 边界情况

| 场景 | 输入 | 处理 |
|------|------|------|
| n = 1 | 1 | 直接返回 true |
| n 已循环数 | 4 | 检测到循环，返回 false |
| 大数 | 99999 | 一次变换后快速变小 (9²×5=405) |

### 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 哈希集合 | O(log n) | O(log n) | 每次计算复杂度 O(log n) |
| 快慢指针 | O(log n) | O(1) | 无额外空间 |
