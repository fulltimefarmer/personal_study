# LeetCode 123. Best Time to Buy and Sell Stock III（买卖股票的最佳时机 III）

## 考点
数组、动态规划

## 题目描述
给定一个数组，它的第 i 个元素是一支给定的股票在第 i 天的价格。

设计一个算法来计算你所能获取的最大利润。你最多可以完成**两笔**交易。

**注意：** 你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

**示例 1：**
```
输入：prices = [3,3,5,0,0,3,1,4]
输出：6
解释：第 4 天买入（价格 0），第 6 天卖出（价格 3），利润 3。
     第 7 天买入（价格 1），第 8 天卖出（价格 4），利润 3。
     总利润 = 3 + 3 = 6。
```

**示例 2：**
```
输入：prices = [1,2,3,4,5]
输出：4
```

**示例 3：**
```
输入：prices = [7,6,4,3,1]
输出：0
```

**提示：**
- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^5`

## 解题思路
**状态机动态规划。** 定义 5 种状态：
- `buy1`：第一次买入后的最大利润（即 -prices[i]）
- `sell1`：第一次卖出后的最大利润
- `buy2`：第二次买入后的最大利润
- `sell2`：第二次卖出后的最大利润

初始状态：
- `buy1 = -Infinity`（未买入过）
- `sell1 = 0`
- `buy2 = -Infinity`
- `sell2 = 0`

状态转移（遍历每天价格 price）：
1. `buy1 = max(buy1, -price)` —— 第一次买入（之前未操作，或更低价买入）
2. `sell1 = max(sell1, buy1 + price)` —— 第一次卖出
3. `buy2 = max(buy2, sell1 - price)` —— 第二次买入（在第一次卖出的基础上）
4. `sell2 = max(sell2, buy2 + price)` —— 第二次卖出

**关键点：**
- 一天可以同时买入和卖出（等同于不操作），所以上述状态更新顺序正确
- 最终返回 `sell2`

时间复杂度：O(n)  
空间复杂度：O(1)
