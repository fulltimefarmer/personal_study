# LeetCode 32. Longest Valid Parentheses（最长有效括号） — **困难**

## 考点
Stack, String, Dynamic Programming

## 题目描述
给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

**示例 1：**
```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

**示例 2：**
```
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

**示例 3：**
```
输入：s = ""
输出：0
```

**提示：**
- `0 <= s.length <= 3 * 10^4`
- `s[i]` 为 `'('` 或 `')'`

## 解题思路

### 核心思路
栈底始终保留"最后一个未匹配右括号的索引"作为有效的**起点基准**，每匹配一对括号就计算从基准到当前位置的长度，动态维护全局最大值。

### 算法步骤

**方法一：栈（推荐）**
1. 初始化栈 `stack = [-1]`（-1 充当虚拟起点）
2. 遍历字符串，索引 `i` 从 `0` 到 `n-1`：
   - 若 `s[i] == '('`：将 `i` 压栈
   - 若 `s[i] == ')'`：
     - 弹出栈顶
     - 若栈为空：将 `i` 压栈（新的无效边界）
     - 若栈非空：`maxLen = max(maxLen, i - stack.top())`
3. 返回 `maxLen`

**方法二：DP**
1. `dp[i]` = 以 `s[i]` 结尾的最长有效括号长度
2. 若 `s[i] == '('`：`dp[i] = 0`
3. 若 `s[i] == ')'`：
   - 若 `s[i-1] == '('`：`dp[i] = dp[i-2] + 2`
   - 若 `s[i-1] == ')'` 且 `s[i-dp[i-1]-1] == '('`：`dp[i] = dp[i-1] + 2 + dp[i-dp[i-1]-2]`

**方法三：双向扫描（贪心）**
1. 从左到右扫描，用 `left`/`right` 计数器，相等时更新长度
2. 从右到左再扫一遍，处理 `((())` 这种左括号多的情况

### 图解示例
输入：`s = ") ( ) ( ) )"`（去掉空格）

```
      索引:  0   1   2   3   4   5
      字符:  )   (   )   (   )   )

栈方法:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
初始: stack = [-1], maxLen = 0

i=0, s[0]=')':
    弹栈→栈空, 压入0→stack=[0]
    maxLen=0  (0-0=0)

i=1, s[1]='(':
    压入1→stack=[0,1]
    stack: [0, 1]
           ↑  ↑

i=2, s[2]=')':
    弹出1→stack=[0]
    栈非空! len = 2 - stack.top() = 2 - 0 = 2
    maxLen = 2 ← 匹配 (1,2)
    索引分布:  )  (  )  ...
              0 [1--2]  有效长度2

i=3, s[3]='(':
    压入3→stack=[0,3]

i=4, s[4]=')':
    弹出3→stack=[0]
    len = 4 - 0 = 4
    maxLen = 4 ← 匹配 (1,2)和(3,4)连续
    索引分布:  )  (  )  (  )  ...
              0 [1--2][3--4]  有效长度4

i=5, s[5]=')':
    弹出0→栈空!
    压入5→stack=[5]  (新的无效边界)
    maxLen = 4

最终: maxLen = 4
```

### 逐步追踪（栈方法）
`s = "( ) ) ( ( ) )"`

| i | s[i] | 操作 | 弹出 | 栈内容 | 栈顶 | 有效长度 | maxLen |
|---|------|------|------|--------|------|---------|--------|
| - | - | 初始 | - | [-1] | -1 | - | 0 |
| 0 | ( | 压入0 | - | [-1, 0] | 0 | - | 0 |
| 1 | ) | 弹出 | 0 | [-1] | -1 | 1-(-1)=2 | 2 |
| 2 | ) | 弹出 | -1 | []→压入2 | 2 | - | 2 |
| 3 | ( | 压入3 | - | [2, 3] | 3 | - | 2 |
| 4 | ( | 压入4 | - | [2, 3, 4] | 4 | - | 2 |
| 5 | ) | 弹出 | 4 | [2, 3] | 3 | 5-3=2 | 2 |
| 6 | ) | 弹出 | 3 | [2] | 2 | 6-2=4 | 4 |

### DP 表格示例
`s = "( ) ) ( )"`

| i | s[i] | dp[i] | 推导 |
|---|------|-------|------|
| 0 | ( | 0 | '(' 结尾不可能有效 |
| 1 | ) | 2 | s[0]='(', dp[1]=dp[-1]+2=0+2=2 |
| 2 | ) | 0 | s[1]≠'(', 无法匹配 |
| 3 | ( | 0 | '(' 结尾 |
| 4 | ) | 2 | s[3]='(', dp[4]=dp[2]+2=0+2=2 |

### 边界情况
| 情况 | 输入 | 输出 | 说明 |
|------|------|------|------|
| 空串 | "" | 0 | 无括号 |
| 全左括号 | "(((" | 0 | 无法闭合 |
| 全右括号 | ")))" | 0 | 无法匹配 |
| 嵌套 | "((()))" | 6 | 全部匹配 |
| 交错 | "()()" | 4 | 连续有效区间 |
| 断开 | "()(()" | 2 | 中间断开 |
