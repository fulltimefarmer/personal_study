# LeetCode 33. Search in Rotated Sorted Array（搜索旋转排序数组） — **中等**

## 考点
Array, Binary Search

## 题目描述
整数数组 `nums` 按升序排列，数组中的值 **互不相同**。

在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 <= k < nums.length`）上进行了 **旋转**，使数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`（下标 **从 0 开始** 计数）。例如，`[0,1,2,4,5,6,7]` 在下标 `3` 处经旋转后可能变为 `[4,5,6,7,0,1,2]`。

给你 **旋转后** 的数组 `nums` 和一个整数 `target`，如果 `nums` 中存在这个目标值 `target`，则返回它的下标，否则返回 `-1`。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**
```
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
```

**示例 2：**
```
输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1
```

**示例 3：**
```
输入：nums = [1], target = 0
输出：-1
```

**提示：**
- `1 <= nums.length <= 5000`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 中的每个值都 **独一无二**
- 题目数据保证 `nums` 在预先未知的某个下标上进行了旋转
- `-10^4 <= target <= 10^4`

## 解题思路

### 核心思路
旋转排序数组**必然有一半是有序的**。二分查找的核心判断：确定 `mid` 落在哪一半，然后在**有序的那一半**中用常规比较判断 target 是否在其中，决定收缩方向。

### 算法步骤
1. 初始化 `left = 0`，`right = n - 1`
2. 循环条件 `left <= right`：
   - 计算 `mid = left + (right - left) / 2`
   - 若 `nums[mid] == target`，返回 `mid`
   - **判断左半有序**：若 `nums[left] <= nums[mid]`
     - 若 `nums[left] <= target < nums[mid]` → `right = mid - 1`
     - 否则 → `left = mid + 1`
   - **否则右半有序**：
     - 若 `nums[mid] < target <= nums[right]` → `left = mid + 1`
     - 否则 → `right = mid - 1`
3. 返回 `-1`

### 逐步追踪
`nums = [4,5,6,7,0,1,2], target = 1`

| 轮次 | left | right | mid | nums[mid] | 哪半有序 | target在有序半? | 操作 |
|------|------|-------|-----|-----------|---------|---------------|------|
| 1 | 0 | 6 | 3 | 7 | 左半[4,7] | 4≤1<7? No | left=4 |
| 2 | 4 | 6 | 5 | 1 | 左半[0,1] | 0≤1≤1? Yes | right=4 |
| 3 | 4 | 4 | 4 | 0 | - | 0≠1 | left=5 |
| - | 5 | 4 | - | - | left>right | - | **返回-1**? |

等等，检查：target=1在索引5。迭代2中mid=5, nums[5]=1==target! 直接返回。

修正追踪：

| 轮次 | left | right | mid | nums[mid] | 判断 | 操作 |
|------|------|-------|-----|-----------|------|------|
| 1 | 0 | 6 | 3 | 7 | 7≠1, 左半有序, 1不在[4,7) | left=4 |
| 2 | 4 | 6 | 5 | 1 | **1==1** | **返回5** ✓ |

### 边界情况
| 情况 | 输入 | target | 输出 | 说明 |
|------|------|--------|------|------|
| 无旋转 | [1,2,3,4,5] | 3 | 2 | 标准二分 |
| 单元素 | [1] | 1 | 0 | 直接命中 |
| 单元素不命中 | [1] | 2 | -1 | 不存在 |
| 旋转点为0 | [1,3,5] | 0 | -1 | 旋转k=0等同未转 |
| 两个元素 | [3,1] | 1 | 1 | 旋转k=1 |

### 复杂度分析
- **时间复杂度**: O(log n)，标准的二分查找，每次迭代区间减半
- **空间复杂度**: O(1)，只使用常数变量

### 关键注意事项
- 用 `nums[left] <= nums[mid]` 判断左半有序（注意 `=` 号，处理 `left == mid` 的情况）
- target 比较要用严格 `<` 或 `<=`，避免边界遗漏
- `mid` 计算用 `left + (right - left) / 2` 防溢出
