# LeetCode 131. Palindrome Partitioning（分割回文串）

## 考点
字符串、动态规划、回溯

## 题目描述
给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是**回文串**。返回 `s` 所有可能的分割方案。

**回文串**是正着读和反着读都一样的字符串。

**示例 1：**
```
输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
```

**示例 2：**
```
输入：s = "a"
输出：[["a"]]
```

**提示：**
- `1 <= s.length <= 16`
- s 仅由小写英文字母组成

## 解题思路
**回溯 + 预计算回文判断。**

**核心步骤：**

1. **预计算回文：** 使用动态规划计算 `isPalindrome[i][j]`，表示 `s[i..j]` 是否为回文串。
   - `isPalindrome[i][j] = s[i] === s[j] && (j - i <= 2 || isPalindrome[i+1][j-1])`

2. **回溯搜索：** 从位置 `start` 开始，遍历所有可能的结束位置 `end`：
   - 如果 `s[start..end]` 是回文串，将其加入当前路径
   - 递归处理 `end + 1` 位置
   - 回溯，移除当前子串

**关键点：**
- 预计算回文将每次判断从 O(n) 降到 O(1)
- 回溯框架标准模板
- 每个分割的子串都必须是回文串

时间复杂度：O(n × 2^n) —— 最坏情况有 2^n 种分割方案，每种方案需要 O(n) 构建  
空间复杂度：O(n²) —— 存储回文判断矩阵 + O(n) 递归栈
