# LeetCode 20. Valid Parentheses（有效的括号）

## 考点
String, Stack

## 题目描述
给定一个只包括 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：
1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

### 示例 1
```
输入：s = "()"
输出：true
```

### 示例 2
```
输入：s = "()[]{}"
输出：true
```

### 示例 3
```
输入：s = "(]"
输出：false
```

### 约束
- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成

## 解题思路

### 方法：栈
核心思想：用栈存储未闭合的左括号。遍历字符串，遇到左括号入栈，遇到右括号检查栈顶是否匹配。

**步骤：**
1. 建立右括号到左括号的映射：`')': '('`, `'}': '{'`, `']': '['`。
2. 遍历字符串：
   - 如果是左括号（不在映射中），入栈。
   - 如果是右括号（在映射中），检查栈顶是否匹配：
     - 栈为空或不匹配则返回 `false`。
     - 匹配则弹出栈顶。
3. 遍历结束后，栈为空返回 `true`，否则返回 `false`。

**关键点：**
- 栈的 LIFO 特性天然适合括号匹配。
- 用映射替代多个 if-else 判断，代码更简洁。
- 最终栈必须为空，所有左括号都被匹配。

时间复杂度：O(n)
空间复杂度：O(n)
