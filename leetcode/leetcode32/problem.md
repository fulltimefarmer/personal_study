# LeetCode 32. Longest Valid Parentheses（最长有效括号）

## 考点
Stack, String, Dynamic Programming

## 题目描述
给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

### 示例 1
```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

### 示例 2
```
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

### 约束
- `0 <= s.length <= 3 * 10^4`
- `s[i]` 为 `'('` 或 `')'`

## 图解

```mermaid
graph TD
    A["初始化 stack = [-1]"] --> B["遍历字符串索引 i"]
    B --> C{"s[i] == '(' ?"}
    C -->|是| D["push(i)<br/>入栈等待匹配"]
    C -->|否 ')'| E["pop()<br/>尝试匹配"]
    E --> F{stack 为空?}
    F -->|是| G["push(i)<br/>当前)作为新基准"]
    F -->|否| H["maxLen = max(maxLen, i - stack.top)"]
    D --> I{i++ done?}
    G --> I
    H --> I
    I -->|否| B
    I -->|是| J[返回 maxLen]
```

> **示例 ")()())"**: i=0 ')' pop后栈空, push(0) → i=1 '(' push(1) → i=2 ')' pop, len=2-0=2 → i=3 '(' push(3) → i=4 ')' pop, len=4-0=4 → i=5 ')' pop后栈空, push(5) → maxLen=4

## 解题思路

### 方法：栈
核心思想：栈底始终存储「最后一个没有被匹配的右括号的下标」，利用下标差计算有效括号长度。

**步骤：**
1. 栈初始化为 `[-1]`（作为参照点）。
2. 遍历字符串，对于索引 `i`：
   - 如果 `s[i] === '('`，`i` 入栈。
   - 如果 `s[i] === ')'`：
     - 弹出栈顶（匹配当前右括号）。
     - 如果栈为空，说明当前右括号没有被匹配，将 `i` 入栈作为新的参照点。
     - 否则，`maxLen = Math.max(maxLen, i - stack[stack.length - 1])`。
3. 返回 `maxLen`。

**关键点：**
- `stack[stack.length - 1]` 是当前有效括号串起始位置的前一个位置。
- 栈的方法比 DP 更直观。
- 初始 `-1` 处理以索引 0 开始的有效括号串。

时间复杂度：O(n)
空间复杂度：O(n)
