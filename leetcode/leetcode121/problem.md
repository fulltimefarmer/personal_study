# LeetCode 121. Best Time to Buy and Sell Stock（买卖股票的最佳时机）

## 考点
数组、动态规划

## 题目描述
给定一个数组 `prices`，它的第 i 个元素 `prices[i]` 表示一支给定股票第 i 天的价格。

你只能选择**某一天**买入这只股票，并选择在**未来的某一个不同的日子**卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0`。

**示例 1：**
```
输入：[7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5。
注意利润不能是 7-1 = 6，因为卖出价格需要大于买入价格。
```

**示例 2：**
```
输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下，没有交易完成，所以最大利润为 0。
```

**提示：**
- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`

## 解题思路
**一次遍历**，动态维护两个变量：
- `minPrice`：到当前天为止的最低股票价格
- `maxProfit`：到当前天为止能获得的最大利润

遍历每一天的价格 `price`：
1. 更新 `minPrice = Math.min(minPrice, price)`
2. 计算如果当天卖出的利润：`price - minPrice`
3. 更新 `maxProfit = Math.max(maxProfit, price - minPrice)`

**关键点：**
- 只能买卖一次，买入必须在卖出之前
- 若价格一直下降，最大利润为 0

时间复杂度：O(n)  
空间复杂度：O(1)
