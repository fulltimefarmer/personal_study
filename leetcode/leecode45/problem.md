# LeetCode 45. Jump Game II（跳跃游戏 II） — **中等**

## 考点
Greedy, Array, Dynamic Programming

## 题目描述
给定一个长度为 `n` 的 **0 索引** 整数数组 `nums`。初始位置为 `nums[0]`。

每个元素 `nums[i]` 表示从索引 `i` 向前跳转的最大长度。换句话说，如果你在 `nums[i]` 处，你可以跳转到任意 `nums[i + j]` 处：

- `0 <= j <= nums[i]`
- `i + j < n`

返回到达 `nums[n - 1]` 的最小跳跃次数。生成的测试用例可以到达 `nums[n - 1]`。

**示例 1：**
```
输入: nums = [2,3,1,1,4]
输出: 2
解释: 跳到最后一个位置的最小跳跃数是 2。从下标为 0 跳到下标为 1 的位置，跳 1 步，然后跳 3 步到达数组的最后一个位置。
```

**示例 2：**
```
输入: nums = [2,3,0,1,4]
输出: 2
```

**提示：**
- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 1000`
- 生成的测试用例可以到达 `nums[n - 1]`

## 解题思路

### 核心思路
贪心 BFS 思想：把跳跃视为"层"。在当前覆盖范围内**一步可达的所有位置**属于同一层（同一次跳跃），一趟扫描找出下一层的最远边界，到达当前层边界时跳跃数+1。

### 算法步骤
1. 初始化：`jumps = 0`, `curEnd = 0`（当前跳跃覆盖的最远边界）, `farthest = 0`（全局能到的最远位置）
2. 遍历 `i` 从 `0` 到 `n-2`（最后一个元素不需要跳）：
   - 更新 `farthest = max(farthest, i + nums[i])`
   - 若 `i == curEnd`（到达当前跳跃层的边界）：
     - `jumps++`
     - `curEnd = farthest`
     - 若 `curEnd >= n-1`，可以提前返回（优化）
3. 返回 `jumps`

### 图解示例
`nums = [2, 3, 1, 1, 4]`

```
数组可视化（每个位置能跳多远）:
    索引:  0   1   2   3   4
    数值:  2   3   1   1   4
           ↓──→
    0:     └────────→  最远到索引2
    1:         └──────────────→  最远到索引4
    2:              └──→  最远到索引3
    3:                   └──→  最远到索引4

分层遍历（BFS思想）:
    ┌──── Jump 0 ────┐
    │                 │
    ▼                 ▼
    0                 1,2     ← 第1跳能到的范围
    [2, 3, 1, 1, 4]
     ↑
    curEnd=0

    ┌─── Jump 1 ──────────┐
    │                     │
    ▼                     ▼
    1,2                   3,4  ← 第2跳能到的范围
    [2, 3, 1, 1, 4]
        ↑     ↑
       farthest=4
       
    到达! (索引4是终点)

详细过程:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

i=0: farthest = max(0, 0+2) = 2
     i(0) == curEnd(0)? ✓ → jumps=1, curEnd=2
     curEnd=2 < n-1=4, 继续

i=1: farthest = max(2, 1+3) = 4
     i(1) != curEnd(2), 继续

i=2: farthest = max(4, 2+1) = 4
     i(2) == curEnd(2)? ✓ → jumps=2, curEnd=4
     curEnd=4 >= n-1=4 → 可提前返回 2 ✓

跳跃路径: 0→1→4 (两步)
```

`nums = [2, 3, 0, 1, 4]`

```
    [2, 3, 0, 1, 4]
     ↓──→
     └────────→ 最远索引2
         └──────────────→ 最远索引4
                ↓ (0步)
                     └──→ 最远索引4

i=0: farthest=2, curEnd=0 → jumps=1, curEnd=2
i=1: farthest=max(2,1+3)=4, i!=curEnd
i=2: farthest=max(4,2+0)=4, i==curEnd → jumps=2, curEnd=4
     到达 → 返回 2 ✓ (0→1→4)
```

### 逐步追踪
`nums = [2, 3, 1, 1, 4]`

| i | nums[i] | i+nums[i] | farthest | curEnd | i==curEnd? | jumps | 操作 |
|---|---------|-----------|----------|--------|------------|-------|------|
| 0 | 2 | 2 | 2 | 0 | ✓ | 0→1 | curEnd=2 |
| 1 | 3 | 4 | 4 | 2 | ✗ | 1 | - |
| 2 | 1 | 3 | 4 | 2 | ✓ | 1→2 | curEnd=4 |
| - | - | - | - | - | curEnd≥4 | 2 | **返回2** ✓ |

`nums = [1, 2, 3]`

| i | nums[i] | i+nums[i] | farthest | curEnd | i==curEnd? | jumps | 操作 |
|---|---------|-----------|----------|--------|------------|-------|------|
| 0 | 1 | 1 | 1 | 0 | ✓ | 0→1 | curEnd=1 |
| 1 | 2 | 3 | 3 | 1 | ✓ | 1→2 | curEnd=3≥2 |
| - | - | - | - | - | curEnd≥2 | 2 | **返回2** ✓ |

路径: 0→1→2 (索引1跳2步到终点)

### 边界情况
| 情况 | 输入 | 输出 | 说明 |
|------|------|------|------|
| 单元素 | [0] | 0 | 已在终点 |
| 一步直达 | [5,0,0,0,0] | 1 | 0→终点一跳 |
| 每步跳1 | [1,1,1,1] | 3 | 只能逐格跳 |
| 中间有0 | [2,4,0,0,1] | 2 | 跳过0区域 |
| 大步跨越 | [10,9,8,...] | 1 | 一步到位 |

### 复杂度分析
- **时间复杂度**: O(n)，一次遍历
- **空间复杂度**: O(1)，只使用三个变量

### 方法对比
| 方法 | 时间复杂度 | 空间复杂度 | 实现难度 | 说明 |
|------|-----------|-----------|---------|------|
| 贪心(BFS) | O(n) | O(1) | 简单 | **推荐** |
| DP | O(n²) | O(n) | 简单 | dp[i]=到达i的最少跳数 |
| BFS(显式) | O(n) | O(n) | 中等 | 用队列模拟，需额外空间 |

### 关键洞察
- **为什么循环到 n-2 而不是 n-1**：因为不需要从最后一个位置起跳
- **为什么 i == curEnd 时要 jumps++**：curEnd 是"当前层"的边界，到达边界说明需要进入下一层（新一次跳跃）
- **贪心正确性证明**：在当前跳跃可达的范围内，选择能跳得最远的位置（即 `farthest`），这样下一跳的覆盖范围最大，是最优策略
