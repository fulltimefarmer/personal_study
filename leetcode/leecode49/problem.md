# LeetCode 49. Group Anagrams（字母异位词分组） — **中等**

## 考点
Array, Hash Table, String, Sorting

## 题目描述
给你一个字符串数组，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。

**字母异位词** 是由重新排列源单词的所有字母得到的一个新单词。

**示例 1：**
```
输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

**示例 2：**
```
输入: strs = [""]
输出: [[""]]
```

**示例 3：**
```
输入: strs = ["a"]
输出: [["a"]]
```

**提示：**
- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

## 解题思路

### 核心思路
字母异位词的**排序结果完全相同**（或字符频率分布相同）。用排序后的字符串作为哈希键分组，相同的键归入同一组。

### 算法步骤

**方法一：排序法（推荐）**
1. 创建 `Map<String, List<String>>`
2. 遍历每个字符串 `str`：
   - 将 `str` 转为字符数组，排序，再拼回字符串得到 `key`
   - `map.get(key).push(str)`（若 key 不存在则先创建空列表）
3. 返回 `map` 的所有 value（即分组结果）

**方法二：字符计数法**
1. 用长度 26 的数组记录每个字母出现次数，拼成字符串作为 key
   - 例如 `"eat"` → `"1,0,0,0,1,0,...,1,..."`（a=1,e=1,t=1）
2. 其他同排序法

### 图解示例
`strs = ["eat", "tea", "tan", "ate", "nat", "bat"]`

```
排序法分组过程:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"eat":
    字符数组: ['e','a','t'] → 排序 → ['a','e','t'] → key="aet"
    map: { "aet": ["eat"] }

"tea":
    排序 → "aet" → 命中! 
    map: { "aet": ["eat", "tea"] }

"tan":
    排序 → "ant"
    map: { "aet": ["eat", "tea"], "ant": ["tan"] }

"ate":
    排序 → "aet" → 命中!
    map: { "aet": ["eat", "tea", "ate"], "ant": ["tan"] }

"nat":
    排序 → "ant" → 命中!
    map: { "aet": ["eat", "tea", "ate"], "ant": ["tan", "nat"] }

"bat":
    排序 → "abt"
    map: { "aet": ["eat", "tea", "ate"], "ant": ["tan", "nat"], "abt": ["bat"] }

结果: [["bat"], ["nat","tan"], ["ate","eat","tea"]]
```

```
字符计数法示意:
    "eat": [a:1,b:0,c:0,d:0,e:1,f:0,...,t:1,...,z:0]
           key = "1#0#0#0#1#0#...#1#...#0" (26个数字用#连接)
    
    "tea": 同样产生 "1#0#0#0#1#0#...#1#...#0" → 匹配"eat"组!
```

### 逐步追踪
`strs = ["eat", "tea", "tan", "ate", "nat", "bat"]`

| str | 原字符串 | 排序后(key) | map 状态 | 操作 |
|-----|---------|------------|---------|------|
| 1 | "eat" | "aet" | {aet:[]} | 创建+加入 |
| 2 | "tea" | "aet" | {aet:[eat,tea]} | 加入已有组 |
| 3 | "tan" | "ant" | {aet:[eat,tea], ant:[tan]} | 创建新组 |
| 4 | "ate" | "aet" | {aet:[eat,tea,ate], ant:[tan]} | 加入已有组 |
| 5 | "nat" | "ant" | {aet:[eat,tea,ate], ant:[tan,nat]} | 加入已有组 |
| 6 | "bat" | "abt" | {aet:[...], ant:[...], abt:[bat]} | 创建新组 |

### 边界情况
| 情况 | 输入 | 输出 | 说明 |
|------|------|------|------|
| 空字符串 | [""] | [[""]] | 空串排序后仍为空串 |
| 单元素 | ["a"] | [["a"]] | 只有一组 |
| 全不同 | ["a","b","c"] | [["a"],["b"],["c"]] | 每组一个 |
| 全相同 | ["abc","abc","abc"] | [["abc","abc","abc"]] | 同一组 |
| 长度不同 | ["a","ab","ba"] | [["a"],["ab","ba"]] | 长度不是判断依据 |

### 复杂度分析
| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 排序法 | O(n × k log k) | O(n × k) |
| 字符计数法 | O(n × k) | O(n × k) |

其中 n = 字符串数量，k = 字符串最大长度。

### 方法对比
| 维度 | 排序法 | 字符计数法 |
|------|--------|-----------|
| 时间复杂度 | O(n·k·log k) | O(n·k) |
| 实现难度 | 极简 | 中等 |
| key 长度 | k（排序后） | 固定长度 |
| k 很大时 | 排序开销大 | 优（线性） |
| k 较小时 | 几乎无差异 | key 构造稍繁琐 |
| 推荐度 | ★★★★★ | ★★★★ |

### 关键技巧
- **排序法**：字符串较短时（如 LeetCode 题中 k≤100），排序开销很小，代码极简
- **字符计数法**：当字符串长度很大时，O(nk) 明显优于 O(nk log k)
- **质数乘积法（不推荐）**：给每个字母分配一个质数，异位词乘积相同。但可能溢出，不实用
- **Map 的 value**：可以直接用 `map.values()` 或 `Array.from(map.values())` 返回结果
