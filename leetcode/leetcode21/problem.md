# LeetCode 21. Merge Two Sorted Lists（合并两个有序链表）

## 考点
Linked List, Recursion

## 题目描述
将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

### 示例 1
```
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

### 约束
- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `l1` 和 `l2` 均按非递减顺序排列

## 解题思路

### 方法一：迭代
核心思想：创建哑节点，比较两个链表当前节点的值，将较小的节点接到结果链表后面。

### 方法二：递归
核心思想：比较两个链表头节点，较小的节点作为当前结果节点，递归处理剩余部分。

**递归步骤：**
1. 如果 `l1` 为空，返回 `l2`；如果 `l2` 为空，返回 `l1`。
2. 如果 `l1.val <= l2.val`：`l1.next = mergeTwoLists(l1.next, l2)`，返回 `l1`。
3. 否则：`l2.next = mergeTwoLists(l1, l2.next)`，返回 `l2`。

**关键点：**
- 递归版本代码简洁优雅。
- 递归深度等于链表长度之和，可能栈溢出（但题目限制长度 ≤ 50，安全）。
- 迭代版本更通用，空间复杂度更低。

时间复杂度：O(m + n)
空间复杂度：O(m + n)（递归），O(1)（迭代）
