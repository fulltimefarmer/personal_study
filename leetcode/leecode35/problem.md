# LeetCode 35. Search Insert Position（搜索插入位置） — **简单**

## 考点
Array, Binary Search

## 题目描述
给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

请必须使用时间复杂度为 `O(log n)` 的算法。

**示例 1：**
```
输入: nums = [1,3,5,6], target = 5
输出: 2
```

**示例 2：**
```
输入: nums = [1,3,5,6], target = 2
输出: 1
```

**示例 3：**
```
输入: nums = [1,3,5,6], target = 7
输出: 4
```

**提示：**
- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 为 **无重复元素** 的 **升序** 排列数组
- `-10^4 <= target <= 10^4`

## 解题思路

### 核心思路
标准的二分查找 "lower bound"：找到第一个 `>= target` 的位置。当 target 存在时就是其索引，不存在时就是插入位置。循环结束后 `left` 指针天然指向这个位置。

### 算法步骤
1. 初始化 `left = 0`, `right = nums.length - 1`
2. 循环 `while (left <= right)`：
   - `mid = left + (right - left) / 2`
   - 若 `nums[mid] == target`：返回 `mid`（找到）
   - 若 `nums[mid] < target`：`left = mid + 1`
   - 若 `nums[mid] > target`：`right = mid - 1`
3. 循环结束，返回 `left`（即插入位置）

### 图解示例
`nums = [1, 3, 5, 6], target = 2`

```
搜索过程:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    索引:  0   1   2   3
    数值:  1   3   5   6

迭1: L=0, R=3, M=1
    [1, 3, 5, 6]
     L  M     R
    nums[1]=3 > target(2) → right = 0

迭2: L=0, R=0, M=0
    [1, 3, 5, 6]
     L/R=M
    nums[0]=1 < target(2) → left = 1

迭3: L=1, R=0 → left > right, 退出
    返回 left = 1 ✓

    插入示意:
    [1, ←, 3, 5, 6]  索引1处插入2
```

`nums = [1, 3, 5, 6], target = 5`

```
迭1: L=0, R=3, M=1
    [1, 3, 5, 6]
     L  M     R
    nums[1]=3 < 5 → left = 2

迭2: L=2, R=3, M=2
    [1, 3, 5, 6]
           L/M R
    nums[2]=5 == 5 → 返回 2 ✓
```

`nums = [1, 3, 5, 6], target = 7`

```
迭1: L=0, R=3, M=1
    nums[1]=3 < 7 → left=2

迭2: L=2, R=3, M=2
    nums[2]=5 < 7 → left=3

迭3: L=3, R=3, M=3
    nums[3]=6 < 7 → left=4

L=4, R=3 → 退出, 返回 4 ✓
插入在数组末尾
```

### 逐步追踪
| target | 轮次 | left | right | mid | nums[mid] | 比较 | 操作 |
|--------|------|------|-------|-----|-----------|------|------|
| 2 | 1 | 0 | 3 | 1 | 3 | 3>2 | right=0 |
| 2 | 2 | 0 | 0 | 0 | 1 | 1<2 | left=1 |
| 2 | - | 1 | 0 | - | - | 退出 | **返回1** |
| 5 | 1 | 0 | 3 | 1 | 3 | 3<5 | left=2 |
| 5 | 2 | 2 | 3 | 2 | 5 | 5==5 | **返回2** |
| 7 | 1 | 0 | 3 | 1 | 3 | 3<7 | left=2 |
| 7 | 2 | 2 | 3 | 2 | 5 | 5<7 | left=3 |
| 7 | 3 | 3 | 3 | 3 | 6 | 6<7 | left=4 |
| 7 | - | 4 | 3 | - | - | 退出 | **返回4** |

### 边界情况
| 情况 | 输入 | target | 输出 | 说明 |
|------|------|--------|------|------|
| 插入最前 | [2,3,4] | 1 | 0 | target 最小 |
| 插入最后 | [2,3,4] | 5 | 3 | target 最大 |
| 插入中间 | [2,3,4] | 3 | 1 | target 存在 |
| 单元素(小) | [5] | 1 | 0 | 插入前面 |
| 单元素(大) | [5] | 9 | 1 | 插入后面 |
| 单元素(等) | [5] | 5 | 0 | 命中 |

### 复杂度分析
- **时间复杂度**: O(log n)，标准二分查找
- **空间复杂度**: O(1)

### 关键洞察
- **为什么返回 `left`**：当 `target` 不存在时，`left` 最终会移动到第一个大于 `target` 的位置（即 `right + 1`），这正是插入位置
- 本质是在求**大于等于 target 的最小下标**（lower bound），这是二分查找最重要的变体之一
- 注意区别：`left <= right`（左闭右闭）配合最终返回 `left`，`left < right`（左闭右开）返回 `left` 也是一样的结果
