# LeetCode 48. Rotate Image（旋转图像） — **中等**

## 考点
Array, Math, Matrix

## 题目描述
给定一个 `n × n` 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在 **原地** 旋转图像，这意味着你需要直接修改输入的二维矩阵。请不要使用另一个矩阵来旋转图像。

**示例 1：**
```
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]
```

**示例 2：**
```
输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

**提示：**
- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 解题思路

### 核心思路
顺时针旋转 90° = **转置（沿主对角线翻转）** + **水平翻转（每行反转）**。两步组合等价于 `matrix[i][j] → matrix[j][n-1-i]`。

### 算法步骤

**方法一：转置 + 行反转**
1. **转置**：`for i in 0..n-1: for j in i+1..n-1: swap(matrix[i][j], matrix[j][i])`
2. **水平翻转**：`for i in 0..n-1: reverse row i (swap matrix[i][j] with matrix[i][n-1-j] for j in 0..n/2-1)`

**方法二：四位置轮换**
1. 分层处理：外层循环 `i` 从 `0` 到 `n/2-1`，内层循环 `j` 从 `i` 到 `n-i-2`
2. 每次旋转四个对应位置的元素：
   - `temp = matrix[i][j]`
   - `matrix[i][j] = matrix[n-1-j][i]`
   - `matrix[n-1-j][i] = matrix[n-1-i][n-1-j]`
   - `matrix[n-1-i][n-1-j] = matrix[j][n-1-i]`
   - `matrix[j][n-1-i] = temp`

### 四位置轮换图解
`matrix = [[1,2,3],[4,5,6],[7,8,9]]` (n=3)

```
分层: 只需处理最外层 i=0 (因为内层只有一个元素 matrix[1][1]=5, 不动)

j=0: 四个角
    matrix[0][0]=1 → matrix[2][0]=7 → matrix[2][2]=9 → matrix[0][2]=3 → matrix[0][0]=1
    角元素: 1→7→9→3→1

    旋转前:         旋转后:
    [1  2  3]       [7  2  1]
    [4  5  6]  →    [4  5  6]
    [7  8  9]       [9  8  3]

j=1: 四条边的中间元素
    matrix[0][1]=2 → matrix[1][0]=4 → matrix[2][1]=8 → matrix[1][2]=6 → matrix[0][1]=2
    
    最终:   [7  4  1]
            [8  5  2]
            [9  6  3]  ✓
```

### 逐步追踪（转置+翻转法）
`matrix = [[1,2,3],[4,5,6],[7,8,9]]`

| 步骤 | 操作 | 矩阵状态 |
|------|------|---------|
| 初始 | - | [[1,2,3],[4,5,6],[7,8,9]] |
| 转置 | swap(0,1)=2↔4 | [[1,4,3],[2,5,6],[7,8,9]] |
| 转置 | swap(0,2)=3↔7 | [[1,4,7],[2,5,6],[3,8,9]] |
| 转置 | swap(1,2)=6↔8 | [[1,4,7],[2,5,8],[3,6,9]] |
| 翻转 | 第0行反转 | [[7,4,1],[2,5,8],[3,6,9]] |
| 翻转 | 第1行反转 | [[7,4,1],[8,5,2],[3,6,9]] |
| 翻转 | 第2行反转 | [[7,4,1],[8,5,2],[9,6,3]] ✓ |

### 边界情况
| 情况 | 输入 | 说明 |
|------|------|------|
| 1×1 | [[1]] | 无需旋转 |
| 2×2 | [[1,2],[3,4]] → [[3,1],[4,2]] | 最小旋转示例 |
| 奇数边 | 3×3, 5×5 | 中心元素不动 |

### 复杂度分析
| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 转置+翻转 | O(n²) | O(1) |
| 四位置轮换 | O(n²) | O(1) |

### 方法对比
| 维度 | 转置+翻转 | 四位置轮换 |
|------|----------|-----------|
| 思路 | 分解为两个简单操作 | 直接一次完成 |
| 实现难度 | 简单 | 中等（易错） |
| 代码量 | 少 | 多 |
| 可读性 | 高 | 中 |
| 推荐度 | ★★★★★ | ★★★ |

### 关键技巧
- **转置**：只遍历 `i < j` 的上三角区域，避免重复交换
- **逆时针 90°**：先转置，再**垂直翻转**（上下行交换）
- **180°**：水平翻转 + 垂直翻转
- **旋转坐标映射**：`(i, j) → (j, n-1-i)` 是顺时针 90° 的单步公式，理解这个就理解了四位置轮换
- **分层理论**：对第 k 层（0-indexed），处理的 j 范围是 `[k, n-k-2]`
