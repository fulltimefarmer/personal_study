# LeetCode 41. First Missing Positive（缺失的第一个正数） — **困难**

## 考点
Array, Hash Table

## 题目描述
给你一个未排序的整数数组 `nums`，请你找出其中没有出现的最小的正整数。

请你实现时间复杂度为 `O(n)` 并且只使用常数级别额外空间的解决方案。

**示例 1：**
```
输入：nums = [1,2,0]
输出：3
解释：范围 [1,2] 中的数字都在数组中。
```

**示例 2：**
```
输入：nums = [3,4,-1,1]
输出：2
解释：1 在数组中，但 2 缺失。
```

**示例 3：**
```
输入：nums = [7,8,9,11,12]
输出：1
解释：最小的正数 1 缺失。
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`

## 解题思路

### 核心思路
答案一定在 `[1, n+1]` 内。将原数组当作**原地哈希表**：把数值 `x`（满足 `1 ≤ x ≤ n`）放到索引 `x-1` 处。最终第一个不满足 `nums[i] == i+1` 的位置即为缺失的最小正整数。

### 算法步骤
1. 第一次遍历，将不在 `[1, n]` 范围内的数设为 `n + 1`（视为无效占位）
2. 第二次遍历，对每个数取绝对值 `x = |nums[i]|`：
   - 若 `x` 在 `[1, n]` 内，将 `nums[x-1]` 标记为负数（表示数字 `x` 出现过）
   - 注意：若 `nums[x-1]` 已经是负数，不重复取反
3. 第三次遍历，找到第一个正数的索引 `i`，返回 `i + 1`
4. 若全为负数，返回 `n + 1`

### 图解示例
`nums = [3, 4, -1, 1]`, n=4

```
Step 1: 把不在 [1,4] 的数替换为 n+1=5
    原数组:  [3, 4, -1, 1]
             3✓  4✓  -1✗  1✓
             
    处理后:  [3, 4, 5, 1]
              ↑  ↑  ↑  ↑
              3  4  ✗  1    (-1→5标记为无效)

Step 2: 用负数标记出现过的数字

    i=0: x=|nums[0]|=|3|=3, 在[1,4]内
         nums[3-1]=nums[2]取负
         [3, 4, -5, 1]
         标记: 数字3出现过
    
    i=1: x=|nums[1]|=|4|=4, 在[1,4]内
         nums[4-1]=nums[3]取负
         [3, 4, -5, -1]
         标记: 数字4出现过

    i=2: x=|nums[2]|=|-5|=5, 不在[1,4]内 → 跳过

    i=3: x=|nums[3]|=|-1|=1, 在[1,4]内
         nums[1-1]=nums[0]取负
         [-3, 4, -5, -1]
         标记: 数字1出现过

Step 3: 找第一个正数
    最终: [-3, 4, -5, -1]
           ↑   ↑  ↑   ↑
         负(-3) 正(4)!
    
    索引1是正数 → 返回 1+1=2 ✓
    
    解读:
      索引0为负 → 1出现了
      索引1为正 → 2缺失! 
      索引2为负 → 3出现了
      索引3为负 → 4出现了
```

`nums = [1, 2, 0]`, n=3

```
Step 1: 替换不在[1,3]的数
    [1, 2, 0] → [1, 2, 4]  (0→4)

Step 2: 标记
    i=0: |1|=1 → nums[0]取负 → [-1, 2, 4]  (1出现)
    i=1: |2|=2 → nums[1]取负 → [-1, -2, 4]  (2出现)
    i=2: |4|=4 不在[1,3] → 跳过

Step 3: 找正数
    [-1, -2, 4]
           ↑ 正数在索引2 → 返回 2+1=3 ✓
    1出现, 2出现, 3缺失!
```

### 逐步追踪
`nums = [7, 8, 9, 11, 12]`, n=5

| 步骤 | 数组状态 | 详细操作 |
|------|---------|---------|
| 初始 | [7, 8, 9, 11, 12] | n=5 |
| Step1 | [7,8,9,11,12] | 所有值>5, 全替换为6: [6,6,6,6,6] |
| Step2 | - | 所有x=6, 不在[1,5], 无标记 |
| Step3 | [6,6,6,6,6] | 索引0是正数 → 返回 **1** ✓ |

### 边界情况
| 情况 | 输入 | 输出 | 说明 |
|------|------|------|------|
| 全为1到n | [1,2,3] | 4 | 返回n+1 |
| 全负数 | [-1,-2,-3] | 1 | 1缺失 |
| 全大于n | [99,100] | 1 | 1缺失 |
| 有零 | [0,2,2,1] | 3 | 零视为无效 |
| 重复元素 | [1,1,1] | 2 | 重复不影响 |
| 单元素 | [1] | 2 | 1存在,2缺失 |
| 单元素 | [2] | 1 | 1缺失 |

### 复杂度分析
- **时间复杂度**: O(n)，三次遍历，每次都是 O(n)
- **空间复杂度**: O(1)，原地操作，不使用额外存储

### 关键技巧
- **为什么范围是 [1, n+1]**：抽屉原理。如果 1~n 都出现了，答案只能是 n+1
- **负数标记**：利用符号位记录"出现过"，不丢失原数据（使用前取绝对值 |x|）
- **为什么需要 Step 1**：将无关数字（≤0 或 >n）统一化，避免访问越界或误标记
- **注意重复取负**：如果 `nums[x-1]` 已经是负数（被之前标记过），不要取反（取反会变成正数）
