# LeetCode 5. Longest Palindromic Substring（最长回文子串）

## 考点
String, Dynamic Programming

## 题目描述
给你一个字符串 `s`，找到 `s` 中最长的回文子串。

如果字符串的反序与原始字符串相同，则该字符串称为回文字符串。

### 示例 1
```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

### 示例 2
```
输入：s = "cbbd"
输出："bb"
```

### 约束
- `1 <= s.length <= 1000`
- `s` 仅由数字和英文字母组成

## 解题思路

### 方法：中心扩展法
核心思想：回文串以某个元素（奇数长度）或某两个元素之间（偶数长度）为中心，向两侧扩展。

**步骤：**
1. 遍历字符串的每个位置作为中心。
2. 对每个中心，分别处理奇数长度和偶数长度的回文：
   - 奇数：以 `i` 为中心，`expandAroundCenter(s, i, i)`
   - 偶数：以 `i` 和 `i+1` 之间为中心，`expandAroundCenter(s, i, i+1)`
3. 扩展函数：当 `left >= 0 && right < n && s[left] === s[right]` 时，向两侧扩展。
4. 记录最长回文的起始位置和长度。
5. 返回最长回文子串。

**关键点：**
- 每个中心扩展的复杂度为 O(n)，总共有 2n-1 个中心。
- 奇数中心 n 个，偶数中心 n-1 个。
- 边扩展边记录最长回文，不需要额外存储。

时间复杂度：O(n²)
空间复杂度：O(1)
