# LeetCode 15. 3Sum（三数之和）

## 考点
Array, Two Pointers, Sorting

## 题目描述
给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。请你返回所有和为 0 且不重复的三元组。

### 示例 1
```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
```

### 示例 2
```
输入：nums = [0,1,1]
输出：[]
```

### 约束
- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## 解题思路

### 方法：排序 + 双指针
核心思想：将数组排序后，固定一个数，然后在剩余部分使用双指针找两数之和等于 `-nums[i]`。

**步骤：**
1. 对数组排序。
2. 遍历数组，固定 `nums[i]`：
   - 如果 `nums[i] > 0`，后面的数都大于 0，不可能和为 0，直接结束。
   - 跳过重复的 `nums[i]`（`i > 0 && nums[i] === nums[i-1]`）。
   - 双指针 `left = i + 1`，`right = n - 1`。
   - 当 `left < right` 时：
     - `sum = nums[i] + nums[left] + nums[right]`
     - `sum === 0`：记录结果，然后跳过重复的 `nums[left]` 和 `nums[right]`。
     - `sum < 0`：`left++`（需要更大的数）。
     - `sum > 0`：`right--`（需要更小的数）。
3. 返回结果。

**关键点：**
- 排序是 O(n log n)，双指针是 O(n²)，总体 O(n²)。
- 去重是关键：固定数去重、左指针去重、右指针去重。
- 剪枝优化：`nums[i] > 0` 时提前结束。

时间复杂度：O(n²)
空间复杂度：O(1)（不计结果存储）
