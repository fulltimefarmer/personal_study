# LeetCode 213. House Robber II（打家劫舍 II） — **中等**

## 考点
数组、动态规划

## 题目描述
你是一个专业的小偷，计划偷窃沿街的房屋，每间房内都藏有一定的现金。这个地方所有的房屋都**围成一圈**，这意味着第一个房屋和最后一个房屋是紧挨着的。同时，相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你**在不触动警报装置的情况下**，今晚能够偷窃到的最高金额。

**示例 1：**
```
输入：nums = [2,3,2]
输出：3
解释：你不能先偷窃 1 号房屋（金额 = 2），然后偷窃 3 号房屋（金额 = 2），因为他们是相邻的。
```

**示例 2：**
```
输入：nums = [1,2,3,1]
输出：4
解释：你可以先偷窃 1 号房屋（金额 = 1），然后偷窃 3 号房屋（金额 = 3）。
     偷窃到的最高金额 = 1 + 3 = 4。
```

**示例 3：**
```
输入：nums = [1,2,3]
输出：3
```

**提示：**
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 1000`

## 解题思路

### 核心思路

房屋首尾相连成环，不能同时偷第一间和最后一间。将环问题拆分为两个线性问题，取两者的最大值：
- 情况1：偷第一间，不偷最后一间 → 范围 `[0, n-2]`
- 情况2：不偷第一间，偷最后一间 → 范围 `[1, n-1]`

然后对每种情况使用 House Robber I 的 DP 解法。

### 算法步骤

1. 若 `n == 1`：返回 `nums[0]`（首尾同一间）
2. 若 `n == 2`：返回 `max(nums[0], nums[1])`
3. 定义 `robRange(start, end)` 辅助函数：
   - `prev2 = nums[start]`
   - `prev1 = max(nums[start], nums[start+1])`
   - 从 `i = start+2` 到 `end`：`curr = max(prev1, prev2 + nums[i])`，滚动
   - 返回 `prev1`
4. 返回 `max(robRange(0, n-2), robRange(1, n-1))`

### 图解示例

**示例 1**: `nums = [2, 3, 2]`

```
圆形房屋布局:
      ┌─────┐
     /  (0)  \
   [2]       [2]
   (0)       (2)
     \  [3]  /
      (1)
      └─────┘

拆分为两个线性问题:

情况1: 偷[0]，不偷[2] → 范围 [2, 3]（索引0~1）
  ┌───┬───┐
  │ 2 │ 3 │  dp: dp[0]=2, dp[1]=max(2,3)=3
  └───┴───┘  结果 = 3

情况2: 不偷[0]，偷[2] → 范围 [3, 2]（索引1~2）
  ┌───┬───┐
  │ 3 │ 2 │  dp: dp[0]=3, dp[1]=max(3,2)=3
  └───┴───┘  结果 = 3

最终: max(3, 3) = 3
方案: 只偷中间(索引1, 金额=3)
```

**示例 2**: `nums = [1, 2, 3, 1]`

```
圆形房屋布局:
      ┌─────────┐
     /   (0)     \
   [1]           [1]
   (0)           (3)
    │     ★      │
    [2]  ────  [3]
    (1)        (2)
     \         /
      └───────┘

拆分:
  情况1 (0~2): [1, 2, 3]

    DP过程:
    i=0: dp[0] = 1
    i=1: dp[1] = max(2, 1) = 2
    i=2: dp[2] = max(dp[1], dp[0]+3) = max(2, 1+3) = 4

    偷[0]和[2]: 1 + 3 = 4

  情况2 (1~3): [2, 3, 1]

    DP过程:
    i=1: dp[0] = 2
    i=2: dp[1] = max(3, 2) = 3
    i=3: dp[2] = max(dp[1], dp[0]+1) = max(3, 2+1) = 3

    只偷[2]: 3

最终: max(4, 3) = 4
方案: 偷索引0(1)和索引2(3) → 1+3=4
验证: 0和2相邻吗? 在环中不相邻(0相邻1和3, 2相邻1和3) ✓
     0和3相邻(首尾)! 但在这个方案中没有同时偷它们 ✓
```

**环形 vs 线性对比：**

```
线性 (House Robber I):        环形 (House Robber II):

[ _  _  _  _ ]               ┌─ _ ─ _ ─ _ ─ _ ─┐
 允许偷首尾                       │                │
                               首尾不能同时偷       │
                                 └──────────────┘
                                 
解法: 一次DP                  解法: 两次DP取max
                                一次 [0~n-2]  一次 [1~n-1]
```

### 逐步追踪表（示例2，n=4）

| 情况 | 范围 | nums子数组 | dp过程 (prev2, prev1) | 结果 |
|------|------|-----------|----------------------|------|
| 1 | [0,2] | [1,2,3] | 1→2→max(2,1+3)=4 | 4 |
| 2 | [1,3] | [2,3,1] | 2→3→max(3,2+1)=3 | 3 |

| i | nums[i] | dp[i]范围1 | dp[i]范围2 |
|---|---------|-----------|-----------|
| 0 | 1 | 1 | — |
| 1 | 2 | 2 | 2 |
| 2 | 3 | 4 | 3 |
| 3 | 1 | — | 3 |

### 边界情况

| 场景 | n | 输入 | 处理 | 结果 |
|------|---|------|------|------|
| 单间房 | 1 | `[5]` | 直接返回 nums[0] | 5 |
| 两间房 | 2 | `[2,3]` | 不能同时偷，取max | 3 |
| 三间房 | 3 | `[1,3,1]` | 情况1:[1,3]→3, 情况2:[3,1]→3 | 3 |
| 全相同 | 4 | `[2,2,2,2]` | 随便隔间偷2+2=4 | 4 |

### 复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| 时间复杂度 | O(n) | 两次线性 DP，每次 O(n) |
| 空间复杂度 | O(1) | 使用滚动变量 |
