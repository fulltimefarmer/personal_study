# LeetCode 26. Remove Duplicates from Sorted Array（删除有序数组中的重复项） — **简单**

## 考点
Array, Two Pointers

## 题目描述
给你一个 **非严格递增排列** 的数组 `nums`，请你 **原地** 删除重复出现的元素，使每个元素 **只出现一次**，返回删除后数组的新长度。元素的 **相对顺序** 应该保持 **一致**。然后返回 `nums` 中唯一元素的个数。

考虑 `nums` 的唯一元素的数量为 `k`，你需要做以下事情确保你的题解可以通过：
- 更改数组 `nums`，使 `nums` 的前 `k` 个元素包含唯一元素，并按照它们最初在 `nums` 中出现的顺序排列。`nums` 的其余元素与 `nums` 的大小不重要。
- 返回 `k`。

**示例 1：**
```
输入：nums = [1,1,2]
输出：2, nums = [1,2,_]
解释：函数应该返回新的长度 2，并且原数组 nums 的前两个元素被修改为 1, 2。不需要考虑数组中超出新长度后面的元素。
```

**示例 2：**
```
输入：nums = [0,0,1,1,1,2,2,3,3,4]
输出：5, nums = [0,1,2,3,4]
解释：函数应该返回新的长度 5，并且原数组 nums 的前五个元素被修改为 0, 1, 2, 3, 4。不需要考虑数组中超出新长度后面的元素。
```

**提示：**
- `1 <= nums.length <= 3 * 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 已按 **非严格递增** 排列

## 解题思路

### 核心思路
利用数组**有序**的特性，快慢双指针原地去重：慢指针 `k` 维护已去重区的末尾，快指针 `i` 扫描寻找下一个不同的元素。

### 算法步骤
1. 初始化慢指针 `k = 0`（已去重区末尾）
2. 快指针 `i` 从 `1` 遍历到 `n-1`
3. 当 `nums[i] != nums[k]` 时：
   - `k++`，扩展去重区
   - `nums[k] = nums[i]`，将新元素放入去重区
4. 返回 `k + 1`（去重区长度）

### 图解示例
输入：`nums = [0,0,1,1,1,2,2,3,3,4]`

```
初始状态:
     k  i
    [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]
     ↑  ↑
   已去重区

Step 1: i=1, nums[1]=0 == nums[k]=0, i++ 跳过
    [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]
     k     i

Step 2: i=2, nums[2]=1 != nums[k]=0
    k++ → k=1, nums[1]=1
    [0, 1, 1, 1, 1, 2, 2, 3, 3, 4]
        k     i

Step 3: i=3, nums[3]=1 == nums[k]=1, 跳过
    [0, 1, 1, 1, 1, 2, 2, 3, 3, 4]
        k        i

Step 4: i=4, nums[4]=1 == nums[k]=1, 跳过
    [0, 1, 1, 1, 1, 2, 2, 3, 3, 4]
        k           i

Step 5: i=5, nums[5]=2 != nums[k]=1
    k++ → k=2, nums[2]=2
    [0, 1, 2, 1, 1, 2, 2, 3, 3, 4]
           k           i

...继续到 i=9
最终: k=4, 返回 k+1=5
    [0, 1, 2, 3, 4, 2, 2, 3, 3, 4]
              k
     ↑---------↑
      去重结果区
```

| 初始 | - | - | 0 | 0 | - | 0 | [0,0,1,1,1,2,2,3,3,4] |
| 1 | 1 | 0 | 0 | 0 | 跳过 | 0 | 无变化 |
| 2 | 2 | 1 | 0 | 0 | k++,赋值 | 1 | [0,1,1,1,1,2,2,3,3,4] |
| 3 | 3 | 1 | 1 | 1 | 跳过 | 1 | 无变化 |
| 4 | 4 | 1 | 1 | 1 | 跳过 | 1 | 无变化 |
| 5 | 5 | 2 | 1 | 1 | k++,赋值 | 2 | [0,1,2,1,1,2,2,3,3,4] |
| 6 | 6 | 2 | 2 | 2 | 跳过 | 2 | 无变化 |
| 7 | 7 | 3 | 2 | 2 | k++,赋值 | 3 | [0,1,2,3,1,2,2,3,3,4] |
| 8 | 8 | 3 | 3 | 3 | 跳过 | 3 | 无变化 |
| 9 | 9 | 4 | 3 | 3 | k++,赋值 | 4 | [0,1,2,3,4,2,2,3,3,4] |

### 边界情况
| 情况 | 输入 | 输出 | 说明 |
|------|------|------|------|
| 单元素 | `[1]` | `1` | 只有一个元素，无重复 |
| 全重复 | `[2,2,2,2]` | `1` | 只保留一个 |
| 无重复 | `[1,2,3,4]` | `4` | 全部保留 |
| 边界值 | `[-100,0,100]` | `3` | 负数也适用 |

### 复杂度分析
- **时间复杂度**: O(n)，每个元素被快指针访问一次
- **空间复杂度**: O(1)，只使用两个指针变量，原地修改

### 方法对比
| 方法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 双指针(快慢指针) | O(n) | O(1) | **推荐**，最优解 |
| Set + 重写 | O(n) | O(n) | 需要额外空间，不满足原地要求 |
| 遍历 + splice | O(n²) | O(1) | 数组移动开销大，不推荐 |
