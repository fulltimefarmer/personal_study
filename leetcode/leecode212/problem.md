# LeetCode 212. Word Search II（单词搜索 II） — **困难**

## 考点
字典树（Trie）、数组、字符串、回溯、矩阵

## 题目描述
给定一个 `m x n` 二维字符网格 `board` 和一个单词（字符串）列表 `words`，找出所有同时在二维网格和字典中出现的单词。

单词必须按照字母顺序，通过**相邻的单元格**内的字母构成，其中"相邻"单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母在一个单词中不允许被重复使用。

**示例 1：**
```
输入：board = [["o","a","a","n"],["e","t","a","e"],["i","h","k","r"],["i","f","l","v"]],
     words = ["oath","pea","eat","rain"]
输出：["eat","oath"]
```

**示例 2：**
```
输入：board = [["a","b"],["c","d"]], words = ["abcb"]
输出：[]
```

**提示：**
- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 12`
- `board[i][j]` 是一个小写英文字母
- `1 <= words.length <= 3 * 10^4`
- `1 <= words[i].length <= 10`
- `words[i]` 由小写英文字母组成
- `words` 中的所有字符串互不相同

## 解题思路

### 核心思路

对每个单词直接 DFS 搜索棋盘会超时。使用 **Trie（字典树）+ 回溯** 优化：将所有单词预插入 Trie，然后对棋盘每个格子进行 DFS 回溯，在搜索路径上同步在 Trie 中匹配。当匹配到 Trie 中的单词节点时，加入结果集。

### 算法步骤

1. 将所有 `words` 插入 Trie 树，每个节点可额外存储完整单词
2. 遍历棋盘每个格子 `(i, j)`：
   - 若 `board[i][j]` 在根节点的子节点中存在，开始 DFS 回溯
3. `backtrack(i, j, node)`：
   - 若 `node.word != null`：将 word 加入结果集，`node.word = null`（去重）
   - 若越界或 `board[i][j]` 不在 node 子节点中：返回
   - 临时保存 `board[i][j]`，标记为 `'#'`（已访问）
   - 递归探索上下左右四个方向
   - 恢复 `board[i][j]`
   - 若 `node` 成为叶子节点（无子节点）：从父节点删除该子节点（剪枝优化）

### 图解示例

**示例**: `board = [["o","a","a","n"],["e","t","a","e"],["i","h","k","r"],["i","f","l","v"]]`, `words = ["oath","pea","eat","rain"]`

```
棋盘 (4×4):
    0   1   2   3
  ┌───┬───┬───┬───┐
0 │ o │ a │ a │ n │
  ├───┼───┼───┼───┤
1 │ e │ t │ a │ e │
  ├───┼───┼───┼───┤
2 │ i │ h │ k │ r │
  ├───┼───┼───┼───┤
3 │ i │ f │ l │ v │
  └───┴───┴───┴───┘

Trie 树结构 (存储4个单词):
        root
       / |  \
      o  p  e  r
      |  |  |  |
      a  e  a  a
      |  |  |  |
      t  a  t  i
      |        |
      h*       n*
    ("oath") ("rain")

搜索过程:
▪ 从 (0,0)='o' 开始:
  Trie中'o'存在, dfs: o
  → (0,1)='a': Trie中o→a存在, dfs: oa
  → (1,1)='t': Trie中oa→t存在, dfs: oat
  → (2,1)='h': Trie中oat→h存在且isEnd!
    → 找到 "oath" ✓, 加入结果

▪ 从 (0,2)='a' 开始:
  'a'在Trie中 (e→a分支)
  → (1,2)='a': e→a→? 'a'不在eat路径中 → 回溯
  → 其他方向也可探索...

▪ 从 (1,0)='e' 开始:
  'e'在Trie中
  → (0,0)已访问/不在路径; (2,0)='i': e→i? 不在 → 回溯
  → (1,1)='t': e→t? 不在 → 回溯
  → (0,1)='a': e→a存在, dfs: ea
    → (0,2)='a': ea→a? 不在 → 回溯
    → (1,2)='a': ea→a? 不在 → 回溯
    → (1,0)已访问
    → (0,0)='o': ea→o? 不在 → 回溯
  → (1,1)继续回溯

▪ 从 (0,3)='n':
  'n'不在root子节点中 → 跳过

▪ 从 (0,1)='a':
  'a'在Trie (o→a分支)
  → 可找到已发现的路径...

▪ 从 (1,3)='e':
  'e'在Trie (e→a→t路径)
  → (0,3)='n': e→n? 不在 → 回溯
  → (2,3)='r': e→r? 不在 → 回溯
  → (1,2)='a': e→a存在, dfs: ea
    → (0,2)='a': ea→a? 不在 → 回溯
    → (2,2)='k': ea→k? 不在 → 回溯
    → (1,1)='t': ea→t存在, dfs: eat且isEnd!
      → 找到 "eat" ✓, 加入结果

搜索结果: ["oath", "eat"]
"pea": p不在root下任何起始位置 → 找不到
"rain": r不在root下任何起始位置 → 找不到
```

**Trie 匹配 + 回溯剪枝示意：**

```
找到 "oath" 的 DFS 路径:

棋盘:              Trie路径:         DFS调用栈:
(0,0)='o'   ───→   root→o          backtrack(0,0, root.children['o'])
  │                    │
(0,1)='a'   ───→       o→a         backtrack(0,1, node.children['a'])
  │                    │
(1,1)='t'   ───→       a→t         backtrack(1,1, node.children['t'])
  │                    │
(2,1)='h'   ───→       t→h (isEnd) backtrack(2,1, node.children['h'])
                         │
                      "oath" 加入结果!
```

### 逐步追踪表

| 起点 | 当前路径 | Trie节点 | isEnd? | 结果 | 下一步探索 |
|------|---------|---------|--------|------|-----------|
| (0,0)='o' | "o" | root→o | No | — | 上下左右 |
| (0,1)='a' | "oa" | o→a | No | — | 上下左右 |
| (1,1)='t' | "oat" | a→t | No | — | 上下左右 |
| (2,1)='h' | "oath" | t→h | **Yes** | +"oath" | 继续探索或回溯 |
| (1,0)='e' | "e" | root→e | No | — | 上下左右 |
| (0,1)='a' | "ea" | e→a | No | — | 上下左右 |
| (1,1)='t' | "eat" | a→t | **Yes** | +"eat" | ... |

### 边界情况与剪枝

| 场景 | 处理 |
|------|------|
| words 为空 | 直接返回 [] |
| 找到单词后的去重 | 将 Trie 节点中的 isEnd 置 false 或 word 置 null |
| 叶子节点剪枝 | 若 node 的 26 个子节点全为空，可安全删除该节点 |
| 重复字符 | 使用 '#' 标记已访问，回溯时恢复 |
| 单词可能重复 | 使用 Set 收集结果（或利用 Trie 去重） |

### 复杂度分析

| 指标 | 理论值 | 说明 |
|------|--------|------|
| 时间复杂度 | O(m × n × 4 × 3^(L-1)) | 棋盘每个格子为起点，每步最多3个方向（刨除来的方向） |
| 空间复杂度 | O(W × L) | Trie 存储所有单词 |
