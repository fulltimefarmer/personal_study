# LeetCode 91. Decode Ways（解码方法） — **中等**

## 考点
String, Dynamic Programming

## 题目描述
一条包含字母 `A-Z` 的消息通过以下映射进行了 **编码**：

```
'A' -> "1"
'B' -> "2"
...
'Z' -> "26"
```

要 **解码** 已编码的消息，所有数字必须基于上述映射的方法，反向映射回字母（可能有多种方法）。

给你一个只含数字的 **非空** 字符串 `s`，请计算并返回 **解码** 方法的 **总数**。

### 示例 1
```
输入：s = "12"
输出：2
解释：它可以解码为 "AB"（1 2）或者 "L"（12）。
```

### 示例 2
```
输入：s = "226"
输出：3
解释：它可以解码为 "BZ" (2 26), "VF" (22 6), 或者 "BBF" (2 2 6) 。
```

### 示例 3
```
输入：s = "06"
输出：0
解释："06" 无法映射到 "F"，因为含有前导零（"6" 和 "06" 不等价）。
```

### 约束
- `1 <= s.length <= 100`
- `s` 只包含数字，并且可能包含前导零

## 解题思路

### 核心思路

这是经典的「爬楼梯」变种 DP 问题。对于位置 `i`，我们有两种方式到达：
- 单独解码当前字符 `s[i-1]`（需要它不是 `'0'`），那么 `dp[i]` 来自 `dp[i-1]`。
- 将当前字符与前一位组合成两位数（需要它在 `[10, 26]` 范围内），那么 `dp[i]` 来自 `dp[i-2]`。

两种方式互不重叠（不同结尾），总数 = 两种方式之和。

### 方法一：动态规划（一维 DP）

**算法步骤：**

1. 如果 `s` 以 `'0'` 开头，直接返回 0（无法解码）。
2. 初始化 `dp = [0] * (n+1)`，`dp[0] = 1`（空串有 1 种解码方式），`dp[1] = 1`。
3. 遍历 `i = 2` 到 `n`：
   - 取一位：`one = int(s[i-1])`，若 `one != 0`：`dp[i] += dp[i-1]`。
   - 取两位：`two = int(s[i-2 : i])`，若 `10 <= two <= 26`：`dp[i] += dp[i-2]`。
4. 返回 `dp[n]`。

**空间优化：** 只需维护 `pre2`（dp[i-2]）、`pre1`（dp[i-1]）、`cur`（dp[i]）三个变量，O(1) 空间。

**图解示例：**

```
s = "226"

字符位置:  s[0]  s[1]  s[2]
            '2'   '2'   '6'

dp[0] = 1  (空串)
dp[1] = 1  (s[0]='2' ≠ '0', 单独解码方案: "B")

i=2, 处理 s[1]='2':
  one = 2 ≠ 0 → dp[2] = dp[1] = 1  (单独: "BB")
  two = int("22") = 22, 10≤22≤26 → dp[2] += dp[0] = 1+1 = 2
  (组合: "V")
  dp[2] = 2, 方案: {"B"+"B", "V"}

i=3, 处理 s[2]='6':
  one = 6 ≠ 0 → dp[3] = dp[2] = 2  (单独: "BB"+"F" 和 "V"+"F")
  two = int("26") = 26, 10≤26≤26 → dp[3] += dp[1] = 2+1 = 3
  (组合: "B"+"Z")
  dp[3] = 3, 方案: {"B"+"B"+"F", "V"+"F", "B"+"Z"}
  即: "BBF", "VF", "BZ"

结果: 3
```

**逐步追踪（以 `s = "12120"` 为例）：**

```
s = "1 2 1 2 0"
i:  0 1 2 3 4

dp[0] = 1
dp[1] = 1 (s[0]='1')

i=2 (s[1]='2'):
  one=2→dp[2]=dp[1]=1
  two=12→dp[2]+=dp[0]=1+1=2
  dp[2]=2

i=3 (s[2]='1'):
  one=1→dp[3]=dp[2]=2
  two=21→dp[3]+=dp[1]=2+1=3
  dp[3]=3

i=4 (s[3]='2'):
  one=2→dp[4]=dp[3]=3
  two=12→dp[4]+=dp[2]=3+2=5
  dp[4]=5

i=5 (s[4]='0'):
  one=0→不贡献 ← 关键: '0'不能单独解码!
  two=20→dp[5]+=dp[3]=5+3=8
  → 必须和前一位组合成"20"(解为T)
  dp[5]=8

结果: 8
```

**边界情况：**

| 情况 | 处理方式 |
|------|---------|
| s 以 '0' 开头 | 直接返回 0（"0" 和 "0x" 都无法解码） |
| s 中有 "00" | 两位数 `two = 0` 不在 [10,26]，两个分支都不贡献 → dp[i]=0 |
| s 中有 "30"~"90" | 一位为 0 不贡献；两位 > 26 不贡献 → dp[i]=0（死胡同） |
| s 长度 1 | dp[1] = 1 if s[0]!='0' else 0 |
| 全部是 "1" | 每个位置两种选择，实际是斐波那契数列 F(n+1) |
| 全部是 "9" | 只能单独解码，dp[i] = 1（每位一种） |

### 方法二：DFS + 记忆化（自顶向下）

从 `s[0]` 开始，每次取 1 位或 2 位，用 memo 缓存结果。

**复杂度分析：**

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP (迭代) | O(n) | O(1) |
| DP (数组) | O(n) | O(n) |
| DFS + 记忆化 | O(n) | O(n) |

**关键点：**

- `'0'` 不能单独解码，必须和前面的 `'1'` 或 `'2'` 配对（如 "10"→J, "20"→T）。
- 两位数范围是 `[10, 26]`，不是 `[1, 26]`——前导零不算有效两位数。
- 递推公式本质上是斐波那契的变体：`dp[i] = (s[i-1]≠0 ? dp[i-1] : 0) + (valid(s[i-2..i-1]) ? dp[i-2] : 0)`。
