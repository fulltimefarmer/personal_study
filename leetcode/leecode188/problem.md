# LeetCode 188. Best Time to Buy and Sell Stock IV（买卖股票的最佳时机 IV） — **困难**

## 考点
数组、动态规划

## 题目描述
给定一个整数数组 `prices`，它的第 `i` 个元素 `prices[i]` 是一支给定股票第 `i` 天的价格，和一个整数 `k`。

设计一个算法来计算你所能获取的最大利润。你最多可以完成 **k** 笔交易。也就是说，你最多可以买 k 次，卖 k 次。

注意：你不能同时参与多笔交易（你必须在再次购买前出售掉之前的股票）。

**示例 1：**
```
输入：k = 2, prices = [2,4,1]
输出：2
解释：在第 1 天（股票价格 = 2）的时候买入，在第 2 天（股票价格 = 4）的时候卖出，这笔交易所能获得利润 = 4 - 2 = 2。
```

**示例 2：**
```
输入：k = 2, prices = [3,2,6,5,0,3]
输出：7
解释：在第 2 天（股票价格 = 2）的时候买入，在第 3 天（股票价格 = 6）的时候卖出，利润 = 6 - 2 = 4。
     随后，在第 5 天（股票价格 = 0）的时候买入，在第 6 天（股票价格 = 3）的时候卖出，利润 = 3 - 0 = 3。
```

**提示：**
- `1 <= k <= 100`
- `1 <= prices.length <= 1000`
- `0 <= prices[i] <= 1000`

## 解题思路

### 核心思路

股票买卖 DP 的泛化版。`dp[i][j]` 表示前 j 天完成最多 i 次交易的最大利润。对于第 j 天，要么不交易，要么作为某次交易的卖出日。维护 `maxPrev` 表示在当天之前完成 i-1 次交易并买入股票的最佳状态。

### 算法步骤

1. 若 `k >= n/2`，退化为无限交易（股票II），累加所有正差价即可
2. 初始化 `dp[k+1][n]`，第一行全为 0（0次交易利润为0）
3. 对每次交易 i (1..k)：
   - `maxPrev = -prices[0]`
   - 对每一天 j (1..n-1)：
     - `dp[i][j] = max(dp[i][j-1], prices[j] + maxPrev)`
     - `maxPrev = max(maxPrev, dp[i-1][j-1] - prices[j])`
4. 返回 `dp[k][n-1]`

### 图解示例

**示例**: `k=2, prices = [3, 2, 6, 5, 0, 3]`

```
价格走势图：
  6 |        ●
  5 |          ●
  4 |
  3 |  ●           ●
  2 |    ●
  1 |
  0 |              ●
    +---+---+---+---+---+
      d0  d1  d2  d3  d4  d5

交易1: 第2天买(2), 第3天卖(6) → 利润 4
交易2: 第5天买(0), 第6天卖(3) → 利润 3
总利润 = 4 + 3 = 7
```

**DP 表构建过程 (2次交易)：**

```
dp[i][j] 表:  i=交易次数, j=天数
初始: dp[0][*] = 0 (0次交易利润为0)

i=1 (最多1次交易):
  maxPrev = -3
  j=1: dp[1][1] = max(0, 2+(-3)) = 0;  maxPrev = max(-3,0-2) = -2
  j=2: dp[1][2] = max(0, 6+(-2)) = 4;  maxPrev = max(-2,0-6) = -2
  j=3: dp[1][3] = max(4, 5+(-2)) = 4;  maxPrev = max(-2,0-5) = -2
  j=4: dp[1][4] = max(4, 0+(-2)) = 4;  maxPrev = max(-2,0-0) = 0
  j=5: dp[1][5] = max(4, 3+0) = 4;    maxPrev = max(0,0-3) = 0

dp表第1行: [0,    0,    4,    4,    4,    4]
            j=0   j=1   j=2   j=3   j=4   j=5

i=2 (最多2次交易):
  maxPrev = -3
  j=1: dp[2][1] = max(0, 2+(-3)) = 0;   maxPrev = max(-3, dp[1][0]-2) = max(-3,0-2) = -2
  j=2: dp[2][2] = max(0, 6+(-2)) = 4;   maxPrev = max(-2, dp[1][1]-6) = max(-2,0-6) = -2
  j=3: dp[2][3] = max(4, 5+(-2)) = 4;   maxPrev = max(-2, dp[1][2]-5) = max(-2,4-5) = -1
  j=4: dp[2][4] = max(4, 0+(-1)) = 4;   maxPrev = max(-1, dp[1][3]-0) = max(-1,4-0) = 4
  j=5: dp[2][5] = max(4, 3+4) = 7;      maxPrev = max(4, dp[1][4]-3) = max(4,4-3) = 4

dp表第2行: [0,    0,    4,    4,    4,    7]
            j=0   j=1   j=2   j=3   j=4   j=5

最终dp表:
  交易次数\天数  j=0  j=1  j=2  j=3  j=4  j=5
  i=0           0    0    0    0    0    0
  i=1           0    0    4    4    4    4
  i=2           0    0    4    4    4    7  ← 答案

答案: dp[2][5] = 7
```

### 逐步追踪表 (i=2 的交易)

| j | prices[j] | dp[1][j-1] | maxPrev(旧) | dp[2][j]计算 | 新maxPrev计算 |
|---|-----------|------------|-------------|-------------|-------------|
| 1 | 2 | 0 | -3 | max(0, 2+(-3)) = 0 | max(-3, 0-2) = -2 |
| 2 | 6 | 0 | -2 | max(0, 6+(-2)) = 4 | max(-2, 0-6) = -2 |
| 3 | 5 | 4 | -2 | max(4, 5+(-2)) = 4 | max(-2, 4-5) = -1 |
| 4 | 0 | 4 | -1 | max(4, 0+(-1)) = 4 | max(-1, 4-0) = 4 |
| 5 | 3 | 4 | 4 | max(4, 3+4) = 7 | max(4, 4-3) = 4 |

### 边界情况

| 场景 | 处理 |
|------|------|
| k=0 | 不能交易，利润为0 |
| k >= n/2 | 退化为无限交易，贪心累加正差价 |
| k=1 | 退化为股票I（一次交易） |
| 价格递减 | 利润始终为0 |
| 价格递增 | n-1次交易利润 = 总涨幅 |

### 复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| 时间复杂度 | O(k × n) | 两层循环 |
| 空间复杂度 | O(k × n) | DP表；可优化为 O(n) 行滚动或 O(k) 列滚动 |
