# LeetCode 22. Generate Parentheses（括号生成）

## 考点
String, Dynamic Programming, Backtracking

## 题目描述
数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的** 括号组合。

### 示例
```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

### 约束
- `1 <= n <= 8`

## 解题思路

### 方法：回溯
核心思想：在构建字符串的过程中，确保左括号数量不超过 n，且右括号数量不超过左括号数量。

**步骤：**
1. 定义回溯函数 `backtrack(open, close, path)`：
   - `open`：已使用的左括号数量。
   - `close`：已使用的右括号数量。
   - `path`：当前构建的字符串。
2. 终止条件：`path.length === 2 * n`，加入结果。
3. 如果 `open < n`，可以添加左括号：`backtrack(open + 1, close, path + '(')`。
4. 如果 `close < open`，可以添加右括号：`backtrack(open, close + 1, path + ')')`。

**关键点：**
- 核心约束：已添加的右括号数不能超过左括号数。
- 回溯的剪枝条件保证了生成的字符串始终有效。
- `n ≤ 8` 保证了解空间不会太大（第 n 个卡特兰数）。

时间复杂度：O(4^n / √n)（卡特兰数）
空间复杂度：O(n)（递归栈深度）
