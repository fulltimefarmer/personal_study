# LeetCode 190. Reverse Bits（颠倒二进制位） — **简单**

## 考点
位运算、分治

## 题目描述
颠倒给定的 32 位无符号整数的二进制位。

**提示：**
- 请注意，在某些语言（如 Java）中，没有无符号整数类型。在这种情况下，输入和输出都将被指定为有符号整数类型，并且不应影响您的实现，因为按二进制表示形式，无论整数是有符号的还是无符号的，其内部的二进制表示形式都是相同的。
- 在 Java 中，编译器使用二进制补码记法来表示有符号整数。因此，在**示例 2** 中，输入表示有符号整数 `-3`，输出表示有符号整数 `-1073741825`。

**示例 1：**
```
输入：n = 00000010100101000001111010011100
输出：964176192 (00111001011110000010100101000000)
解释：输入的二进制串 00000010100101000001111010011100 表示无符号整数 43261596，
     因此返回 964176192，其二进制表示形式为 00111001011110000010100101000000。
```

**示例 2：**
```
输入：n = 11111111111111111111111111111101
输出：3221225471 (10111111111111111111111111111111)
解释：输入的二进制串 11111111111111111111111111111101 表示无符号整数 4294967293，
     因此返回 3221225471，其二进制表示形式为 10111111111111111111111111111111。
```

**提示：**
- 输入是一个长度为 32 的二进制字符串

**进阶：** 如果多次调用这个函数，你将如何优化你的算法？

## 解题思路

### 核心思路

反转 32 位无符号整数的二进制位。两种方法：逐位反转（简单直观），分治法（O(1) 时间内用掩码批量交换）。

### 方法一：逐位反转

#### 算法步骤

1. 初始化 `result = 0`
2. 循环 32 次（i = 0 到 31）：
   - `result = (result << 1) | (n & 1)` — 结果左移，拼上 n 的最低位
   - `n = n >> 1` — n 右移，丢弃已处理的最低位
3. 返回 `result`

#### 图解示例

**示例**: `n = 43261596` (二进制: `00000010100101000001111010011100`)

```
逐位过程（简化为8位示意）：

n = 1011_0100  (8位)
目标: 0010_1101

位位置:  7  6  5  4  3  2  1  0
n值:     1  0  1  1  0  1  0  0

迭代过程:
i=0: bit=n&1=0, result=(0<<1)|0=0, n=0101_1010
i=1: bit=n&1=0, result=(0<<1)|0=0, n=0010_1101
i=2: bit=n&1=1, result=(0<<1)|1=1, n=0001_0110
i=3: bit=n&1=0, result=(1<<1)|0=2, n=0000_1011
i=4: bit=n&1=1, result=(2<<1)|1=5, n=0000_0101
i=5: bit=n&1=1, result=(5<<1)|1=11, n=0000_0010
i=6: bit=n&1=0, result=(11<<1)|0=22, n=0000_0001
i=7: bit=n&1=1, result=(22<<1)|1=45, n=0000_0000

result = 45 = 0010_1101 ✓ (1011_0100 的反转)

result 构建过程示意:
  i=0: result = 0000_0000
  i=1: result = 0000_0000
  i=2: result = 0000_0001
  i=3: result = 0000_0010
  i=4: result = 0000_0101
  i=5: result = 0000_1011
  i=6: result = 0001_0110
  i=7: result = 0010_1101  ← n 的低位变成了 result 的高位
```

### 方法二：分治法（掩码交换）

```
分治法示意图（8位示例）:

原始:   [b7][b6][b5][b4][b3][b2][b1][b0]

Step1: 相邻1位交换 (mask: 0x55555555 = 0101...0101)
        [b6][b7][b4][b5][b2][b3][b0][b1]

Step2: 相邻2位交换 (mask: 0x33333333 = 0011...0011)
        [b4][b5][b6][b7][b0][b1][b2][b3]

Step3: 相邻4位交换 (mask: 0x0F0F0F0F)
        [b0][b1][b2][b3][b4][b5][b6][b7] ← 完成!

32位版:
  n = (n >> 16) | (n << 16)
  n = ((n & 0xFF00FF00) >> 8) | ((n & 0x00FF00FF) << 8)
  n = ((n & 0xF0F0F0F0) >> 4) | ((n & 0x0F0F0F0F) << 4)
  n = ((n & 0xCCCCCCCC) >> 2) | ((n & 0x33333333) << 2)
  n = ((n & 0xAAAAAAAA) >> 1) | ((n & 0x55555555) << 1)
```

### 逐步追踪表（逐位法，32位轮次）

| 轮次 | n (处理前) | n & 1 | result << 1 | result (新) | n >> 1 |
|------|-----------|-------|-------------|-------------|--------|
| 1 | ....11100 | 0 | 0 | 0 | ....01110 |
| 2 | ....01110 | 0 | 0 | 0 | ....00111 |
| ... | ... | ... | ... | ... | ... |
| 32 | 0 or 1 | last bit | ... | final | 0 |

### 边界情况

| 场景 | 输入 | 说明 |
|------|------|------|
| 全0 | 0 | 反转后仍为 0 |
| 全1 | 0xFFFFFFFF | 反转后仍为 0xFFFFFFFF |
| 只有最高位为1 | 0x80000000 | 反转后最低位为1（值为1） |
| 只有最低位为1 | 1 | 反转后最高位为1 (0x80000000) |

### 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 逐位反转 | O(1) | O(1) | 固定32次循环 |
| 分治法 | O(1) | O(1) | 5次位操作，无循环 |
