# LeetCode 119. Pascal's Triangle II（杨辉三角 II）

## 考点
数组、动态规划

## 题目描述
给定一个非负索引 `rowIndex`，返回「杨辉三角」的第 `rowIndex` 行。

在「杨辉三角」中，每个数是它左上方和右上方的数的和。

**示例 1：**
```
输入：rowIndex = 3
输出：[1,3,3,1]
```

**示例 2：**
```
输入：rowIndex = 0
输出：[1]
```

**示例 3：**
```
输入：rowIndex = 1
输出：[1,1]
```

**提示：**
- `0 <= rowIndex <= 33`

**进阶：**
你可以优化你的算法到 `O(rowIndex)` 空间复杂度吗？

## 解题思路
只需要返回第 `rowIndex` 行，不需要存储所有行。使用**滚动数组**优化空间。

**方法一：迭代滚动更新**
- 使用一个长度为 `rowIndex + 1` 的数组
- 倒序更新：`row[j] = row[j] + row[j-1]`（j 从大到小遍历）
- 这样每次使用的 `row[j-1]` 都是上一轮的值

**方法二：数学公式**
杨辉三角第 n 行第 k 个数为组合数 C(n, k)，可通过递推公式计算：
- `row[0] = 1`
- `row[k] = row[k-1] * (n - k + 1) / k`

时间复杂度：O(rowIndex)  
空间复杂度：O(rowIndex)
