# LeetCode 173. Binary Search Tree Iterator（二叉搜索树迭代器） — **中等**

## 考点
栈、树、设计、二叉搜索树、二叉树、迭代器

## 题目描述
实现一个二叉搜索树迭代器类 `BSTIterator`，表示一个按中序遍历二叉搜索树迭代器：
- `BSTIterator(TreeNode root)` 初始化 BSTIterator 类的一个对象。BST 的根节点 `root` 会作为构造函数的一部分给出。指针应初始化为一个不存在于 BST 中的数字，且该数字小于 BST 中的任何元素。
- `boolean hasNext()` 如果向指针右侧遍历存在数字，则返回 `true`；否则返回 `false`。
- `int next()` 将指针向右移动，然后返回指针处的数字。

注意，指针初始化为一个不存在于 BST 中的数字，所以对 `next()` 的首次调用将返回 BST 中的最小元素。

你可以假设 `next()` 调用总是有效的，即当调用 `next()` 时，BST 的中序遍历中至少存在一个下一个数字。

**示例：**
```
输入：
["BSTIterator", "next", "next", "hasNext", "next", "hasNext", "next", "hasNext", "next", "hasNext"]
[[[7, 3, 15, null, null, 9, 20]], [], [], [], [], [], [], [], [], []]
输出：[null, 3, 7, true, 9, true, 15, true, 20, false]
解释：
BSTIterator bSTIterator = new BSTIterator([7, 3, 15, null, null, 9, 20]);
bSTIterator.next();    // 返回 3
bSTIterator.next();    // 返回 7
bSTIterator.hasNext(); // 返回 True
bSTIterator.next();    // 返回 9
bSTIterator.hasNext(); // 返回 True
bSTIterator.next();    // 返回 15
bSTIterator.hasNext(); // 返回 True
bSTIterator.next();    // 返回 20
bSTIterator.hasNext(); // 返回 False
```

**提示：**
- 树中节点的数目在范围 `[1, 10^5]` 内
- `0 <= Node.val <= 10^6`
- 最多调用 `10^5` 次 `hasNext` 和 `next` 操作

**进阶：** 你可以设计一个满足下述条件的解决方案吗？`next()` 和 `hasNext()` 操作均摊时间复杂度为 `O(1)`，并使用 `O(h)` 内存。其中 `h` 是树的高度。

## 解题思路

### 核心思路

BST 中序遍历得到的是升序序列。使用栈模拟递归的中序遍历过程，实现"受控的按需遍历"：每次 `next()` 只返回下一个节点，而非一次性遍历整棵树。栈中保存的是从根到当前子树最左节点的路径。

### 算法步骤

**初始化 `BSTIterator(root)`**：
- 调用 `_leftmostInorder(root)`，将根节点及其所有左子节点依次压栈

**`next()`**：
1. 弹出栈顶节点 `top`（即当前最小值）
2. 若 `top` 有右子树，将右子节点及其所有左子节点压入栈中
3. 返回 `top.val`

**`hasNext()`**：
- 返回 `!stack.isEmpty()`

### 图解示例

**BST 结构**:
```
        7
       / \
      3  15
         / \
        9  20
```

```
中序遍历结果: 3 → 7 → 9 → 15 → 20

初始化后栈的状态:
┌────┐
│  7 │ ← 根节点及其左子节点
│  3 │ ← 最左节点(最小值)
└────┘
stack: [7, 3]  (栈底→栈顶 = 3, 7)

调用 next() 的状态变化:

next() #1: pop 3 → 返回3
  ┌────┐      3 没有右子树，不压新节点
  │  7 │
  └────┘
  stack: [7]

next() #2: pop 7 → 返回7
  ┌────┐      7 有右子树(15)，压入15及其所有左子节点
  │ 15 │      15 → left=9 → 9无左子
  │  9 │
  └────┘
  stack: [15, 9]

next() #3: pop 9 → 返回9
  ┌────┐      9 没有右子树
  │ 15 │
  └────┘
  stack: [15]

next() #4: pop 15 → 返回15
  ┌────┐      15 有右子树(20)，压入20及左子节点
  │ 20 │      20 无左子
  └────┘
  stack: [20]

next() #5: pop 20 → 返回20
  ┌────┐      20 没有右子树
  │    │
  └────┘
  stack: [] → hasNext() 返回 false
```

### 逐步追踪表

| 调用 | 操作前栈 | 弹出节点 | 返回值 | 压入右子树 | 操作后栈 |
|------|---------|---------|--------|-----------|---------|
| init | [] | — | — | [7,3] | [7, 3] |
| next()#1 | [7, 3] | 3 | 3 | 无 | [7] |
| next()#2 | [7] | 7 | 7 | [15,9] | [15, 9] |
| next()#3 | [15, 9] | 9 | 9 | 无 | [15] |
| next()#4 | [15] | 15 | 15 | [20] | [20] |
| next()#5 | [20] | 20 | 20 | 无 | [] |
| hasNext() | [] | — | false | — | [] |

### 方法二：递归拍平

初始化时递归中序遍历将所有节点值存入数组，用索引指针控制迭代。空间 O(n)，不符合进阶要求。

| 方法 | next() 时间 | 空间 |
|------|------------|------|
| 栈模拟 | 均摊 O(1) | O(h) |
| 递归拍平 | O(1) | O(n) |

### 边界情况

| 场景 | 处理 |
|------|------|
| 单节点树 | 栈初始有一个节点，调用next()后栈为空 |
| 退化成链表（只有左子） | 初始化将所有节点一次性压栈 |
| 退化成链表（只有右子） | 每次next()压入右子分支 |
| 空树 | 题目保证非空 |

### 复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| next() 均摊时间 | O(1) | 每个节点最多被压栈和弹栈各一次 |
| hasNext() 时间 | O(1) | 直接检查栈是否为空 |
| 空间复杂度 | O(h) | h 为树高，最坏 O(n)，平均 O(log n) |
