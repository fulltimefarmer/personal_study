# LeetCode 11. Container With Most Water（盛最多水的容器）

## 考点
Array, Two Pointers, Greedy

## 题目描述
给定一个长度为 `n` 的整数数组 `height`。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

### 示例 1
```
输入：[1,8,6,2,5,4,8,3,7]
输出：49
解释：垂直线分别代表数组 [1,8,6,2,5,4,8,3,7]。最大容量为 49（索引 1 和 8，高度 min(8,7)=7，宽度 7，面积 49）。
```

### 约束
- `n == height.length`
- `2 <= n <= 10^5`
- `0 <= height[i] <= 10^4`

## 解题思路

### 方法：双指针
核心思想：容器面积由较短的边和两边的距离决定。初始左右指针指向数组两端，每次移动较短的那一边，尝试获得更大的面积。

**步骤：**
1. 初始化 `left = 0`，`right = n - 1`，`maxArea = 0`。
2. 当 `left < right` 时：
   - 计算当前面积 `area = min(height[left], height[right]) * (right - left)`。
   - 更新 `maxArea = Math.max(maxArea, area)`。
   - 移动较短的一边（如果 `height[left] < height[right]` 则 `left++`，否则 `right--`）。
3. 返回 `maxArea`。

**关键点：**
- 为什么移动较短的边是正确的？因为如果移动较长的边，宽度减少，而高度受限于短边（不会增加），面积只会变小或不变。
- 移动短边虽然宽度减少，但新高度可能更高，有机会得到更大面积。
- 双指针从两端开始保证了最大宽度，逐步缩小宽度，尝试用高度弥补。

时间复杂度：O(n)
空间复杂度：O(1)
