# LeetCode 189. Rotate Array（轮转数组） — **中等**

## 考点
数组、数学、双指针

## 题目描述
给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

**示例 1：**
```
输入：nums = [1,2,3,4,5,6,7], k = 3
输出：[5,6,7,1,2,3,4]
解释：
向右轮转 1 步：[7,1,2,3,4,5,6]
向右轮转 2 步：[6,7,1,2,3,4,5]
向右轮转 3 步：[5,6,7,1,2,3,4]
```

**示例 2：**
```
输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
解释：
向右轮转 1 步：[99,-1,-100,3]
向右轮转 2 步：[3,99,-1,-100]
```

**提示：**
- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

**进阶：**
- 尽可能想出更多的解决方案，至少有 **三种** 不同的方法可以解决这个问题。
- 你可以使用空间复杂度为 `O(1)` 的 **原地** 算法解决这个问题吗？

## 解题思路

### 核心思路

向右轮转 k 位等价于：后 k 个元素移到前面，前 n-k 个元素移到后面。通过三次反转实现原地操作，无需额外数组。

### 方法一：三次反转法（O(1) 空间）

#### 算法步骤

1. `k = k % n`（k 可能大于 n）
2. 反转整个数组：`reverse(0, n-1)`
3. 反转前 k 个元素：`reverse(0, k-1)`
4. 反转后 n-k 个元素：`reverse(k, n-1)`

#### 图解示例

**示例**: `nums = [1, 2, 3, 4, 5, 6, 7]`, `k = 3`

```
原始数组: [1, 2, 3, 4, 5, 6, 7]
           ←—— n=7 ——→
目标结果: [5, 6, 7, 1, 2, 3, 4]
           ←后k=3→ ←—前n-k=4—→

反转过程图解：

Step 1: 反转整个数组 reverse(0, 6)
  原始:    [1, 2, 3, 4, 5, 6, 7]
  操作:     ←──────────────────→
           交换: 1↔7, 2↔6, 3↔5
  结果:    [7, 6, 5, 4, 3, 2, 1]

Step 2: 反转前k=3个 reverse(0, 2)
  当前:    [7, 6, 5 | 4, 3, 2, 1]
  操作:     ←──→
           交换: 7↔5
  结果:    [5, 6, 7 | 4, 3, 2, 1]

Step 3: 反转后n-k=4个 reverse(3, 6)
  当前:    [5, 6, 7 | 4, 3, 2, 1]
  操作:               ←──────→
                     交换: 4↔1, 3↔2
  结果:    [5, 6, 7 | 1, 2, 3, 4] ✓

最终结果与目标一致！ [5, 6, 7, 1, 2, 3, 4]
```

**原理图示**:

```
设数组 = [A段][B段]，A有n-k个，B有k个
目标 = [B段][A段]

reverse(0, n-1):  [A段][B段]  →  [B段^R][A段^R]
reverse(0, k-1):  [B段^R][A段^R] → [B段][A段^R]
reverse(k, n-1):  [B段][A段^R] → [B段][A段]

(R 表示反转)
```

### 逐步追踪表

| 步骤 | 操作 | 数组状态 | 说明 |
|------|------|---------|------|
| 0 | 初始 | [1,2,3,4,5,6,7] | n=7, k=3 |
| 1 | reverse(0,6) | [7,6,5,4,3,2,1] | 整个数组反转 |
| 2 | reverse(0,2) | [5,6,7,4,3,2,1] | 前k个恢复顺序 |
| 3 | reverse(3,6) | [5,6,7,1,2,3,4] | 后n-k个恢复顺序 |

### 方法二：额外数组法

创建新数组，`newArr[(i+k) % n] = nums[i]`，再拷贝回原数组。O(n) 空间。

### 方法三：环状替换法

从位置0开始，将元素放到 `(i+k) % n`，循环直到回到起点。需跟踪替换次数，可能有多轮循环（当 gcd(n,k) > 1 时）。

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 三次反转 | O(n) | O(1) |
| 额外数组 | O(n) | O(n) |
| 环状替换 | O(n) | O(1) |

### 边界情况

| 场景 | 输入 | 处理 |
|------|------|------|
| k = 0 | `[1,2,3]`, k=0 | k%n=0，三次反转抵消，数组不变 |
| k = n | `[1,2,3]`, k=3 | k%n=0，同上 |
| k > n | `[1,2,3]`, k=4 | k%n=1，相当于右移1位 |
| 单元素 | `[1]`, k=5 | k%1=0，不变 |
| 两元素 | `[1,2]`, k=1 | 反转为[2,1] |

### 复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| 时间复杂度 | O(n) | 三次反转，每次 O(n) |
| 空间复杂度 | O(1) | 原地操作，仅用常数变量 |
