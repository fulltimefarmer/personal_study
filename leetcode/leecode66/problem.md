# LeetCode 66. Plus One（加一） — **简单**

## 考点
Array, Math

## 题目描述
给定一个由 **整数** 组成的 **非空** 数组所表示的非负整数，在该数的基础上加一。

最高位数字存放在数组的首位，数组中每个元素只存储单个数字。

你可以假设除了整数 0 之外，这个整数不会以零开头。

### 示例 1
```
输入：digits = [1,2,3]
输出：[1,2,4]
解释：输入数组表示数字 123，加一得到 124。
```

### 示例 2
```
输入：digits = [4,3,2,1]
输出：[4,3,2,2]
解释：4321 + 1 = 4322
```

### 示例 3
```
输入：digits = [9]
输出：[1,0]
解释：9 + 1 = 10
```

### 约束
- `1 <= digits.length <= 100`
- `0 <= digits[i] <= 9`
- `digits` 不包含前导 0

## 解题思路

### 核心思路
从最低位（数组末尾）开始模拟加一操作。如果当前位小于 9，加一后直接返回（无需进位）。如果是 9，则置零并向前进位。最坏情况：所有位都是 9，需要新建一个长度 +1 的数组。

**关键洞察：** 只有数字 9 才会产生进位。遇到非 9 的数字，加一后立即结束，后面的位无需处理。

### 算法步骤

1. 从 i = digits.length - 1 开始向前遍历
2. 如果 digits[i] < 9：
   - digits[i] += 1
   - 立即返回 digits（无进位传播）
3. 否则 digits[i] == 9：
   - digits[i] = 0（进位）
   - 继续循环
4. 如果循环结束仍未返回（所有位都是 9）：
   - 创建新数组 result，长度为 n + 1
   - result[0] = 1，其余为 0
   - 返回 result

### 图解示例

**例子 1：digits = [1, 2, 3]（无进位）**

```
   ［1］［2］［3］
            ↑
           i=2

digits[2]=3 < 9 → 3+1=4, 直接返回 [1,2,4]

   ［1］［2］［4］ ✓
```

**例子 2：digits = [1, 2, 9]（部分进位）**

```
   ［1］［2］［9］
            ↑
           i=2

Step 1: i=2, digits[2]=9 → 置0 (进位!)
   ［1］［2］［0］
        ↑
       i=1

Step 2: i=1, digits[1]=2 < 9 → 2+1=3, 返回!
   ［1］［3］［0］ ✓
```

**例子 3：digits = [9, 9, 9]（全进位）**

```
   ［9］［9］［9］
            ↑
           i=2

Step 1: i=2, digits[2]=9 → 0
   ［9］［9］［0］
        ↑
       i=1

Step 2: i=1, digits[1]=9 → 0
   ［9］［0］［0］
    ↑
   i=0

Step 3: i=0, digits[0]=9 → 0
   ［0］［0］［0］
   (循环结束，未返回)

Step 4: 所有位都是9 → 创建新数组
   ［1］［0］［0］［0］  ← 等价于 999+1=1000
```

### 逐步追踪

| 输入 | 步骤 | i | digits[i] 初值 | 操作 | 数组状态 | 返回 |
|------|------|---|---------------|------|----------|------|
| [1,2,3] | 1 | 2 | 3 | 3<9, +=1 | [1,2,4] | ✓ |
| [1,2,9] | 1 | 2 | 9 | =9, 置0 | [1,2,0] | - |
| | 2 | 1 | 2 | 2<9, +=1 | [1,3,0] | ✓ |
| [9,9,9] | 1 | 2 | 9 | =9, 置0 | [9,9,0] | - |
| | 2 | 1 | 9 | =9, 置0 | [9,0,0] | - |
| | 3 | 0 | 9 | =9, 置0 | [0,0,0] | - |
| | 4 | - | - | 新建数组 | [1,0,0,0] | ✓ |
| [8,9,9] | 1 | 2 | 9 | =9, 置0 | [8,9,0] | - |
| | 2 | 1 | 9 | =9, 置0 | [8,0,0] | - |
| | 3 | 0 | 8 | 8<9, +=1 | [9,0,0] | ✓ |

### 边界情况

| 情况 | 输入 | 处理 | 结果 |
|------|------|------|------|
| 无进位 | [1,2,3] | 末尾加 1 直接返回 | [1,2,4] |
| 中间进位 | [1,9,9] | 进位传播到第一个非 9 位 | [2,0,0] |
| 全 9 | [9,9,9] | 所有位置零，新建数组 | [1,0,0,0] |
| 单元素 9 | [9] | 置零后新建 | [1,0] |
| 单元素非 9 | [5] | 直接加 1 | [6] |
| 大数组 | [0] (前导0只在0本身上合法) | 直接加 1 | [1] |

### 复杂度分析

- **时间复杂度：** O(n)，最坏情况遍历所有位（全 9 时）
- **空间复杂度：** O(1) 平均情况（原地修改）；O(n) 最坏情况（全 9 需要新建数组）
- 这是模拟整数加法的标准做法，避免大数溢出
