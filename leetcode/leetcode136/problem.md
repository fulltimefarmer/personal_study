# LeetCode 136. Single Number（只出现一次的数字）

## 考点
位运算、数组

## 题目描述
给你一个**非空**整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

**示例 1：**
```
输入：nums = [2,2,1]
输出：1
```

**示例 2：**
```
输入：nums = [4,1,2,1,2]
输出：4
```

**示例 3：**
```
输入：nums = [1]
输出：1
```

**提示：**
- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- 除了某个元素只出现一次以外，其余每个元素均出现两次

## 解题思路
**异或运算（XOR）。**

异或运算的关键性质：
1. `a ⊕ a = 0`（任何数与自身异或得 0）
2. `a ⊕ 0 = a`（任何数与 0 异或得自身）
3. 满足交换律和结合律

**算法：**
初始化 `result = 0`，遍历数组中每个元素，执行 `result ^= num`。

由于出现两次的数互相抵消（异或得 0），最终剩下的就是只出现一次的数。

**举例：**
`[4,1,2,1,2]` → `4 ⊕ 1 ⊕ 2 ⊕ 1 ⊕ 2` = `4 ⊕ (1 ⊕ 1) ⊕ (2 ⊕ 2)` = `4 ⊕ 0 ⊕ 0` = `4`

时间复杂度：O(n)  
空间复杂度：O(1)
