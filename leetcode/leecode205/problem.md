# LeetCode 205. Isomorphic Strings（同构字符串） — **简单**

## 考点
哈希表、字符串

## 题目描述
给定两个字符串 `s` 和 `t`，判断它们是否是同构的。

如果 `s` 中的字符可以按某种映射关系替换得到 `t`，那么这两个字符串是同构的。

每个出现的字符都应当映射到另一个字符，同时不改变字符的顺序。不同字符不能映射到同一个字符上，相同字符只能映射到同一个字符上，字符可以映射到自己本身。

**示例 1：**
```
输入：s = "egg", t = "add"
输出：true
```

**示例 2：**
```
输入：s = "foo", t = "bar"
输出：false
```

**示例 3：**
```
输入：s = "paper", t = "title"
输出：true
```

**提示：**
- `1 <= s.length <= 5 * 10^4`
- `t.length == s.length`
- `s` 和 `t` 由任意有效的 ASCII 字符组成

## 解题思路

### 核心思路

同构字符串要求建立 s→t 的双射（一一映射）。即每个 s[i] 唯一映射到某个 t[i]，且每个 t[i] 也只能被一个 s[i] 映射。使用两个映射表（或两个长度为 256 的数组）维护双向映射关系。

### 算法步骤

1. 初始化两个哈希表/数组 `mapST` 和 `mapTS`（大小 256 对应 ASCII）
2. 遍历 i = 0 到 n-1：
   - 若 `mapST[s[i]]` 已存在且不等于 `t[i]`：返回 false
   - 若 `mapTS[t[i]]` 已存在且不等于 `s[i]`：返回 false
   - `mapST[s[i]] = t[i]`, `mapTS[t[i]] = s[i]`
3. 返回 true

### 图解示例

**示例 1**: `s = "egg"`, `t = "add"` (同构)

```
映射关系建立过程:

i=0: s[0]='e', t[0]='a'
  mapST: e → a      mapTS: a → e
  [e] → [a]  ✓

i=1: s[1]='g', t[1]='d'
  mapST: g → d      mapTS: d → g
  [g] → [d]  ✓

i=2: s[2]='g', t[2]='d'
  检查 mapST['g'] = 'd' == t[2] ✓
  检查 mapTS['d'] = 'g' == s[2] ✓
  一致，继续

最终映射:
  s:  e → g → g
      ↓   ↓   ↓
  t:  a → d → d
  映射关系: e→a, g→d
  返回 true
```

**示例 2**: `s = "foo"`, `t = "bar"` (非同构)

```
i=0: s[0]='f', t[0]='b'
  mapST: f → b      mapTS: b → f  ✓

i=1: s[1]='o', t[1]='a'
  mapST: o → a      mapTS: a → o  ✓

i=2: s[2]='o', t[2]='r'
  检查 mapST['o'] = 'a' ≠ 'r'
  ✗ 失败! 因为 'o' 被要求映射到 'r'，
  但之前已映射到 'a'
  返回 false

映射冲突示意:
  s:  f → o → o
      ↓   ↓   ✗
  t:  b → a → r
  映射: f→b ✓, o→a ✓, o→r ✗ (冲突!)
```

**一个字符映射到两个的情况：**

```
s = "ab", t = "aa"  → 非同构

i=0: a→a ✓
i=1: 检查mapTS['a']='a' == s[1]='b'?  ✗
     'a' 已被 s[0]='a' 映射到，不能再被 'b' 映射
     返回 false
```

### 逐步追踪表（示例1）

| i | s[i] | t[i] | mapST 检查 | mapTS 检查 | mapST 更新 | mapTS 更新 |
|---|------|------|-----------|-----------|-----------|-----------|
| 0 | 'e' | 'a' | e→无 | a→无 | e→a | a→e |
| 1 | 'g' | 'd' | g→无 | d→无 | g→d | d→g |
| 2 | 'g' | 'd' | g→d=d ✓ | d→g=g ✓ | 不变 | 不变 |

### 边界情况

| 场景 | 输入 | 结果 | 说明 |
|------|------|------|------|
| 空字符串 | s="", t="" | true | 题目保证至少1字符 |
| 自己映射自己 | s="abc", t="abc" | true | a→a, b→b, c→c |
| 交叉映射 | s="ab", t="ba" | true | a→b, b→a 合法双射 |
| 多对一 | s="ab", t="aa" | false | 'a' 被两个字符映射 |
| 一对多 | s="aa", t="ab" | false | 'a' 映射到两个字符 |

### 复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| 时间复杂度 | O(n) | 一次遍历 |
| 空间复杂度 | O(1) | 字符集大小固定（ASCII 256） |
