# LeetCode 122. Best Time to Buy and Sell Stock II（买卖股票的最佳时机 II）

## 考点
贪心、数组、动态规划

## 题目描述
给你一个整数数组 `prices`，其中 `prices[i]` 表示某支股票第 i 天的价格。

在每一天，你可以决定是否购买和/或出售股票。你在任何时候**最多只能持有一股**股票。你也可以先购买，然后在**同一天**出售。

返回你能获得的**最大利润**。

**示例 1：**
```
输入：prices = [7,1,5,3,6,4]
输出：7
解释：第 2 天买入（价格 1），第 3 天卖出（价格 5），利润 4。
     第 4 天买入（价格 3），第 5 天卖出（价格 6），利润 3。
     总利润 = 4 + 3 = 7。
```

**示例 2：**
```
输入：prices = [1,2,3,4,5]
输出：4
解释：第 1 天买入，第 5 天卖出，利润 4。
```

**示例 3：**
```
输入：prices = [7,6,4,3,1]
输出：0
```

**提示：**
- `1 <= prices.length <= 3 * 10^4`
- `0 <= prices[i] <= 10^4`

## 解题思路
**贪心策略：** 只要今天的价格比昨天高，就进行买卖（昨天买、今天卖）。

可以交易无限次，因此所有的上涨区间都可以捕捉到。对于任意价格上升区间 `[i, j]`，`prices[j] - prices[i] = (prices[i+1] - prices[i]) + ... + (prices[j] - prices[j-1])`，即区间总利润等于每一步利润之和。

**算法：**
1. 初始化 `maxProfit = 0`
2. 遍历 `prices`，对于第 i 天（i ≥ 1）：
   - 如果 `prices[i] > prices[i-1]`，说明可以获利，累加差值

**也可以用动态规划：**
- `dp[i][0]`：第 i 天不持有股票的最大利润
- `dp[i][1]`：第 i 天持有股票的最大利润
- 状态转移：
  - `dp[i][0] = max(dp[i-1][0], dp[i-1][1] + prices[i])`
  - `dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])`

时间复杂度：O(n)  
空间复杂度：O(1)
