# LeetCode 210. Course Schedule II（课程表 II） — **中等**

## 考点
深度优先搜索、广度优先搜索、图、拓扑排序

## 题目描述
现在你总共有 `numCourses` 门课需要选，记为 `0` 到 `numCourses - 1`。给你一个数组 `prerequisites`，其中 `prerequisites[i] = [ai, bi]`，表示在选修课程 `ai` 前**必须**先选修 `bi`。

- 例如，想要学习课程 `0`，你需要先完成课程 `1`，我们用一个匹配来表示：`[0,1]`。

返回你为了学完所有课程所安排的学习顺序。可能会有多个正确的顺序，你只要返回**任意一种**就可以了。如果不可能完成所有课程，返回**一个空数组**。

**示例 1：**
```
输入：numCourses = 2, prerequisites = [[1,0]]
输出：[0,1]
解释：总共有 2 门课程。要学习课程 1，你需要先完成课程 0。因此，正确的课程顺序为 [0,1]。
```

**示例 2：**
```
输入：numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
输出：[0,1,2,3] or [0,2,1,3]
解释：总共有 4 门课程。要学习课程 3，你应该先完成课程 1 和课程 2。并且课程 1 和课程 2 都应该排在课程 0 之后。
     因此，一个正确的课程顺序是 [0,1,2,3]。另一个正确的排序是 [0,2,1,3]。
```

**示例 3：**
```
输入：numCourses = 1, prerequisites = []
输出：[0]
```

**提示：**
- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= numCourses * (numCourses - 1)`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < numCourses`
- `ai != bi`
- 所有 `[ai, bi]` 互不相同

## 解题思路

### 核心思路

与 207 题相同的问题框架，但需要返回具体的拓扑排序结果序列。使用 Kahn 算法（BFS 入度法）可以自然地按拓扑顺序输出，或使用 DFS 后序遍历逆序。

### 方法一：BFS — Kahn 算法

#### 算法步骤

1. 构建邻接表 `graph`（先修→后续）和入度数组 `indegree`
2. 将所有入度为 0 的节点入队
3. 初始化结果数组 `order = []`
4. 当队列非空时：
   - 出队节点 `u`，加入 `order`
   - 遍历 u 的所有邻居 v：`indegree[v]--`，若变为 0 则入队
5. 若 `order.length == numCourses` → 返回 `order`；否则返回 `[]`（有环）

### 方法二：DFS 后序遍历

对每个未访问节点 DFS，完成后将节点加入结果列表，最后反转列表。DFS 过程中检测环。

### 图解示例

**示例 2**: `numCourses=4, prerequisites=[[1,0],[2,0],[3,1],[3,2]]`

```
课程依赖关系图:
          0
        /   \
       ↓     ↓
       1     2
        \   /
         ↓ ↓
          3

邻接表:
  0: [1, 2]
  1: [3]
  2: [3]
  3: []

入度数组:
  课程:  0  1  2  3
  入度:  0  1  1  2

BFS拓扑排序过程:

初始: 入度[0,1,1,2], 入度0的有: [0]
  queue = [0]

step1: pop 0 → order=[0]
  邻居1入度 1→0 → 入队
  邻居2入度 1→0 → 入队
  queue = [1, 2]

step2: pop 1 → order=[0, 1]
  邻居3入度 2→1
  queue = [2]

step3: pop 2 → order=[0, 2, 1]
  邻居3入度 1→0 → 入队
  queue = [3]

step4: pop 3 → order=[0, 2, 1, 3]
  queue = []

order.length=4 == numCourses=4 → 返回 [0, 1, 2, 3] 或 [0, 2, 1, 3]

拓扑顺序图:
  可行的课程顺序（多条路径）:
  
  路径1: 0→1→2→3
  路径2: 0→2→1→3  ← 两种都是合法的
  
  依赖关系保证:
  - 0 在 1 和 2 之前 ✓
  - 1 在 3 之前 ✓
  - 2 在 3 之前 ✓
```

**DFS 后序遍历相同例子：**

```
DFS从0开始:
  dfs(0): [未访问→正在访问]
    dfs(1): [未访问→正在访问]
      dfs(3): [未访问→正在访问→已完成]
      → 加入3
    → 加入1
    dfs(2): [未访问→正在访问]
      dfs(3): 已完成, 跳过
    → 加入2
  → 加入0
  
  后序结果: [3, 1, 2, 0]
  反转: [0, 2, 1, 3] ✓
```

### 逐步追踪表（BFS）

| 步骤 | 队列 | 出队 | order | 更新的邻居 | 新入度为0 | 入队 | 更新后队列 |
|------|------|------|-------|-----------|----------|------|-----------|
| 0 | [0] | — | [] | — | — | — | [0] |
| 1 | [0] | 0 | [0] | 1, 2 | 1(1→0), 2(1→0) | 1, 2 | [1, 2] |
| 2 | [1, 2] | 1 | [0,1] | 3 | 3(2→1) | — | [2] |
| 3 | [2] | 2 | [0,1,2] | 3 | 3(1→0) | 3 | [3] |
| 4 | [3] | 3 | [0,1,2,3] | — | — | — | [] |

### 有环情况示例

```
prerequisites=[[0,1],[1,0]]:
  
  邻接表: 0:[], 1:[0]... 不对
  实际上: 0→1, 1→0
  
  入度: [1, 1]  无入度为0的节点!
  queue=[], order=[]
  order.length=0 ≠ 2 → 返回 []
```

### 边界情况

| 场景 | 处理 |
|------|------|
| 无先修课 | 任意顺序均可，如 [0,1,2,...,n-1] |
| 孤立节点 | 入度为0，正常排入 |
| 有环 | 返回空数组 |
| 单门课 | `prerequisites=[]`，返回 `[0]` |

### 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| BFS (Kahn) | O(V + E) | O(V + E) |
| DFS | O(V + E) | O(V + E) |
