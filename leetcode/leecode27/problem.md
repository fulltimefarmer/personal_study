# LeetCode 27. Remove Element（移除元素） — **简单**

## 考点
Array, Two Pointers

## 题目描述
给你一个数组 `nums` 和一个值 `val`，你需要 **原地** 移除所有数值等于 `val` 的元素，并返回移除后数组的新长度。

元素的顺序可以改变。你不需要考虑数组中超出新长度后面的元素。

**示例 1：**
```
输入：nums = [3,2,2,3], val = 3
输出：2, nums = [2,2,_,_]
解释：你的函数应该返回 k = 2, 并且 nums 中的前两个元素均为 2。你在返回的 k 个元素之外留下了什么并不重要。
```

**示例 2：**
```
输入：nums = [0,1,2,2,3,0,4,2], val = 2
输出：5, nums = [0,1,4,0,3,_,_,_]
解释：你的函数应该返回 k = 5，并且 nums 中的前五个元素为 0,0,1,3,4。
注意这五个元素可以任意顺序返回。
```

**提示：**
- `0 <= nums.length <= 100`
- `0 <= nums[i] <= 50`
- `0 <= val <= 100`

## 解题思路

### 核心思路
快慢指针分离：慢指针 `k` 记录"有效区"的写入位置，快指针 `i` 扫描跳过目标值，将有效元素前移覆盖。

### 算法步骤
1. 初始化慢指针 `k = 0`（指向下一个有效元素应放置的位置）
2. 快指针 `i` 从 `0` 遍历到 `n-1`
3. 当 `nums[i] != val` 时：
   - `nums[k] = nums[i]`（将有效元素搬到前面）
   - `k++`
4. 返回 `k`（有效区长度）

### 图解示例
输入：`nums = [3,2,2,3], val = 3`

```
初始状态:
     k,i
    [3, 2, 2, 3]

Step 1: i=0, nums[0]=3 == val, i++ (跳过)
     k  i
    [3, 2, 2, 3]

Step 2: i=1, nums[1]=2 != val
    nums[k]=nums[i] → nums[0]=2, k++
        k  i
    [2, 2, 2, 3]

Step 3: i=2, nums[2]=2 != val
    nums[k]=nums[i] → nums[1]=2, k++
           k  i
    [2, 2, 2, 3]

Step 4: i=3, nums[3]=3 == val, i++ (跳过)
           k     i(越界)
    [2, 2, 2, 3]

最终: k=2, 有效区 [2,2]
```

### 逐步追踪
| 步骤 | i | nums[i] | val | 操作 | k (操作前) | 操作 | k (操作后) | 数组变化 |
|------|---|---------|-----|------|-----------|------|-----------|---------|
| 初始 | - | - | 3 | - | 0 | - | 0 | [3,2,2,3] |
| 1 | 0 | 3 | 3 | nums[0]==val, 跳过 | 0 | 无 | 0 | 无变化 |
| 2 | 1 | 2 | 3 | nums[0]=2, k++ | 0 | 赋值 | 1 | [2,2,2,3] |
| 3 | 2 | 2 | 3 | nums[1]=2, k++ | 1 | 赋值 | 2 | [2,2,2,3] |
| 4 | 3 | 3 | 3 | nums[3]==val, 跳过 | 2 | 无 | 2 | 无变化 |

### 边界情况
| 情况 | 输入 | val | 输出 | 说明 |
|------|------|-----|------|------|
| 空数组 | `[]` | 0 | `0` | 直接返回0 |
| 全为目标值 | `[2,2,2]` | 2 | `0` | 全部移除 |
| 无目标值 | `[1,2,3]` | 5 | `3` | 全部保留 |
| 单元素命中 | `[1]` | 1 | `0` | 移除唯一元素 |

### 复杂度分析
- **时间复杂度**: O(n)，每个元素被快指针访问一次
- **空间复杂度**: O(1)，只使用两个指针变量

### 方法对比
| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 快慢指针 | O(n) | O(1) | 原地，保持相对顺序 | - |
| 双端指针(首尾交换) | O(n) | O(1) | 减少赋值次数(元素少时) | 打乱顺序 |
