# LeetCode 172. Factorial Trailing Zeroes（阶乘后的零） — **中等**

## 考点
数学

## 题目描述
给定一个整数 `n`，返回 `n!`（n 的阶乘）结果中尾随零的数量。

**示例 1：**
```
输入：n = 3
输出：0
解释：3! = 6，不含尾随零。
```

**示例 2：**
```
输入：n = 5
输出：1
解释：5! = 120，有一个尾随零。
```

**示例 3：**
```
输入：n = 0
输出：0
```

**提示：**
- `0 <= n <= 10^4`

**进阶：** 你能设计出对数时间复杂度的解法吗？

## 解题思路

### 核心思路

n! 中尾随零的数量取决于因子中 2×5=10 的个数。在阶乘展开中，因子 2 的数量总是远多于因子 5，因此尾随零的数量由因子 5 的个数决定。累加 `n/5 + n/25 + n/125 + ...` 即可得到答案。

### 算法步骤

1. 初始化 `count = 0`
2. 当 `n >= 5` 时循环：
   - `n = n / 5`（整数除法）
   - `count += n`
3. 返回 `count`

### 图解示例

**示例1**: `n = 25`

```
分解 25! 中的因子 5：

1~25 中：
  • 5的倍数:  5, 10, 15, 20, 25     → 至少贡献 1 个 5 (共5个)
  • 25的倍数:  25                    → 额外再贡献 1 个 5 (共1个)
  • 125的倍数: 无

总数 = 5 + 1 = 6 个因子 5

每层贡献示意：
  n=25:  [5] [10] [15] [20] [25]  ← 每隔5个取一个 → 25/5  = 5
  n=5:   [25]                      ← 每隔25个取一个 → 25/25 = 1
  n=1:   无
  ─────────────────────────────────
  total = 5 + 1 = 6

验证: 25! = 15511210043330985984000000
      末尾：000000 ← 6个零！
```

**示例2**: `n = 100`

```
n=100: 5,10,15,...,100 → 100/5 = 20 个
n=20:  25,50,75,100    → 100/25 = 4 个
n=4:   无
total = 20 + 4 = 24 个零
```

### 逐步追踪表

| 迭代 | 当前 n | n/5 | 累加 count | 含义 |
|------|--------|-----|------------|------|
| 1 | 25 | 5 | 5 | 5的倍数贡献5个因子5 |
| 2 | 5 | 1 | 6 | 25的倍数额外贡献1个因子5 |
| 3 | 1 | 0 | 6 | 停止（1 < 5） |

### 边界情况

| 场景 | n | 结果 | 说明 |
|------|---|------|------|
| n < 5 | 3 | 0 | 阶乘中没有因子5 |
| n = 5 | 5 | 1 | 恰好一个5 |
| n = 0 | 0 | 0 | 0! = 1，无尾随零 |
| n = 10 | 10 | 2 | 5和10各贡献一个 |

### 复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| 时间复杂度 | O(log₅ n) | 每次除以5，约 log₅ n 次迭代 |
| 空间复杂度 | O(1) | 只使用常数个变量 |
