# LeetCode 19. Remove Nth Node From End of List（删除链表的倒数第N个结点）

## 考点
Linked List, Two Pointers

## 题目描述
给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

### 示例
```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

### 约束
- 链表中结点的数目为 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

## 解题思路

### 方法：双指针（快慢指针）
核心思想：使用两个指针，快指针先走 `n` 步，然后快慢指针一起走，当快指针到达末尾时，慢指针刚好指向倒数第 `n` 个节点的前驱。

**步骤：**
1. 创建哑节点 `dummy`，`dummy.next = head`。
2. 快慢指针 `fast` 和 `slow` 都初始化为 `dummy`。
3. `fast` 先前进 `n + 1` 步（这样当 fast 为 null 时，slow 指向被删节点的前驱）。
4. 快慢指针同时前进，直到 `fast === null`。
5. `slow.next = slow.next.next`（跳过被删节点）。
6. 返回 `dummy.next`。

**关键点：**
- 使用哑节点处理删除头节点的情况。
- `fast` 先走 `n + 1` 步确保 `slow` 停在被删节点的前驱。
- 不需要计算链表长度，一次遍历完成。

时间复杂度：O(n)
空间复杂度：O(1)
