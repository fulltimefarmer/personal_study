# LeetCode 13. Roman to Integer（罗马数字转整数）

## 考点
Hash Table, Math, String

## 题目描述
罗马数字规则同上题。给定一个罗马数字字符串，将其转换成整数。输入范围 `1 <= s.length <= 15`，保证 `s` 是有效的罗马数字，数值范围 `[1, 3999]`。

### 示例
```
输入: s = "MCMXCIV"
输出: 1994
```

## 解题思路

### 方法：逐字符解析
核心思想：从左到右遍历，如果当前字符对应的值小于下一个字符的值，则减去当前值（如 IV 中 I < V，4 = -1 + 5）；否则加上当前值。

**步骤：**
1. 建立罗马字符到数值的映射。
2. 遍历字符串，对于位置 `i`：
   - 获取当前字符值 `cur` 和下一个字符值 `next`（如果存在）。
   - 如果 `cur < next`，`result -= cur`（如 IV、IX 等）。
   - 否则 `result += cur`。
3. 返回 `result`。

**关键点：**
- 罗马数字通常从左到右递减，当出现左侧值小于右侧值时表示减法组合。
- 只在出现减法规则的 6 种情况下（IV、IX、XL、XC、CD、CM）`cur < next`。

时间复杂度：O(n)
空间复杂度：O(1)
