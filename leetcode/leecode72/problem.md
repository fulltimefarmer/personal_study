# LeetCode 72. Edit Distance（编辑距离） — **中等**

## 考点
String, Dynamic Programming

## 题目描述
给你两个单词 `word1` 和 `word2`，请返回将 `word1` 转换成 `word2` 所使用的最少操作数。

你可以对一个单词进行如下三种操作：
- 插入一个字符
- 删除一个字符
- 替换一个字符

### 示例 1
```
输入：word1 = "horse", word2 = "ros"
输出：3
解释：
horse -> rorse (将 'h' 替换为 'r')
rorse -> rose (删除 'r')
rose -> ros (删除 'e')
```

### 示例 2
```
输入：word1 = "intention", word2 = "execution"
输出：5
解释：
intention -> inention (删除 't')
inention -> enention (将 'i' 替换为 'e')
enention -> exention (将 'n' 替换为 'x')
exention -> exection (将 'n' 替换为 'c')
exection -> execution (插入 'u')
```

### 约束
- `0 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 由小写英文字母组成

## 解题思路

### 核心思路
经典 Levenshtein 编辑距离问题。dp[i][j] 表示 word1 前 i 个字符转换为 word2 前 j 个字符的最少操作数。三种操作对应三个状态转移：
- **插入**（在 word1 末尾插入 word2[j-1]）→ dp[i][j-1] + 1
- **删除**（删除 word1[i-1]）→ dp[i-1][j] + 1
- **替换**（将 word1[i-1] 改为 word2[j-1]）→ dp[i-1][j-1] + 1（或 +0 如果字符相等）

**关键洞察：** dp 表的每个格子需要的值来自其左、上、左上三个方向，因此可以逐行扫描。

### 算法步骤

1. 获取 m = word1.length, n = word2.length
2. 初始化 dp[m+1][n+1]
3. 边界：dp[i][0] = i（全删），dp[0][j] = j（全插）
4. 对 i = 1..m, j = 1..n：
   - 若 word1[i-1] == word2[j-1]：dp[i][j] = dp[i-1][j-1]
   - 否则：dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
5. 返回 dp[m][n]

```
dp[3][2] "hor"→"ro": r≠o → 1+min(dp[2][2]=1, dp[3][1]=2, dp[2][1]=2) = 1+1 = 2 (替换)
```

**dp 路径回溯（最优操作序列）：**

```
     ""  r   o   s
 ""  0   1   2   3

 o   2   2   1   2
 r   3   2   2   2
 s   4   3   3   2
 e   5   4   4  (3) ← 终点

从 dp[5][3]=3 回溯:
  → dp[4][3]=2 (s匹配，无操作)
  → dp[3][2]=2 (不是匹配)
      → 选择 dp[2][2]=1 (o匹配)
      → dp[1][1]=1 (替换 h→r)
      → dp[0][0]=0

操作: 替换h→r, 删除r, 删除e  (共3步)
horse → rorse → rose → ros
```

### 边界情况

| 情况 | word1 | word2 | 处理 | 结果 |
|------|-------|-------|------|------|
| 两者为空 | "" | "" | dp[0][0]=0 | 0 |
| 一个为空 | "abc" | "" | dp[i][0]=i, 全部删除 | 3 |
| 完全相同 | "abc" | "abc" | 主对角线全匹配 | 0 |
| 完全不同 | "abc" | "xyz" | 每步都要操作 | 3 |

### 空间优化（一维 DP）

```
只用两行或一行滚动:

for i in 1..m:
  prev = dp[0]  // 左上角
  dp[0] = i      // 边界
  for j in 1..n:
    temp = dp[j]
    if w1[i-1]==w2[j-1]: dp[j] = prev
    else: dp[j] = 1 + min(dp[j], dp[j-1], prev)
    prev = temp

空间: O(n)
```

### 复杂度分析

- **二维 DP：** 时间 O(m × n)，空间 O(m × n)
- **一维 DP：** 时间 O(m × n)，空间 O(n)
- 编辑距离是经典 DP 问题，广泛应用于拼写检查、DNA 序列比对等
