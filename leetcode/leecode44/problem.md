# LeetCode 44. Wildcard Matching（通配符匹配） — **困难**

## 考点
Greedy, Recursion, String, Dynamic Programming

## 题目描述
给你一个输入字符串 (`s`) 和一个字符模式 (`p`)，请你实现一个支持 `'?'` 和 `'*'` 的通配符匹配规则：

- `'?'` 可以匹配任何单个字符。
- `'*'` 可以匹配任意字符串（包括空字符串）。

判定匹配成功的充要条件是：字符模式必须能够 **完全匹配** 输入字符串（而不是部分匹配）。

**示例 1：**
```
输入：s = "aa", p = "a"
输出：false
解释："a" 无法匹配 "aa" 整个字符串。
```

**示例 2：**
```
输入：s = "aa", p = "*"
输出：true
解释：'*' 可以匹配任意字符串。
```

**示例 3：**
```
输入：s = "cb", p = "?a"
输出：false
解释：'?' 可以匹配 'c', 但第二个 'a' 无法匹配 'b'。
```

**提示：**
- `0 <= s.length, p.length <= 2000`
- `s` 仅由小写英文字母组成
- `p` 仅由小写英文字母、`'?'` 或 `'*'` 组成

## 解题思路

### 核心思路
`?` 匹配单个字符，`*` 匹配任意长度（包括空）。DP 本质是：`dp[i][j]` 表示 `s` 的前 `i` 个字符与 `p` 的前 `j` 个字符是否匹配，转移时 `*` 可匹配空或一个字符。

### 算法步骤

**方法一：DP**
1. 定义 `dp[i][j]`：`s[0..i-1]` 与 `p[0..j-1]` 是否匹配
2. 初始化：`dp[0][0] = true`（空串匹配空模式）
3. 处理 `p` 的前导 `*`：若 `p[j-1] == '*'`，则 `dp[0][j] = dp[0][j-1]`
4. 填充表格（i 从 1 到 m，j 从 1 到 n）：
   - 若 `p[j-1] == '*'`：`dp[i][j] = dp[i-1][j] || dp[i][j-1]`
     - `dp[i-1][j]`：`*` 匹配 `s[i-1]`（消耗一个字符，`*` 可以继续用）
     - `dp[i][j-1]`：`*` 匹配空串
   - 若 `p[j-1] == '?'` 或 `p[j-1] == s[i-1]`：`dp[i][j] = dp[i-1][j-1]`
5. 返回 `dp[m][n]`

**方法二：贪心 + 双指针（最优空间）**
1. 维护 `i`（s 指针）、`j`（p 指针）、`starIdx`（上一个 `*` 的位置）、`matchIdx`（`*` 匹配的 s 中的起始位置）
2. 遇到 `*` 时记录位置并预判匹配空串
3. 不匹配时若有记录的 `*`，回退到 star 位置让 `*` 多匹配一个字符

### 图解示例
`s = "adceb"`, `p = "*a*b"`

```
DP 表格:
       ""  *   a   *   b
    ""  T   T   F   F   F
    a   F   T   T   T   F
    d   F   T   F   T   F
    c   F   T   F   T   F
    e   F   T   F   T   F
    b   F   T   F   T   T  ← 答案!

填充详解:
    dp[0][0]=T (空对空)
    dp[0][1]=T (p[0]='*', 匹配空串, dp[0][0]=T)
    dp[0][2]=F (p[1]='a', 不能匹配空串)

    dp[1][0]=F (s有字符, p为空)
    dp[1][1]: p[0]='*' → dp[0][1]||dp[1][0] = T||F = T
    dp[1][2]: p[1]='a', s[0]='a' → dp[0][1] = T ✓
    dp[1][3]: p[2]='*' → dp[0][3]||dp[1][2] = F||T = T
    dp[1][4]: p[3]='b', s[0]='a' → F

    dp[2][1]: p[0]='*' → dp[1][1]||dp[2][0] = T||F = T
    dp[2][2]: p[1]='a', s[1]='d' → F
    dp[2][3]: p[2]='*' → dp[1][3]||dp[2][2] = T||F = T
    ...

    dp[5][4]: p[3]='b', s[4]='b' → dp[4][3] = T
    → 最终 T ✓

匹配解释:
    s = a  d  c  e  b
    p = *  a  *  b
        │  │  │  │
       空 a  dce  b    ← *匹配 "dce", 另一个*匹配空
```

`s = "aa"`, `p = "*"`

```
DP 表格:
       ""  *
    ""  T   T
    a   F   T
    a   F   T  ← 全部匹配!

dp[1][1]: p[0]='*' → dp[0][1]||dp[1][0] = T||F = T
dp[2][1]: p[0]='*' → dp[1][1]||dp[2][0] = T||F = T
```

### 逐步追踪
`s = "acdcb"`, `p = "a*c?b"`

| i\j | "" | a | * | c | ? | b |
|-----|----|---|---|---|---|---|
| "" | T | F | F | F | F | F |
| a | F | T | T | F | F | F |
| c | F | F | T | T | F | F |
| d | F | F | T | F | T | F |
| c | F | F | T | T | F | F |
| b | F | F | T | F | T | **F** |

```
dp[1][1]: p[0]='a', s[0]='a' → dp[0][0]=T
dp[1][2]: p[1]='*' → dp[0][2]||dp[1][1] = F||T = T
dp[2][2]: p[1]='*' → dp[1][2]||dp[2][1] = T||F = T
dp[2][3]: p[2]='c', s[1]='c' → dp[1][2] = T
...

注意: 这个例子实际上不匹配，因为模式 "a*c?b" 中 c 在 d 之前就无法匹配
*可以匹配空或任意，但 p[2]='c' 必须匹配 s中的一个'c'
```

### 边界情况
| 情况 | s | p | 输出 | 说明 |
|------|---|---|------|------|
| 空串空模式 | "" | "" | true | 两个都空 |
| 空串有* | "" | "****" | true | * 匹配空串 |
| 空串无* | "" | "a" | false | 不匹配 |
| 全* | "abc" | "***" | true | 全匹配 |
| 全? | "abc" | "????" | false | ? 比 s 多一个 |
| 无通配 | "abc" | "abc" | true | 完全匹配 |

### 复杂度分析
| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| DP | O(m × n) | O(m × n) 或 O(n) (滚动数组) |
| 贪心+双指针 | O(m × n) 最坏 | O(1) |

### DP 空间优化（滚动数组）
可以将二维 DP 优化为一维：`dp[j]` 表示当前行，从右向左更新以处理 `dp[i-1][j]` 的依赖。

### 方法对比
| 维度 | DP | 贪心双指针 |
|------|-----|-----------|
| 实现难度 | 中等 | 较难 |
| 空间 | O(m×n) / O(n) | O(1) |
| 最坏时间 | O(m×n) | O(m×n) |
| 平均时间 | O(m×n) | 更快 |
| 直观性 | 高 | 中 |
| 推荐度 | ★★★★★ | ★★★ |
