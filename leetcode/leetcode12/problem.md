# LeetCode 12. Integer to Roman（整数转罗马数字）

## 考点
Hash Table, Math, String

## 题目描述
罗马数字包含以下七种字符：I, V, X, L, C, D, M。

| 字符 | 数值 |
|------|------|
| I    | 1    |
| V    | 5    |
| X    | 10   |
| L    | 50   |
| C    | 100  |
| D    | 500  |
| M    | 1000 |

特殊规则：4 不写做 IIII，而是 IV；9 不写做 VIIII，而是 IX；同理还有 40(XL)、90(XC)、400(CD)、900(CM)。

给你一个整数，将其转为罗马数字。输入范围 `1 <= num <= 3999`。

### 示例
```
输入: num = 1994
输出: "MCMXCIV"
解释: M = 1000, CM = 900, XC = 90, IV = 4
```

## 解题思路

### 方法：贪心匹配
核心思想：列出所有可能的罗马数字组合（从大到小），每次用尽可能大的值去匹配。

**步骤：**
1. 建立数值到罗马数字的映射数组，从大到小排列，包含所有基本字符和特殊组合。
2. 遍历映射数组，当 `num >= value` 时，将对应罗马字符追加到结果，`num -= value`。
3. 重复直到 `num === 0`。

**关键点：**
- 贪心策略保证正确性：因为罗马数字规则是从大到小排列。
- 需要包含 900、400、90、40、9、4 这些特殊组合。
- 数字范围限定在 1-3999。

时间复杂度：O(1)（常数次迭代）
空间复杂度：O(1)（结果字符串长度固定）
