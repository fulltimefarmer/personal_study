# LeetCode 14. Longest Common Prefix（最长公共前缀）

## 考点
String, Trie

## 题目描述
编写一个函数来查找字符串数组中的最长公共前缀。如果不存在公共前缀，返回空字符串 `""`。

### 示例 1
```
输入：strs = ["flower","flow","flight"]
输出："fl"
```

### 示例 2
```
输入：strs = ["dog","racecar","car"]
输出：""
```

### 约束
- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 仅由小写英文字母组成

## 解题思路

### 方法：纵向扫描
核心思想：取第一个字符串为基准，逐字符与其他字符串的对应位置比较。

**步骤：**
1. 如果数组为空，返回 `""`。
2. 遍历第一个字符串的每个字符位置 `i`。
3. 对于每个位置，获取第一个字符串的字符 `ch`。
4. 检查其余所有字符串在位置 `i` 的字符是否等于 `ch`。
5. 如果不等或某个字符串长度不够，返回 `strs[0].substring(0, i)`。
6. 遍历结束说明第一个字符串就是公共前缀，返回它。

**关键点：**
- 纵向扫描比水平扫描（两两比较）更直观。
- 时间复杂度最坏为 O(S)，其中 S 是所有字符串的字符总数。
- 可以优化：先找出最短字符串，以其长度为遍历上限。

时间复杂度：O(n * m)，n 是字符串数量，m 是最短字符串长度
空间复杂度：O(1)
