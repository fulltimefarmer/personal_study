# LeetCode 108. Convert Sorted Array to Binary Search Tree（将有序数组转换为二叉搜索树）

## 考点
树、二叉搜索树、数组、分治、二叉树

## 题目描述
给你一个整数数组 nums，其中元素已经按**升序**排列，请你将其转换为一棵**高度平衡**的二叉搜索树。

**高度平衡**二叉树是一棵满足「每个节点的左右两个子树的高度差的绝对值不超过 1」的二叉树。

**示例 1：**
```
输入：nums = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]
解释：[0,-10,5,null,-3,null,9] 也是正确答案。
```

**示例 2：**
```
输入：nums = [1,3]
输出：[3,1]
解释：[1,null,3] 和 [3,1] 都是高度平衡二叉搜索树。
```

**提示：**
- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- nums 按**严格递增**顺序排列

## 解题思路
由于数组已经升序排列，可以利用**二分法**的思路：每次选择数组的中间元素作为根节点，这样就能保证左右子树的节点数尽可能平衡。

1. 定义递归函数，接收数组的左右边界 `left` 和 `right`
2. 如果 `left > right`，返回 `null`
3. 计算中间位置 `mid = Math.floor((left + right) / 2)`（或选择左中位数/右中位数均可）
4. 以 `nums[mid]` 创建根节点
5. 递归构建左子树：`build(left, mid - 1)`
6. 递归构建右子树：`build(mid + 1, right)`
7. 返回根节点

**关键点：**
- 总是选择中间位置作为根，确保高度平衡
- 数组有序保证了二叉搜索树的性质（左小右大）

时间复杂度：O(n) —— 每个节点访问一次  
空间复杂度：O(log n) —— 递归栈深度（平衡树的高度）
