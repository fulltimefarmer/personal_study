# LeetCode 34. Find First and Last Position of Element in Sorted Array（在排序数组中查找元素的第一个和最后一个位置） — **中等**

## 考点
Array, Binary Search

## 题目描述
给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**
```
输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]
```

**示例 2：**
```
输入：nums = [5,7,7,8,8,10], target = 6
输出：[-1,-1]
```

**示例 3：**
```
输入：nums = [], target = 0
输出：[-1,-1]
```

**提示：**
- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `nums` 是一个非递减数组
- `-10^9 <= target <= 10^9`

## 解题思路

### 核心思路
分别用两次二分查找定位**左边界**（第一个 `>= target` 的位置）和**右边界**（第一个 `> target` 的位置减一）。命中 target 时不停止，而是继续向目标方向收缩。

### 算法步骤
1. **找左边界** `findFirst(nums, target)`：
   - 标准二分，`nums[mid] >= target` 时 `right = mid - 1`，记录 `ans = mid`
   - 最终 `left` 指向第一个 `>= target` 的位置
2. **找右边界** `findLast(nums, target)`：
   - 标准二分，`nums[mid] <= target` 时 `left = mid + 1`，记录 `ans = mid`
   - 最终 `right` 指向最后一个 `<= target` 的位置
3. **另一种写法**：找左边界 = `lowerBound(target)`，找右边界 = `lowerBound(target+1) - 1`
4. 验证左边界是否有效（不越界且值等于 target），否则返回 `[-1, -1]`

### 图解示例
`nums = [5, 7, 7, 8, 8, 10], target = 8`

```
数组形态:
    索引:  0   1   2   3   4   5
    数值:  5   7   7   8   8  10
                       ↑   ↑
                     first last

━━━ 查找左边界 (first position) ━━━
    l=0, r=5, mid=2, nums[2]=7 < 8 → l=3
    l=3, r=5, mid=4, nums[4]=8 >= 8 → ans=4, r=3
    l=3, r=3, mid=3, nums[3]=8 >= 8 → ans=3, r=2
    l=3, r=2 → 停止, first=3 ✓

    [5, 7, 7, 8, 8, 10]
              ↑
           first=3

━━━ 查找右边界 (last position) ━━━
    l=0, r=5, mid=2, nums[2]=7 < 8 → l=3
    l=3, r=5, mid=4, nums[4]=8 <= 8 → ans=4, l=5
    l=5, r=5, mid=5, nums[5]=10 > 8 → r=4
    l=5, r=4 → 停止, last=4 ✓

    [5, 7, 7, 8, 8, 10]
                 ↑
              last=4
```

### lowerBound 方法图解
`nums = [5, 7, 7, 8, 8, 10], target = 8`

```
lowerBound(8):
    找第一个 >= 8 的位置
    [5, 7, 7, 8, 8, 10]
              ↑
             返回 3 (first)

lowerBound(9):  // target+1
    找第一个 >= 9 的位置
    [5, 7, 7, 8, 8, 10]
                       ↑
                      返回 5

答案: [lowerBound(8), lowerBound(9)-1] = [3, 4] ✓
```

### 逐步追踪
`nums = [5,7,7,8,8,10], target = 8`

| 查找目标 | 轮次 | left | right | mid | nums[mid] | 比较 | 操作 | ans |
|---------|------|------|-------|-----|-----------|------|------|-----|
| first | 1 | 0 | 5 | 2 | 7 | 7<8 | left=3 | - |
| first | 2 | 3 | 5 | 4 | 8 | 8≥8 | right=3, ans=4 | 4 |
| first | 3 | 3 | 3 | 3 | 8 | 8≥8 | right=2, ans=3 | 3 |
| first | - | 3 | 2 | - | - | 退出 | - | **3** |
| last | 1 | 0 | 5 | 2 | 7 | 7≤8 | left=3, ans=2 | 2 |
| last | 2 | 3 | 5 | 4 | 8 | 8≤8 | left=5, ans=4 | 4 |
| last | 3 | 5 | 5 | 5 | 10 | 10>8 | right=4 | 4 |
| last | - | 5 | 4 | - | - | 退出 | - | **4** |

### 边界情况
| 情况 | 输入 | target | 输出 | 说明 |
|------|------|--------|------|------|
| 空数组 | [] | 0 | [-1,-1] | 直接返回 |
| 不存在 | [1,2,3] | 5 | [-1,-1] | target比所有元素大 |
| 不存在 | [3,4,5] | 1 | [-1,-1] | target比所有元素小 |
| 全相同 | [2,2,2] | 2 | [0,2] | 全部匹配 |
| 单个匹配 | [1,2,3] | 2 | [1,1] | 只有一个 |
| 边界匹配 | [1,2,2,3] | 2 | [1,2] | 连续匹配 |

### 复杂度分析
- **时间复杂度**: O(log n)，两次独立的二分查找
- **空间复杂度**: O(1)

### 方法对比
| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|-----------|-----------|------|------|
| 两次二分 | O(log n) | O(1) | 最标准、最清晰 | 需要两次二分 |
| lowerBound × 2 | O(log n) | O(1) | 代码复用性高 | lowerBound(9)可能越界 |
| 一次二分+中心扩展 | O(log n + k) | O(1) | 思路直观 | k大时退化为O(n) |
