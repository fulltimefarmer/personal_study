# LeetCode 120. Triangle（三角形最小路径和）

## 考点
数组、动态规划

## 题目描述
给定一个三角形 `triangle`，找出自顶向下的最小路径和。

每一步只能移动到下一行中相邻的节点上。相邻的节点在这里指的是**下标与上一层节点下标相同**或者**等于上一层节点下标 + 1**的两个节点。也就是说，如果正位于当前行的下标 `i`，那么下一步可以移动到下一行的下标 `i` 或 `i + 1`。

**示例 1：**
```
输入：triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
输出：11
解释：路径 2 → 3 → 5 → 1 的总和最小，为 11。
```

**示例 2：**
```
输入：triangle = [[-10]]
输出：-10
```

**提示：**
- `1 <= triangle.length <= 200`
- `triangle[0].length == 1`
- `triangle[i].length == triangle[i - 1].length + 1`
- `-10^4 <= triangle[i][j] <= 10^4`

## 解题思路
采用**自底向上的动态规划**，更简洁且无需处理边界。

**状态定义：**
`dp[j]` 表示从三角形底部到当前位置的最小路径和。

**自底向上递推：**
从倒数第二行开始向上遍历：
- `dp[j] = triangle[i][j] + Math.min(dp[j], dp[j+1])`

初始化 `dp` 为三角形的最后一行。

**关键点：**
- 自底向上避免了边界判断
- 每个位置只能从 `dp[j]` 或 `dp[j+1]` 转移（对应下一行的同列或下一列）
- 最终 `dp[0]` 就是答案

时间复杂度：O(n²)，n 为三角形行数  
空间复杂度：O(n)
