# LeetCode 115. Distinct Subsequences（不同的子序列）

## 考点
字符串、动态规划

## 题目描述
给你两个字符串 `s` 和 `t`，统计并返回在 `s` 的**子序列**中 `t` 出现的个数。

题目数据保证答案符合 32 位带符号整数范围。

**子序列**：通过删除一些（也可以不删除）字符且不干扰剩余字符相对位置所组成的新字符串。

**示例 1：**
```
输入：s = "rabbbit", t = "rabbit"
输出：3
解释：
有 3 种可以从 s 中得到 "rabbit" 的方案：
rabbbit → rabbit（删除第 3 个 b）
rabbbit → rabbit（删除第 4 个 b）
rabbbit → rabbit（删除第 5 个 b）
```

**示例 2：**
```
输入：s = "babgbag", t = "bag"
输出：5
```

**提示：**
- `1 <= s.length, t.length <= 1000`
- s 和 t 由英文字母组成

## 解题思路
采用**动态规划**。定义 `dp[i][j]` 表示 `s[0..i-1]` 的子序列中等于 `t[0..j-1]` 的个数。

**状态转移方程：**
- 如果 `s[i-1] === t[j-1]`：
  - 可以选择用 `s[i-1]` 匹配 `t[j-1]`：`dp[i-1][j-1]`
  - 也可以跳过 `s[i-1]`：`dp[i-1][j]`
  - 所以 `dp[i][j] = dp[i-1][j-1] + dp[i-1][j]`
- 如果 `s[i-1] !== t[j-1]`：
  - 只能跳过 `s[i-1]`：`dp[i-1][j]`
  - 所以 `dp[i][j] = dp[i-1][j]`

**初始化：**
- `dp[i][0] = 1`（空字符串 t 是任何 s 的子序列，只有一种方式即删除所有字符）
- `dp[0][j] = 0`（j > 0 时，空字符串 s 无法形成非空 t）

**优化：**
可以使用一维滚动数组优化空间复杂度。

时间复杂度：O(m × n)，m = s.length，n = t.length  
空间复杂度：O(m × n) 可优化到 O(n)
