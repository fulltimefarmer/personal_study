# LeetCode 10. Regular Expression Matching（正则表达式匹配）

## 考点
String, Dynamic Programming, Recursion

## 题目描述
给你一个字符串 `s` 和一个字符规律 `p`，请你来实现一个支持 `'.'` 和 `'*'` 的正则表达式匹配。

- `'.'` 匹配任意单个字符
- `'*'` 匹配零个或多个前面的那一个元素

所谓匹配，是要涵盖 **整个** 字符串 `s`，而不是部分字符串。

### 示例 1
```
输入：s = "aa", p = "a"
输出：false
解释："a" 无法匹配 "aa" 整个字符串。
```

### 示例 2
```
输入：s = "aa", p = "a*"
输出：true
```

### 示例 3
```
输入：s = "ab", p = ".*"
输出：true
解释：".*" 表示可匹配零个或多个（'*'）任意字符（'.'）。
```

### 约束
- `1 <= s.length <= 20`
- `1 <= p.length <= 20`
- `s` 只包含小写英文字母
- `p` 只包含小写英文字母、`'.'` 和 `'*'`
- 保证每次出现字符 `'*'` 时，前面都匹配到有效的字符

## 解题思路

### 方法：动态规划
核心思想：定义 `dp[i][j]` 表示 `s[0..i-1]` 和 `p[0..j-1]` 是否匹配。

**状态转移：**
1. 如果 `p[j-1]` 不是 `'*'`：
   - `dp[i][j] = dp[i-1][j-1] && (s[i-1] === p[j-1] || p[j-1] === '.')`

2. 如果 `p[j-1]` 是 `'*'`（其前面有字符 `p[j-2]`）：
   - 匹配 0 次：`dp[i][j] = dp[i][j-2]`
   - 匹配 ≥1 次：`dp[i][j] = dp[i-1][j] && (s[i-1] === p[j-2] || p[j-2] === '.')`

**初始化：**
- `dp[0][0] = true`（空字符串匹配空模式）
- `dp[0][j]`：空字符串可能匹配 `a*`, `a*b*` 等模式

**步骤：**
1. 创建 `(m+1) × (n+1)` 的 DP 表。
2. 初始化 `dp[0][0] = true`，处理空字符串的匹配。
3. 按行填充 DP 表。
4. 返回 `dp[m][n]`。

时间复杂度：O(m × n)
空间复杂度：O(m × n)
