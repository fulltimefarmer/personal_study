# LeetCode 132. Palindrome Partitioning II（分割回文串 II）

## 考点
字符串、动态规划

## 题目描述
给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是回文串。

返回符合要求的最少分割次数。

**示例 1：**
```
输入：s = "aab"
输出：1
解释：只需一次分割就可将 s 分割成 ["aa","b"] 这样两个回文子串。
```

**示例 2：**
```
输入：s = "a"
输出：0
```

**示例 3：**
```
输入：s = "ab"
输出：1
```

**提示：**
- `1 <= s.length <= 2000`
- s 仅由小写英文字母组成

## 解题思路
**动态规划 + 预计算回文。**

**步骤一：预计算回文**
用 DP 计算 `isPalindrome[i][j]`，表示 `s[i..j]` 是否为回文串：
`isPalindrome[i][j] = s[i] === s[j] && (j - i <= 2 || isPalindrome[i+1][j-1])`

推荐用中心扩展法，避免 O(n²) 的空间开销。

**步骤二：动态规划求最小分割次数**
定义 `dp[i]` 表示 `s[0..i]` 的最小分割次数。

初始：`dp[i] = i`（最坏情况每个字符单独分割）

转移：
- 如果 `s[0..i]` 本身是回文：`dp[i] = 0`
- 否则遍历 `j` 从 `0` 到 `i-1`：
  - 如果 `s[j+1..i]` 是回文：`dp[i] = min(dp[i], dp[j] + 1)`

**优化思路：**
可以在扩展回文时同时更新 dp 值，减少遍历次数。使用中心扩展法（奇偶两种中心），当扩展到一个回文区间 `[left, right]` 时：
- 若 `left === 0`：`dp[right] = 0`
- 否则：`dp[right] = min(dp[right], dp[left - 1] + 1)`

时间复杂度：O(n²)  
空间复杂度：O(n)
