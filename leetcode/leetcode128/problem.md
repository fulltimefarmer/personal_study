# LeetCode 128. Longest Consecutive Sequence（最长连续序列）

## 考点
并查集、数组、哈希表

## 题目描述
给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1：**
```
输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。
```

**示例 2：**
```
输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
```

**提示：**
- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 解题思路
使用**哈希集合**实现 O(n) 的解法。

**核心思想：** 只从连续序列的起点开始计数，避免重复计算。

1. 将所有数字放入哈希集合 `set`（去重）
2. 遍历集合中的每个数字 `num`：
   - 如果 `num - 1` 不在集合中，说明 `num` 是一个连续序列的起点
   - 从 `num` 开始，不断检查 `num + 1` 是否在集合中，统计序列长度
   - 更新最大长度
3. 返回最大长度

**为什么是 O(n)？**
- 虽然内层 while 循环看起来是 O(n²)，但每个数字最多被内层循环访问一次（因为只有作为序列起点时才进入 while，而每个数字只会属于一个序列）
- 因此总体时间复杂度为 O(n)

**关键点：**
- 判断起点：`num - 1` 不在集合中时才展开搜索
- 需要先对数组去重

时间复杂度：O(n)  
空间复杂度：O(n)
