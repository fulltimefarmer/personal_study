# LeetCode 2. Add Two Numbers（两数相加）

## 考点
Linked List, Math

## 题目描述
给你两个 **非空** 的链表，表示两个非负的整数。它们每位数字都是按照 **逆序** 的方式存储的，并且每个节点只能存储 **一位** 数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

### 示例 1
```
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
解释：342 + 465 = 807
```

### 示例 2
```
输入：l1 = [0], l2 = [0]
输出：[0]
```

### 示例 3
```
输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
输出：[8,9,9,9,0,0,0,1]
```

### 约束
- 每个链表中的节点数在范围 `[1, 100]` 内
- `0 <= Node.val <= 9`
- 题目数据保证列表表示的数字不含前导零

## 解题思路

### 方法：模拟加法
核心思想：同时遍历两个链表，逐位相加，处理进位。

**步骤：**
1. 创建哑节点 `dummy` 作为结果链表的头节点前驱。
2. 使用 `carry` 变量记录进位（0 或 1）。
3. 同时遍历 `l1` 和 `l2`：
   - 取出当前位的值（如果链表已到末尾则取 0）。
   - 计算 `sum = val1 + val2 + carry`。
   - 当前位结果 = `sum % 10`，进位 = `Math.floor(sum / 10)`。
   - 创建新节点存储当前位结果，连接到结果链表。
4. 遍历结束后，如果 `carry > 0`，创建新节点存储进位。
5. 返回 `dummy.next`。

**关键点：**
- 使用哑节点简化头节点处理。
- 链表长度可能不同，短链表遍历完后续位视为 0。
- 最后需要检查是否有额外进位。

时间复杂度：O(max(m, n))
空间复杂度：O(max(m, n))（结果链表长度）
