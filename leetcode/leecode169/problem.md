# LeetCode 169. Majority Element（多数元素） — **简单**

## 考点
Array, Hash Table, Divide and Conquer, Counting, Sorting

## 题目描述
给定一个大小为 `n` 的数组 `nums` ，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `n / 2` 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

**示例 1：**

```
输入：nums = [3,2,3]
输出：3
```

**示例 2：**

```
输入：nums = [2,2,1,1,1,2,2]
输出：2
```

**提示：**
- `n == nums.length`
- `1 <= n <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`

**进阶：** 尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。

## 解题思路

### 核心思路

多数元素出现次数 > n/2，意味着它的数量比其他所有元素的总和还多。Boyer-Moore 投票算法模拟"两两抵消"过程：不同元素互相抵消，最后剩下的必然是多数元素。

### 方法一：Boyer-Moore 投票算法

#### 算法步骤

1. 初始化 `candidate = null`, `count = 0`
2. 遍历数组每个元素 `x`：
   - 若 `count == 0`：`candidate = x`
   - 若 `x == candidate`：`count += 1`
   - 若 `x != candidate`：`count -= 1`
3. 返回 `candidate`

#### 图解示例

**示例**: `nums = [2, 2, 1, 1, 1, 2, 2]`

```
战场模型：不同元素相遇同归于尽

Step 0: 初始
        candidate=?, count=0
        [ ] ← 空阵营

Step 1: x=2, count=0 → 2 入营
        candidate=2, count=1
        阵营: [2]

Step 2: x=2, 同阵营
        candidate=2, count=2
        阵营: [2, 2]

Step 3: x=1, 敌对!
        candidate=2, count=1  ← 一名2与1同归于尽
        阵营: [2]

Step 4: x=1, 敌对!
        candidate=2, count=0  ← 最后一名2也与1同归于尽
        阵营: []

Step 5: x=1, count=0 → 1 入营
        candidate=1, count=1
        阵营: [1]

Step 6: x=2, 敌对!
        candidate=1, count=0
        阵营: []

Step 7: x=2, count=0 → 2 入营
        candidate=2, count=1
        阵营: [2]

最终 candidate = 2（多数元素）
```

#### 逐步追踪表

| 索引 | 元素 x | 操作前 count | x==candidate? | 操作 | 操作后候选 | 操作后 count |
|------|--------|-------------|---------------|------|-----------|-------------|
| 0 | 2 | 0 | count==0 | 换候选 | 2 | 1 |
| 1 | 2 | 1 | Yes | count++ | 2 | 2 |
| 2 | 1 | 2 | No | count-- | 2 | 1 |
| 3 | 1 | 1 | No | count-- | 2 | 0 |
| 4 | 1 | 0 | count==0 | 换候选 | 1 | 1 |
| 5 | 2 | 1 | No | count-- | 1 | 0 |
| 6 | 2 | 0 | count==0 | 换候选 | 2 | 1 |

### 方法二：排序法

排序后取中间位置的元素。因为多数元素出现 > n/2 次，排序后中间位置一定是多数元素。

### 方法三：哈希表统计

遍历统计每个元素的频率，返回频率 > n/2 的元素。

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 投票算法 | O(n) | O(1) |
| 排序法 | O(n log n) | O(1) 或 O(log n) |
| 哈希表 | O(n) | O(n) |

### 边界情况

| 场景 | 输入 | 处理 |
|------|------|------|
| 全部相同 | `[5,5,5,5]` | count 持续增加，返回5 |
| 多数在开头 | `[3,3,1,2,3]` | 投票算法正常工作 |
| 单个元素 | `[1]` | 直接返回1 |
| 恰好过半+1 | `[1,1,2,2,1]` | 投票后1胜出 |

### 复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| 时间复杂度 | O(n) | 一次遍历 |
| 空间复杂度 | O(1) | 只使用两个变量 |
