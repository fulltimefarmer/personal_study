# LeetCode 206. Reverse Linked List（反转链表） — **简单**

## 考点
递归、链表

## 题目描述
给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

**示例 1：**
```
输入：head = [1,2,3,4,5]
输出：[5,4,3,2,1]
```

**示例 2：**
```
输入：head = [1,2]
输出：[2,1]
```

**示例 3：**
```
输入：head = []
输出：[]
```

**提示：**
- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

**进阶：** 链表可以选用迭代或递归方式完成反转。你能否用两种方法解决这道题？

## 解题思路

### 核心思路

反转单链表：遍历链表，将每个节点的 next 指针反过来指向前一个节点。需要三个指针：`prev`（已反转部分的头）、`curr`（当前处理的节点）、`next`（下一个要处理的节点）。

### 方法一：迭代法

#### 算法步骤

1. 初始化 `prev = null`, `curr = head`
2. 当 `curr != null` 时循环：
   - `next = curr.next` — 保存下一个节点
   - `curr.next = prev` — 反转指针
   - `prev = curr` — prev 前进
   - `curr = next` — curr 前进
3. 返回 `prev`（新头节点）

#### 图解示例

**示例**: `head = [1, 2, 3, 4, 5]`

```
初始状态:
  null ← prev
  1 → 2 → 3 → 4 → 5 → null
  ↑
  curr

───────────────────────────────────

Step 1:
  保存 next = curr.next (节点2)
  反转 curr.next = prev (null)

  null ← 1    2 → 3 → 4 → 5 → null
         ↑    ↑
        prev next/curr(下一步)

  指针图示:
  ┌────┐    ┌────┐    ┌────┐    ┌────┐    ┌────┐
  │ 1  │    │ 2  │    │ 3  │    │ 4  │    │ 5  │
  │next├─?  │next├───→│next├───→│next├───→│next├→null
  └────┘    └────┘    └────┘    └────┘    └────┘
    ↑         ↑
   prev      curr
  1.next → null

───────────────────────────────────

Step 2:
  prev = 1, curr = 2
  保存 next = curr.next (节点3)
  反转 curr.next = prev (节点1)

  null ← 1 ← 2    3 → 4 → 5 → null
              ↑    ↑
             prev curr

───────────────────────────────────

Step 3:
  prev = 2, curr = 3
  null ← 1 ← 2 ← 3    4 → 5 → null
                  ↑    ↑
                 prev curr

───────────────────────────────────

Step 4:
  null ← 1 ← 2 ← 3 ← 4    5 → null
                      ↑    ↑
                     prev curr

───────────────────────────────────

Step 5:
  null ← 1 ← 2 ← 3 ← 4 ← 5
                          ↑    ↑
                         prev curr = null

循环结束！返回 prev (节点5)

最终链表:
  5 → 4 → 3 → 2 → 1 → null
```

### 方法二：递归法

```
递归过程（从尾到头回溯）:

reverseList(1→2→3→4→5→null)
  │
  ├─ reverseList(2→3→4→5)  →  返回 5→4→3→2→null
  │    │
  │    ├─ reverseList(3→4→5)  →  返回 5→4→3→null
  │    │    │
  │    │    ├─ reverseList(4→5)  →  返回 5→4→null
  │    │    │    │
  │    │    │    └─ reverseList(5)  →  返回 5 (基案)
  │    │    │
  │    │    │  回溯: head=4, head.next=5
  │    │    │  4.next.next = 4  →  5.next = 4
  │    │    │  4.next = null
  │    │    │  返回 5→4
  │    │
  │    │  回溯: head=3, head.next=4
  │    │  3.next.next = 3  →  4.next = 3
  │    │  3.next = null
  │    │  返回 5→4→3
  │
  │  回溯: head=2, head.next=3
  │  2.next.next = 2  →  3.next = 2
  │  2.next = null
  │  返回 5→4→3→2
  │
    回溯: head=1, head.next=2
    1.next.next = 1  →  2.next = 1
    1.next = null
    返回 5→4→3→2→1
```

### 逐步追踪表（迭代法）

| 步 | curr.val | next.val | curr.next→ | prev.val | curr.val (下一步) | 说明 |
|----|---------|---------|-----------|---------|-----------------|------|
| 初始 | 1 | — | — | null | 1 | 开始 |
| 1 | 1 | 2 | null | 1 | 2 | 1反转指向null |
| 2 | 2 | 3 | 1 | 2 | 3 | 2反转指向1 |
| 3 | 3 | 4 | 2 | 3 | 4 | 3反转指向2 |
| 4 | 4 | 5 | 3 | 4 | 5 | 4反转指向3 |
| 5 | 5 | null | 4 | 5 | null | 5反转指向4, 结束 |

### 边界情况

| 场景 | 输入 | 处理 |
|------|------|------|
| 空链表 | `[]` | curr==null，直接返回null |
| 单节点 | `[1]` | 执行一次，返回节点1 |
| 两节点 | `[1,2]` | 正常反转 |

### 复杂度分析

| 方法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 迭代法 | O(n) | O(1) |
| 递归法 | O(n) | O(n)（递归栈） |
