# LeetCode 17. Letter Combinations of a Phone Number（电话号码的字母组合） — **中等**

## 考点
Hash Table, String, Backtracking

## 题目描述
给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

| 数字 | 字母     |
|------|----------|
| 2    | abc      |
| 3    | def      |
| 4    | ghi      |
| 5    | jkl      |
| 6    | mno      |
| 7    | pqrs     |
| 8    | tuv      |
| 9    | wxyz     |

**示例 1：**
```
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

**示例 2：**
```
输入：digits = ""
输出：[]
```

**示例 3：**
```
输入：digits = "2"
输出：["a","b","c"]
```

**提示：**
- `0 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 的一个数字

## 解题思路

### 核心思路
典型的回溯问题。每个数字对应多个字母选择，问题可以建模为：从每个数字对应的字母集合中各选一个字母，形成所有可能的组合。回溯法（DFS）遍历这个决策树。

### 算法步骤

**方法一：回溯法（DFS）**

1. 建立数字到字母的映射表（数组或哈希表）：
   - `2→"abc", 3→"def", 4→"ghi", 5→"jkl", 6→"mno", 7→"pqrs", 8→"tuv", 9→"wxyz"`
2. 特殊情况：如果 `digits` 为空，返回 `[]`
3. 定义回溯函数 `backtrack(index, path)`：
   - **终止条件**：`index == digits.length`，将 `path` 加入结果列表，返回
   - **选择列表**：获取 `digits[index]` 对应的字母集合 `letters`
   - **遍历选择**：对于 `letters` 中的每个字母 `c`：
     - **做选择**：`path.append(c)`
     - **递归**：`backtrack(index + 1, path)`（进入下一层决策）
     - **撤销选择**：`path.deleteCharAt(path.length() - 1)`（回溯）
4. 调用 `backtrack(0, new StringBuilder())`，返回结果

**方法二：迭代法（BFS/队列）**

1. 初始化结果列表为 `[""]`（只有一个空字符串）
2. 遍历 `digits` 中的每个数字：
   - 获取该数字对应的字母集合
   - 将当前结果列表中的每个字符串分别追加字母集合中的每个字母
   - 替换结果列表
3. 返回结果列表

### 逐步追踪

以输入 `digits = "2"` 为例：

| 递归层级 | index | digits[index] | letters | 选择 | path | 是否到达叶子 | 操作 |
|---------|-------|---------------|---------|------|------|------------|------|
| 1       | 0     | '2'           | "abc"   | 'a'  | "a"  | —          | 递归 index+1 |
| 2       | 1     | —(越界)       | —       | —    | "a"  | 是         | 加入结果, 返回 |
| 1(回溯) | 0     | '2'           | "abc"   | 'b'  | "b"  | —          | 递归 index+1 |
| 2       | 1     | —(越界)       | —       | —    | "b"  | 是         | 加入结果, 返回 |
| 1(回溯) | 0     | '2'           | "abc"   | 'c'  | "c"  | —          | 递归 index+1 |
| 2       | 1     | —(越界)       | —       | —    | "c"  | 是         | 加入结果, 返回 |

结果：["a", "b", "c"]

### 边界情况

1. **空输入 `digits = ""`**：直接返回 `[]`（不是 `[""]`），注意题目要求
2. **单个数字**：返回该数字对应的所有字母，每个字母是单独的字符串
3. **数字包含 7 或 9**（对应 4 个字母）：算法不变，分支因子为 4
4. **数字长度达到上限 4**（如 "7777"）：最多 4^4 = 256 种组合，不会溢出

### 复杂度分析

时间复杂度：O(3^m × 4^n)，其中 m 是对应 3 个字母的数字个数（2,3,4,5,6,8），n 是对应 4 个字母的数字个数（7,9）。这是一个指数级别的复杂度，但由于输入长度 <=4，实际组合数最多为 4^4=256

空间复杂度：O(k)，k 为输入数字的长度。递归调用栈的深度最多为 4；不计结果存储

### 方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 回溯法（DFS） | O(3^m × 4^n) | O(k) | 递归实现，代码清晰 ✓ |
| 迭代法（BFS） | O(3^m × 4^n) | O(3^m × 4^n) | 不需要递归，但需要存储中间结果 |
