# 第 2 题：最小栈（Min Stack）

## 题目描述

设计一个支持 `push`、`pop`、`top` 操作，并能在**常数时间**内检索到最小元素的栈。

实现 `MinStack` 类：

| 方法 | 说明 |
|------|------|
| `push(val)` | 将元素 `val` 压入栈 |
| `pop()` | 移除栈顶元素 |
| `top()` | 获取栈顶元素 |
| `getMin()` | 获取栈中的最小元素 |

所有操作均需在 O(1) 时间复杂度内完成。

### 示例

```text
ms = MinStack()
ms.push(-2)
ms.push(0)
ms.push(-3)
ms.getMin()  -> -3
ms.pop()
ms.top()     -> 0
ms.getMin()  -> -2
```

## 考察点

- 辅助栈（单调栈）的经典用法
- 如何在元素被弹出后仍能快速还原历史最小值

## 解题思路

用一个**辅助栈** `min_stack` 与主栈 `stack` 同步维护"截至当前栈顶"的最小值：

1. `push(val)`：主栈入栈；若 `val <= min_stack` 栈顶（或辅助栈为空），则 `val` 也入辅助栈。使用 `<=` 保证重复最小值不会因一次 `pop` 而丢失。
2. `pop()`：主栈出栈；若出栈元素恰好等于辅助栈顶，辅助栈也出栈。
3. `getMin()`：直接返回辅助栈栈顶。

这样每个操作都是 O(1)，且空间最坏 O(n)。

### 复杂度

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| push / pop / top / getMin | O(1) | O(n) |
