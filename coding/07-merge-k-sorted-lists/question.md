# 第 7 题：合并 K 个升序链表（Merge K Sorted Lists）

## 题目描述

给你一个链表数组 `lists`，每个链表都是升序排列的。请将这 `k` 个链表合并为一个升序链表并返回其头节点。

### 示例

```text
lists = [[1, 4, 5], [1, 3, 4], [2, 6]]
输出: [1, 1, 2, 3, 4, 4, 5, 6]
```

## 考察点

- 最小堆（优先队列）在多路归并中的应用
- Python `heapq` 中元组比较：`(val, 序号, node)`，用序号避免节点不可比
- 哨兵节点简化链表操作

## 解题思路

1. **最小堆**维护每个链表的当前头节点，堆中元素为 `(节点值, 链表序号, 节点)`。序号 `i` 用于值相同时打破平局，避免直接比较节点。
2. 每次从堆中弹出最小节点接到结果链表尾部；若该节点有后继，将后继入堆。
3. 重复直到堆空。

### 复杂度

| 项 | 复杂度 |
|----|--------|
| 时间复杂度 | O(N log k)，N 为节点总数，堆大小最多为 k |
| 空间复杂度 | O(k) |
