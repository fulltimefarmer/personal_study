# 第 8 题：二叉树的锯齿形层序遍历（Binary Tree Zigzag Level Order Traversal）

## 题目描述

给你二叉树的根节点 `root`，返回其节点值的**锯齿形层序遍历**——即逐层从左到右、再从右到左交替进行，第一层从左到右，第二层从右到左，依此类推。

### 示例

```text
输入: root = [3, 9, 20, None, None, 15, 7]

        3
       / \
      9  20
         / \
        15  7

输出: [[3], [20, 9], [15, 7]]
```

## 考察点

- BFS 层序遍历
- 按层奇偶切换遍历方向

## 解题思路

基于普通 BFS 层序遍历，增加一个布尔标记 `left_to_right`：

1. 队列按层处理节点，每层收集 `level` 值列表。
2. 若当前层方向为右到左（`left_to_right == False`），则 `level.reverse()` 后再追加到结果。
3. 每处理完一层翻转方向标记。

### 复杂度

| 项 | 复杂度 |
|----|--------|
| 时间复杂度 | O(n)，每个节点入队、出队各一次 |
| 空间复杂度 | O(n)，队列最多容纳一层节点 |
