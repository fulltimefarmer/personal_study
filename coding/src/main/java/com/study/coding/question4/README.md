# 题目 4：文本左右对齐

## 题目描述

给定一个单词数组 `words` 和一个长度 `maxWidth`，重新排版单词，使其成为每行恰好有 `maxWidth` 个字符，且左右两端对齐的文本。

你应该使用贪心算法来放置单词：尽可能多地往每行中放置单词，必要时用空格填充，使得每行恰好有 `maxWidth` 个字符。

要求尽可能均匀地分配单词间的空格。如果某一行的空格数不能被单词间隔数整除，则左侧间隔的空格数可以比右侧多。

文本的最后一行应为左对齐，且单词之间只插入一个空格，剩余空间用空格填充到 `maxWidth`。

注意：
- 单词是指由非空格字符组成的字符序列。
- 每个单词的长度大于 0，且小于等于 `maxWidth`。
- 输入单词数组 `words` 至少包含一个单词。

## 示例

```
输入：words = ["This", "is", "an", "example", "of", "text", "justification."]
     maxWidth = 16

输出：
[
   "This    is    an",
   "example  of text",
   "justification.  "
]

解释（用 · 表示空格）：
第 1 行："This····is····an"          — 单词间 4 个空格（左侧多分配）
第 2 行："example··of·text"          — 单词间 2 个、1 个空格（左侧多分配）
第 3 行："justification.··"          — 最后一行左对齐，末尾补齐
```

## 解题思路

### 1. 问题分解

整个问题可以拆分为三个子问题：

1. **单词分组**：确定每一行包含哪些单词。
2. **空格计算**：计算每行需要多少空格以及如何分配。
3. **行构建**：根据前两步的结果拼接字符串。

### 2. 第一步：单词分组（贪心）

```
算法逻辑：
1. 初始化当前行 length = words[i].length()。
2. 每次尝试添加下一个单词时，需要额外 1 个空格 + 单词长度。
3. 如果 length + 1 + nextWord.length() <= maxWidth，则将其加入当前行。
4. 否则，当前行完成，开始下一行。
```

关键点：需要区分 "单词本身的长度" 和 "加上空格后的总长度"。

### 3. 第二步：空格分配（核心难点）

```
假设一行有 N 个单词，它们之间共有 G = N - 1 个间隔。
设总可用空格数 = maxWidth - 所有单词总长度 = S。

情况 1：N == 1 或最后一行
  → 左对齐：单词靠左，剩余全部填空格。

情况 2：N > 1 且非最后一行
  → 每个间隔基础空格数 = S / G（整数除法）
  → 余数多余空格数 = S % G
  → 前 (S % G) 个间隔各多分配 1 个空格
```

示例：单词 ["example", "of", "text"]，maxWidth=16
- 单词总长度 = 7 + 2 + 4 = 13
- 总空格数 S = 16 - 13 = 3
- 间隔数 G = 2
- 每个间隔基础空格 = 3 / 2 = 1
- 余数 = 3 % 2 = 1
- 分配结果：第 1 个间隔 2 空格，第 2 个间隔 1 空格 → "example··of·text"

### 4. 第三步：行构建

使用 `StringBuilder` 高效拼接：

```java
for (每个单词 j) {
    sb.append(words[j]);
    if (不是最后一个单词) {
        int spaces = 基础空格 + (当前间隔是否在余数范围内 ? 1 : 0);
        sb.append(" ".repeat(spaces));
    }
}
// 最后一行：补齐尾部空格
while (sb.length() < maxWidth) sb.append(' ');
```

### 5. 边界情况

| 边界情况 | 处理方式 |
|----------|----------|
| 单独一个单词占一行 | 左对齐，末尾补空格 |
| 最后一行有多个单词 | 单词间单空格，末尾补空格 |
| 一行恰好填满 maxWidth | 无需补空格，正常返回 |
| 空输入 | 返回空列表 |

### 6. 复杂度分析

- **时间复杂度**：O(n * L)，n 为单词数，L 为每个单词的平均长度。每个单词被访问常数次（分组 + 构建）。
- **空间复杂度**：O(n)，结果列表存储所有行，每行长度不超过 maxWidth。
