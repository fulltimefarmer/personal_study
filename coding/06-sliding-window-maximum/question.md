# 第 6 题：滑动窗口最大值（Sliding Window Maximum）

## 题目描述

给定一个整数数组 `nums` 和一个整数 `k`，请返回所有大小为 `k` 的滑动窗口中的最大值。

返回结果是一个数组，其中 `result[i]` 是窗口 `[i, i + k - 1]` 中的最大值。

### 示例

```text
nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3
输出: [3, 3, 5, 5, 6, 7]

窗口位置            最大值
[1, 3, -1]          3
[3, -1, -3]         3
[-1, -3, 5]         5
[-3, 5, 3]          5
[5, 3, 6]           6
[3, 6, 7]           7
```

## 考察点

- 单调双端队列（monotonic deque）维护窗口最大值
- 下标与元素值的关系：用下标判断元素是否滑出窗口

## 解题思路

朴素做法对每个窗口取 `max` 是 O(nk)，会超时。用**单调递减双端队列**优化到 O(n)。

队列里存**下标**，并保持对应元素值从队头到队尾单调递减：

1. 遍历数组，维护窗口左边界：若队头下标已滑出窗口（`dq[0] <= i - k`），从队头弹出。
2. 从队尾开始，弹出所有值小于当前元素 `nums[i]` 的下标（它们不可能是之后窗口的最大值）。
3. 将 `i` 入队尾。
4. 当窗口形成（`i >= k - 1`）时，队头即为当前窗口最大值，记录 `nums[dq[0]]`。

### 复杂度

| 项 | 复杂度 |
|----|--------|
| 时间复杂度 | O(n)，每个元素入队、出队各一次 |
| 空间复杂度 | O(k) |
