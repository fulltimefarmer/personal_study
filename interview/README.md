## 使用方式

1. 先刷每个文档中的 ★★★★★ 必考题，确保能脱稿讲 60 秒。
2. 再刷 ★★★★☆ 高频题，结合自己的项目经历补充例子。
3. 最后看 ★★★☆☆ 中频题查漏补缺。
4. 每道题先自测，再看“答题要点”，不要直接背答案。
5. 建议按“Java → Spring Cloud → 中间件 → SQL → 其他”的顺序复习。

## 频率说明

- ★★★★★ 必考：近两年大厂一面/二面反复出现，必须掌握原理与细节。
- ★★★★☆ 高频：中高级岗位常见，建议结合项目经历准备。
- ★★★☆☆ 中频：加分项或特定岗位会问，时间充裕时补充。
