## 使用方式

1. 先刷每个文档中的 ★★★★★ 必考题，确保能脱稿讲 60 秒。
2. 再刷 ★★★★☆ 高频题，结合自己的项目经历补充例子。
3. 最后看 ★★★☆☆ 中频题查漏补缺。
4. 每道题的“标准回答”用于现场作答，“深入回答”用于应对追问，“适用案例”用于结合项目展开。
5. 建议按“Java → Spring Cloud → DB 与中间件 → 系统设计 → 其他”的顺序复习。

## 三段式解析（全部文档）

- **标准回答**：面试现场可直接说的版本，先给结论，控制在 60 到 90 秒。
- **深入回答**：面试官继续追问时展开，包含底层原理、源码细节、边界与对比。
- **适用案例**：结合项目经历说明怎么用、踩过什么坑、如何验证效果。

Java 文档还包含 **JDK 9—21 新特性专题**，覆盖模块化、var、record、sealed、模式匹配、文本块、虚拟线程、结构化并发、分代 ZGC 和升级实践。

Spring Cloud 文档新增 **Dubbo 服务治理专题**，覆盖服务暴露/引用、SPI、负载均衡、集群容错、线程模型、序列化、优雅停机和 Dubbo 3 Triple/应用级服务发现。

DB 与中间件文档合并了原 SQL 与 MySQL、中间件两份题库，并新增 MySQL 架构、复制备份和 PostgreSQL 专题，覆盖索引、事务与锁、SQL 优化、分库分表、MySQL 运维、PostgreSQL、Redis、Kafka、Nacos、消息队列、Elasticsearch、MongoDB、ZooKeeper、Neo4j 和 ClickHouse。每题同样采用标准回答、深入回答和适用案例。

系统设计文档覆盖设计方法论、高并发高可用、性能优化、存储与消息选型、18 个典型系统设计和线上故障排查，可与 system-design/ 中的完整方案配合使用。

其他文档覆盖分布式理论、高并发架构、场景设计、网络/Linux、HTTPS、设计模式、DDD 和 gRPC；DDD 专题包含限界上下文、聚合、实体/值对象、领域事件、Repository、防腐层、CQRS 和事件溯源，gRPC 专题覆盖 Protobuf、四种调用模式、超时、负载均衡和排障。每题同样采用标准回答、深入回答和适用案例。

## 频率说明

- ★★★★★ 必考：近两年大厂一面/二面反复出现，必须掌握原理与细节。
- ★★★★☆ 高频：中高级岗位常见，建议结合项目经历准备。
- ★★★☆☆ 中频：加分项或特定岗位会问，时间充裕时补充。
