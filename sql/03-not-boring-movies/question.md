
# 第 3 题：有趣的电影

## 题目描述

有一张 `Cinema` 表，记录电影院上映的电影信息：

| 列名        | 类型    | 说明                               |
|-------------|---------|------------------------------------|
| id          | INT     | 主键，电影ID                       |
| movie       | VARCHAR | 电影名称                           |
| description | VARCHAR | 电影描述（"boring" 表示无聊）      |
| rating      | FLOAT   | 电影评分（0~10）                   |

请编写 SQL，找出所有影片描述**不等于** `"boring"` 且 ID 为**奇数**的电影，并按评分**从高到低**排序输出。

### 示例

**输入：**

| id | movie      | description | rating |
|----|------------|-------------|--------|
| 1  | 战狼       | great       | 9.0    |
| 2  | 科幻片A    | boring      | 7.5    |
| 3  | 流浪地球   | wonderful   | 8.9    |
| 4  | 动画片B    | boring      | 6.0    |
| 5  | 哪吒       | amazing     | 9.5    |

**输出：**

| id | movie    | description | rating |
|----|----------|-------------|--------|
| 5  | 哪吒     | amazing     | 9.5    |
| 1  | 战狼     | great       | 9.0    |
| 3  | 流浪地球 | wonderful   | 8.9    |

**解释：** ID 为 2 和 4 的电影描述是 "boring"，被排除；ID 为 5、1、3 的是奇数且不无聊，按评分降序排列。

## 考察点

- `WHERE` 中不等于条件 `<>` 或 `!=`
- 判断奇数的常用数学方法：`id % 2 = 1` 或者位运算
- `ORDER BY ... DESC` 降序排序

## 解题思路

1. 条件一：`description <> 'boring'` 排除无聊电影
2. 条件二：`id % 2 = 1` 或者 `MOD(id, 2) = 1` 筛选奇数 ID
3. 最后 `ORDER BY rating DESC` 按评分降序

这两个条件用 `AND` 连接，需要同时满足。

**注意**：在 PostgreSQL 中，`%` 是取模运算符。也可以使用 `id & 1 = 1`（位与运算）来判断奇数，效率更高但可读性稍差。
