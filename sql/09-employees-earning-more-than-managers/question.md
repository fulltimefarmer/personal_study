
# 第 9 题：超过经理收入的员工

## 题目描述

有一张 `Employee` 表，包含所有员工及其经理的信息：

| 列名     | 类型    | 说明             |
|----------|---------|------------------|
| id       | INT     | 主键，员工 ID     |
| name     | VARCHAR | 员工姓名         |
| salary   | INT     | 工资             |
| managerId | INT    | 员工的经理 ID（可为NULL，表示没有经理） |

请编写 SQL，找出**工资比自己的经理工资还高的员工**的姓名。

### 示例

**输入：**

| id | name | salary | managerId |
|----|------|--------|-----------|
| 1  | 张总 | 80000  | NULL      |
| 2  | 小王 | 60000  | 1         |
| 3  | 小李 | 75000  | 1         |
| 4  | 小赵 | 85000  | 1         |
| 5  | 小孙 | 50000  | 3         |

**输出：**

| Employee |
|----------|
| 小赵     |

**解释：** 小赵（salary=85000）的经理是张总（salary=80000），小赵的工资比张总高。

## 考察点

- **自连接（Self Join）**：一张表和自己做 `JOIN`
- 理解自连接中别名的作用（`e1` 代表员工，`e2` 代表经理）

## 解题思路

因为"员工"和"经理"的信息都在同一张 `Employee` 表中，所以需要把这张表**和自己连接**。

```sql
SELECT e1.name AS "Employee"
FROM Employee e1
JOIN Employee e2 ON e1.managerId = e2.id
WHERE e1.salary > e2.salary;
```

- `e1`：代表"员工"（我们要输出的对象）
- `e2`：代表"经理"（通过 `e1.managerId = e2.id` 关联出来）
- `e1.salary > e2.salary`：员工的工资比经理高

**注意**：不需要处理 `managerId IS NULL` 的情况（即没有经理的最高层），因为 `JOIN` 条件 `e1.managerId = e2.id` 中 `NULL = id` 不会匹配任何行，这些员工自然会被排除。

### 扩展

- 如果需要返回"全部员工及其经理信息"（包含没有经理的），可以用 `LEFT JOIN` 替代 `INNER JOIN`
- 如果要找"比直属上级高两级的人的工资还高"，可以再做一次自连接（三表关联）
