
# 第 5 题：变更性别

## 题目描述

有一张 `Salary` 表，包含员工的薪资和性别信息：

| 列名 | 类型    | 说明                                          |
|------|---------|-----------------------------------------------|
| id   | INT     | 主键，员工 ID                                   |
| name | VARCHAR | 员工姓名                                       |
| sex  | CHAR(1) | 性别，`'m'` 表示男性（male），`'f'` 表示女性（female） |
| salary | INT  | 工资                                          |

请编写一个 SQL 更新语句，将所有 `'f'` 改为 `'m'`，将所有 `'m'` 改为 `'f'`，即**交换性别**。要求**只使用一条 `UPDATE` 语句**，不能使用 `SELECT`。

### 示例

**更新前：**

| id | name | sex | salary |
|----|------|-----|--------|
| 1  | 张三 | m   | 8000   |
| 2  | 李四 | f   | 12000  |
| 3  | 王五 | m   | 9000   |
| 4  | 赵六 | f   | 15000  |

**更新后：**

| id | name | sex | salary |
|----|------|-----|--------|
| 1  | 张三 | f   | 8000   |
| 2  | 李四 | m   | 12000  |
| 3  | 王五 | f   | 9000   |
| 4  | 赵六 | m   | 15000  |

## 考察点

- `UPDATE` 语句
- `CASE WHEN` 条件表达式在 `SET` 子句中的使用
- `SET sex = CASE WHEN sex = 'm' THEN 'f' ELSE 'm' END` 的经典写法

## 解题思路

目标是将性别取反：`'m' → 'f'`，`'f' → 'm'`。不能写两条 `UPDATE` 分别处理，因为先执行完一条后数据已经变了，会导致全部变成一种性别。

正确做法是使用 `CASE WHEN` 表达式在赋值时做判断：

```sql
UPDATE Salary
SET sex = CASE WHEN sex = 'm' THEN 'f' ELSE 'm' END;
```

当 `sex = 'm'` 时赋值为 `'f'`，否则（即 `sex = 'f'` 时）赋值为 `'m'`。由于赋值是在同一时刻对所有行进行的（基于旧值），所以不会出现交叉污染的问题。

### 扩展

- 如果未来新增了第三种性别（比如 `'x'`），可以用更明确的 `CASE WHEN sex = 'm' THEN 'f' WHEN sex = 'f' THEN 'm' ELSE sex END` 来保证未知值不被改变
- `CASE WHEN` 是 SQL 中实现 if-else 逻辑的核心语法，在 `SELECT`、`WHERE`、`ORDER BY`、`SET` 中都可以使用
