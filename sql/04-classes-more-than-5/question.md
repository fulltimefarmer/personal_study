
# 第 4 题：超过 5 名学生的课程

## 题目描述

有一张 `Courses` 表，记录了学生的选课情况：

| 列名   | 类型    | 说明     |
|--------|---------|----------|
| student | VARCHAR | 学生姓名 |
| class   | VARCHAR | 课程名称 |

一个学生可以选修多门课程，因此同一个学生在同一门课中可能出现多次（比如同一个学生多次报名同一门课）。

请编写 SQL，列出所有**至少有 5 个不同学生**选修的课程。

### 示例

**输入：**

| student | class    |
|---------|----------|
| 张三    | 数学     |
| 李四    | 英语     |
| 王五    | 数学     |
| 赵六    | 计算机   |
| 张三    | 英语     |
| 孙七    | 数学     |
| 周八    | 数学     |
| 张三    | 数学     |
| 吴九    | 数学     |

**输出：**

| class |
|-------|
| 数学  |

**解释：** 数学课有张三、王五、孙七、周八、吴九共 5 个不同学生（张三报了两次数学，但只算一个），因此满足条件；英语课只有张三和李四，不满足。

## 考察点

- `GROUP BY` 分组统计
- `HAVING` 对分组结果过滤（与 `WHERE` 的区别）
- `COUNT(DISTINCT column)` 去重计数

## 解题思路

1. 按课程 `class` 分组
2. 统计每门课的不同学生数：`COUNT(DISTINCT student)`
3. 用 `HAVING` 过滤出人数 ≥ 5 的课程

**关键点**：题目要求的是"不同学生"，所以必须使用 `COUNT(DISTINCT student)`，而不是 `COUNT(student)`。如果使用 `COUNT(*)` 或 `COUNT(student)`，张三在数学中出现两次会被计为 2 人。

### WHERE 和 HAVING 的区别

- `WHERE`：在分组**之前**过滤行，用于过滤原始数据
- `HAVING`：在分组**之后**过滤组，用于过滤聚合结果
- 本题需要用 `HAVING`，因为过滤条件是"课程的人数 ≥ 5"，这是聚合之后才能知道的
