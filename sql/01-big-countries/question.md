
# 第 1 题：大的国家

## 题目描述

有一张 `World` 表，记录世界上各个国家的基本信息：

| 列名          | 类型    | 说明           |
|---------------|---------|----------------|
| name          | VARCHAR | 国家名称       |
| continent     | VARCHAR | 所属大洲       |
| area          | INT     | 国土面积（平方公里） |
| population    | INT     | 人口数         |
| gdp           | BIGINT  | 国内生产总值   |

如果一个国家满足以下两个条件之一，它就是**大国**：
- 国土面积至少 300 万平方公里；或者
- 人口数至少 2500 万。

请编写 SQL 查询，返回所有大国的名称、人口数和国土面积。

### 示例

**输入：**

| name      | continent | area    | population | gdp          |
|-----------|-----------|---------|------------|--------------|
| 阿富汗    | 亚洲      | 652230  | 25500100   | 20343000000  |
| 阿尔巴尼亚 | 欧洲     | 28748   | 2831741    | 12960000000  |
| 阿尔及利亚 | 非洲     | 2381741 | 37100000   | 188681000000 |
| 安道尔    | 欧洲      | 468     | 78115      | 3712000000   |
| 安哥拉    | 非洲      | 1246700 | 20609294   | 100990000000 |

**输出：**

| name      | population | area    |
|-----------|------------|---------|
| 阿富汗    | 25500100   | 652230  |
| 阿尔及利亚 | 37100000   | 2381741 |

**解释：** 阿富汗人口超过 2500 万，是人口大国；阿尔及利亚人口超过 2500 万，也是人口大国；其他国家两个条件都不满足。

## 考察点

- `WHERE` 条件过滤中 `OR` 和 `AND` 的区别
- 数值类型比较
- `SELECT` 基本语法

## 解题思路

这是最简单的入门题。核心就是理解 `OR` 条件：

1. 题目要求满足"面积 ≥ 3000000  **或** 人口 ≥ 25000000"——注意是"或"，不是"且"
2. SQL 中用 `OR` 连接两个条件
3. 筛选出满足条件的行，只保留需要的列

一个常见误区是用 `AND` 替代 `OR`，这会导致只选出两个条件**同时**满足的国家，与题意不符。
